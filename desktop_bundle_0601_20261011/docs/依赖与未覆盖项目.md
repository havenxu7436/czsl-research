# 外部依赖、忠实度边界与未覆盖项目

## 需要现有服务器输入

当前运行入口默认依赖 `/data/xhw/czsl_repro`：

- `data/ut-zap50k/images/` 与 compositional-split-natural 的 train/val/test pair 文件、metadata；原图目录具体布局由 dataset.py 读取。
- `data/glove/glove.6B.300d.txt`；必须与 frozen manifest 指纹一致。
- `knowledge/kcc0601_v1/trusted_v1/ut-zap50k/` 的描述/标签/审阅输入。
- `knowledge/kcc0601_v1/cache_trusted_v1/ut-zap50k/` 的原始 tensor、manifest 与报告。桌面只带输入与指纹，没有假装这些 tensors 已完整备份。
- `src/KCC0601_v1/` 的冻结 baseline 文件；prepare 检查身份，新 work 执行的是本包源码。
- ViT B16 预训练模型、服务器 torch 缓存与 Python 环境。权重来源规则在 `source/models/configs.py/vit_utils.py`；归档未下载或打包这些大文件。

原 cache 的 historical manifest 记录了 population std prior；这是**父缓存出处**，不是本轮选择。`prepare.py` 会在新 work 重算 sample std prior 与 min-max epsilon，只读保留原 cache。

`tools/check_server_inputs.py` 对上述 manifest 中输入和关键 baseline 进行只读指纹检查，不能代替图片逐项完整性、CUDA、依赖导入或真实训练 smoke。

本包携带两套不同来源知识：Text K 的历史 OE/AE/OI，以及 B/F/H 逻辑银行的 paper-guided reconstruction。它们并非同一批描述。归档保留两套内容及各自 provenance，不把差异掩盖成一个统一作者知识库。

历史知识 manifest 里的 `bulk_trusted_unverified` 等状态原样保留。文件 checksum 一致只是完整性证据，不是语义真伪或无泄露的充分证明。

## 环境

已下载的真实历史服务器快照：Python3.8.18、torch1.13.1+cu117、torchvision0.14.1+cu117、numpy1.24.4、scipy1.10.1；完整版本见 `environment/pip_freeze.actual_server.txt`。

当前代码还涉及 PyYAML、yacs、Pillow、tqdm、prettytable、tensorboard、fasttext、gensim；后两者在 word_embedding_utils 顶层导入，即使选择 GloVe 也要可导入。CLIP 分支/备用文件还依赖 `clip`，pip freeze 不一定完整记录其来源。

该快照来自旧执行包，不是此次从在线服务器读取；不要直接用它覆盖现有环境，也不宣称它是经过验证的新机器完整 lockfile。优先使用已运行 CPF 的现有环境，由实际 smoke 验收。

## 与原方案仍有区别的主线接口

1. 原 §2 列 `ddm_v3.py`，当前冻结底座是既有 `ddm.py`；简化公式与真实 CPF 层融合细节不能等同。切换底座要另立对照。
2. 共享 B×300 视觉输入广播到 head 类别维，而非显式独立 B×N/M×D class-conditioned 特征。
3. object logits 为 cosine/0.05；head raw 输出 temperature1。这些尺度已冻结，不通过 TEST 搜索。
4. D/E/F 无 Feature 条件函数未在原文给出完整实现，本轮声明采用 composition＋attribute logit，额外 J0/Jtext 控制接口变化。
5. description 节点执行 raw dot＋sigmoid，但编码是 GloVe 重建知识与投影 global CLS，不是 §7.3 推荐 CLIP 编码。
6. OI/OE/AE 算子与逻辑知识为重建，不是失去的原作者数据或官方完整 LogiCZSL/Troika 结果。
7. 固定 mean/centered/lambda0.1/beta0.01/GT CE/factorized/template-only 为选定分支。主评分为原文推荐的 logit 构造，不宣称由此得到唯一严格归一化的概率联合分布。

## 运行质量约束

- epochs<37，防止未对齐 minority augmentation 绕过知识公式；30轮并不保证已经收敛。若统一扩大预算，先新协议处理augmentation与schedule。
- 旧 TEST 已观察，本轮明确作为 follow-up；仍只用 VAL 选模，不宣称 untouched holdout。
- 新工作目录至少100GiB空闲。用户最近截图 `/var/tmp` 所在分区剩余201G，`/data` 仅3.6G；输出保持 `/var/tmp`，不要移入 `/data`。
- 不删除旧实验，不终止已有 GPU 任务，不因deadline砍掉关键对照或拼用不同预算结果。
- 本次本地归档没有查询在线服务器训练状态；实际完成度以服务器 protocol、日志与结果为准。
