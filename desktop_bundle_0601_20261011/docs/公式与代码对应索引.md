## 建议阅读顺序

1. 原方案 §3/6/7/8/9。
2. `source/models/formula_model.py`：直接看输入到评分、loss、推理的主接线。
3. `source/models/full_feature.py`：factorized head，仅关注 `forward` 与 `_setup_full`；后面的 `_full_train/_full_eval` 为旧 helper，主 G/H 不调用。
4. `prepare.py`：接口记录、42组 YAML 与冻结 protocol；`legacy_prepare.py` 不是本轮独立入口。
5. `smoke_formula.py/test_formula.py`：验证实际调用而非只核对公式字符串。
6. `RUNBOOK.md`：上传、prepare、运行、查看、恢复与下载。

根目录 `formula_model.py/smoke_formula.py` 是发布源文件副本，真正训练调用的是 `source/models/formula_model.py/source/tests/smoke_formula.py`。二者在 r2 manifest 中均已冻结。

`build_release.py` 保留原始开发构建出处，依赖旧 workspace snapshot，**不是桌面包必须执行的安装步骤**。当前 `source/` 已构建完成；无需在新文件夹重跑 build。

其他数据集 YAML 与 ddm_v1/v2/v3/v4 在源码快照中保留用于出处与比较，不表示当前 UT-only prepare 支持它们或已做相应实验。
