## 0. 总体原则

研究主线仍为知识条件下的组合预测。以下是本模型的定义，而不是对真实数据分布已成立的独立性结论：

```math
P(a,o\mid x,\mathcal K)
=P(o\mid x,\mathcal K)P(a\mid o,x,\mathcal K).
```

开启 Text K 时，对象分支也读取知识，故对象项一般应写为 $`P(o\mid x,\mathcal K)`$；没有知识输入时可简写为 $`P(o\mid x)`$。

令 $`Z^o`$ 为对象 logits，$`U`$ 为未加 prior 的条件属性 logits，$`\Pi`$ 为兼容性偏置。先定义：

```math
\begin{aligned}
\widetilde U_{b,o,a}&=U_{b,o,a}+\lambda_k\Pi_{o,a},\\
\ell^o_{b,o}&=Z^o_{b,o}-\log\sum_{o'}\exp Z^o_{b,o'},\\
\ell^{a\mid o}_{b,o,a}
&=\widetilde U_{b,o,a}-\log\sum_{a'}\exp\widetilde U_{b,o,a'},\\
S_{b,o,a}&=\ell^o_{b,o}+\ell^{a\mid o}_{b,o,a}
=\log P(o,a\mid x_b,\mathcal K).
\end{aligned}
```

因此完整笛卡尔积上满足：

```math
\sum_{o,a}\exp S_{b,o,a}=1,
\qquad
\sum_a\exp S_{b,o,a}=\exp\ell^o_{b,o}.
```

第一版的 $`Z^o+U+\lambda_k\Pi`$ 可以作为能量评分，但缺少对象归一化与逐对象条件归一化，不能直接称为上述因子分解概率；尤其逐对象的属性配分项不是对所有候选相同的常数，省略会改变跨对象排序。

| 符号 | 含义／维度 |
|---|---|
| $`B,N,M,d`$ | batch、对象数、属性数、语义维度；UT 当前为 $`N=12,M=16,d=300`$ |
| $`v_o,v_a,g`$ | 对象视觉向量、属性视觉向量、投影后的全局 CLS；均为 $`B\times300`$ |
| $`W_o,W_a`$ | 原始 CPF 名称嵌入；$`N\times300`$、$`M\times300`$ |
| $`W_o^{\mathcal K},W_a^{\mathcal K}`$ | 名称与有效描述聚合的知识嵌入 |
| $`E_{oa}`$ | 全对象×属性模板嵌入；$`N\times M\times300`$ |
| $`U,\widetilde U,S`$ | 未加 prior 的条件 logits、加 prior 的条件 logits、联合 log 概率；均为 $`B\times N\times M`$ |
| $`\mathcal C_{tr},\mathcal C_{cw},\mathcal C_{ow}`$ | 训练 pairs、closed-world 合法 pairs、完整笛卡尔积 pairs |
| $`T,T_v,T_d,\gamma,\alpha`$ | 分类温度、注意力温度、描述温度、head 残差增益、描述监督锚点权重 |

缓存轴顺序为 **object→attribute**；数据集 pair 元组顺序为 **`(attribute, object)`**。完整概率先构造，再按候选表顺序抽取；训练候选限制不用于修改语义节点的完整边缘分布。

## 1. 实验主线

### 1.1 原始 CPF 分支：`A_native`

记 $`\bar u=u/\lVert u\rVert_2`$，原生分数为：

```math
\begin{aligned}
c_{b,o,a}&=\left\langle\overline{f_c(v_o,v_a)},
\overline{f_w(W_o[o],W_a[a])}\right\rangle,\\
a_{b,a}&=\langle\bar v_a,\bar W_a[a]\rangle,
\qquad o_{b,o}=\langle\bar v_o,\bar W_o[o]\rangle.
\end{aligned}
```

原生任务损失和推理评分保留为：

```math
\begin{aligned}
\mathcal L_{task}^{native}
&=\mathrm{CE}_{\mathcal C_{tr}}(c/T,y_c)
+0.6\,\mathrm{CE}(a/T,y_a)
+0.4\,\mathrm{CE}(o/T,y_o),\\
S^{native}_{b,o,a}&=c_{b,o,a}+a_{b,a}+o_{b,o},
\qquad T=0.05.
\end{aligned}
```

来源：[原生模型底座][ddm]与[模型入口的 LegacyDDM][entry]。`A_native` 不启用 Text K、prior、feature head 或语义损失，也不更换原生推理评分；本版不将旧 B／C 的任务路由继续作为新的主比较接口。

### 1.2 知识联合概率分支：`R0` 至 `Rfull`

所有 `R*` 组使用 §0 的归一化联合概率和 §9 的共享任务损失。在共同接口上独立启用 Text K、prior、coupled head、OI/OE/AE 语义约束。

`R0` 不使用知识，但已经更换概率接口、属性损失和默认视觉注意力温度；它是修订接口的无知识对照，**不是原生 CPF 的另一个名称**。`R0_native_attention` 用于进一步区分注意力温度改动，见 §10。

来源：[概率算子][math]，完整实现：

```python
def joint_log_probability(obj, conditional, prior=None, weight=0.0):
    if obj.ndim != 2 or conditional.ndim != 3 or conditional.shape[:2] != obj.shape:
        raise ValueError('Expected object BxO and conditional BxOxA')
    obj, conditional = obj.float(), conditional.float()
    if not torch.isfinite(obj).all() or not torch.isfinite(conditional).all():
        raise ValueError('Nonfinite logits')
    if prior is not None:
        if prior.shape != conditional.shape[1:] or not torch.isfinite(prior).all():
            raise ValueError('Invalid prior axes/values')
        conditional = conditional + weight * prior.float()[None]
    lo = F.log_softmax(obj, dim=-1)
    lc = F.log_softmax(conditional, dim=-1)
    return lo[:, :, None] + lc, lo, lc
```

prior 位于条件分布内。在固定 logits 下，它不能直接改变完整对象边缘 $`P(o\mid x,\mathcal K)`$，但能改变组合排序和对象条件下的属性分布；训练时通过共享参数和损失，仍可能间接改变对象分支。

## 2. 代码基线与文件位置

### 2.1 CPF 视觉底座

实际入口为 `DDM(RevisionMixin, LegacyDDM)`；[RevisionMixin][model] 继承保留的 [FormulaMixin][fallback]，底座为归档中的 [ddm.py][ddm]，视觉编码器为 ViT-B/16。修订组的方法由 `RevisionMixin` 覆盖；旧 `formula_model.py` 中的加法评分／旧节点定义不是 `R*` 的主接线。

设 $`G:\mathbb R^{768}\to\mathbb R^{300}`$ 为对象投影，$`A:\mathbb R^{900}\to\mathbb R^{300}`$ 为属性融合投影，$`V_\ell`$ 为第 $`\ell`$ 层 patch tokens，$`\widehat W_o`$ 为当前组实际读取的对象文本表：

```math
\begin{aligned}
g_b&=G(CLS_b),\\
t_{b,o}&=\mathrm{softmax}_o
\left(\mathrm{cos}(g_b,\widehat W_o[o])/T_v\right),\\
q_b&=\sum_o t_{b,o}\widehat W_o[o],\\
\omega_{b,\ell,p}(z)
&=\mathrm{softmax}_{p}
\left(\mathrm{cos}(z_b,G(V_{b,\ell,p}))/T_v\right),\\
v_{o,b}&=g_b+G\left(\sum_p\omega_{b,12,p}(q)V_{b,12,p}\right),\\
r_{b,\ell}&=G\left(\sum_p\omega_{b,\ell,p}(v_o)V_{b,\ell,p}\right),
\quad \ell\in\{9,6,3\},\\
v_{a,b}&=A([r_{b,9};r_{b,6};r_{b,3}]).
\end{aligned}
```

修订组默认 $`T_v=0.07`$。原生 helper 先归一化 query/key，再将余弦除以 $`\sqrt{300}`$，相当于上式取 $`T_v=\sqrt{300}`$；余弦范围内最大权重比仅为 $`\exp(2/\sqrt{300})\approx1.122`$。调整温度是显式模型改动，不是宣称原论文公式写错；`A_native` 保留原生设置。

来源：[修订模型][model]，完整 `formula_features`：

```python
def formula_features(self, batch):
    if not self.rev_enabled or self.rev_attention == 'native':
        return super().formula_features(batch)
    l3, l6, l9, l12, cls = self.feat_extractor(batch['img'])
    eo, ea = self._kcc_obj_embeddings(self.tot_objs), self._kcc_attr_embeddings(self.tot_attrs)
    g = self.objc_embedder(cls)
    def attend(query, keys):
        return (torch.einsum('bd,bnd->bn', F.normalize(query, dim=-1),
                              F.normalize(keys, dim=-1)) / self.rev_attention_temp).softmax(-1)
    text_weights = (F.normalize(g, dim=-1) @ F.normalize(eo, dim=-1).t() / self.rev_attention_temp).softmax(-1)
    guide = text_weights @ eo
    vo = g + self.objc_embedder((l12 * attend(guide, self.objc_embedder(l12))[:, :, None]).sum(1))
    parts = [self.objc_embedder((layer * attend(vo, self.objc_embedder(layer))[:, :, None]).sum(1))
             for layer in (l9, l6, l3)]
    return vo, self.attrc_embedder(torch.cat(parts, -1)), g, eo, ea
```

共享余弦分类器如下。来源：[ddm.py][ddm]，完整核心类：

```python
class CosineClassifier(nn.Module):
    def __init__(self, temp=0.05):
        super(CosineClassifier, self).__init__()
        self.temp = temp

    def forward(self, img, concept, scale=True):
        """
        img: (bs, emb_dim)
        concept: (n_class, emb_dim)
        """
        img_norm = F.normalize(img, dim=-1)
        concept_norm = F.normalize(concept, dim=-1)
        pred = torch.matmul(img_norm, concept_norm.transpose(0, 1))
        if scale:
            pred = pred / self.temp
        return pred
```

## 3. 三条知识注入路径

### 3.1 路径 1：文本知识嵌入

描述句子使用已登录 GloVe token 均值并归一化：

```math
E(s)=\mathrm{norm}\left(
\frac{1}{|\mathcal T(s)|}\sum_{t\in\mathcal T(s)}e(t)
\right).
```

名称不重新分词编码，而复用 CPF 初始化的原始名称向量后归一化。令 $`v_0`$ 为名称，$`v_j=E(d_j)`$，$`m_0=1`$，描述 mask 为 $`m_j`$：

```math
\begin{aligned}
W^{\mathcal K}_{mean}
&=\mathrm{norm}\left(\frac{\sum_{j=0}^{L}m_jv_j}
{\sum_{j=0}^{L}m_j}\right),\\
\alpha_j
&=\frac{m_j\exp(\langle v_0,v_j\rangle/T_{agg})}
{\sum_{k=0}^{L}m_k\exp(\langle v_0,v_k\rangle/T_{agg})},\\
W^{\mathcal K}_{attn}&=\mathrm{norm}\left(\sum_{j=0}^{L}\alpha_jv_j\right),
\qquad T_{agg}=0.5.
\end{aligned}
```

默认 mean；attention 是已实现的 Text K 聚合消融。来源：[数学算子][math]，完整实现：

```python
def aggregate_descriptions(names, descriptions, mask, method='mean', temperature=0.5):
    names = F.normalize(names.float(), dim=-1)
    values = torch.cat((names[:, None], F.normalize(descriptions.float(), dim=-1)), dim=1)
    valid = torch.cat((torch.ones(len(names), 1, dtype=torch.bool, device=mask.device), mask.bool()), dim=1)
    if method == 'mean':
        weights = valid.float() / valid.sum(-1, keepdim=True)
    elif method == 'attention':
        if temperature <= 0:
            raise ValueError('Invalid aggregation temperature')
        z = torch.einsum('cd,ckd->ck', names, values) / temperature
        weights = z.masked_fill(~valid, -torch.inf).softmax(-1)
    else:
        raise ValueError('Unknown aggregation')
    pooled = (values * weights[:, :, None]).sum(1)
    if (pooled.norm(dim=-1) < 1e-8).any():
        raise ValueError('Aggregation collapsed to zero')
    return F.normalize(pooled, dim=-1)
```

全部描述被删除时，Text K 退化为归一化名称；语义分支也显式回退到名称，见 §4.3。句子整体 OOV／零向量属于资产错误，会报错；不将它隐式伪装为正常描述，也不沿用第一版的 80% token 覆盖阈值。

### 3.2 路径 2：compatibility calibration

centered prior 的主实现使用**总体标准差**：

```math
\begin{aligned}
\mu_K&=\frac{1}{NM}\sum_{o,a}K_{o,a},\\
\sigma_K&=\sqrt{\frac{1}{NM}\sum_{o,a}(K_{o,a}-\mu_K)^2},\\
\Pi^{centered}_{o,a}&=\frac{K_{o,a}-\mu_K}{\sigma_K+10^{-8}}.
\end{aligned}
```

备选 clamped-log 为：

```math
\begin{aligned}
L_{o,a}&=\log\bigl(\max(\epsilon_K,\min(1,K_{o,a}))\bigr),\\
\Pi^{log}_{o,a}&=L_{o,a}-\frac1M\sum_{a'}L_{o,a'},
\qquad \epsilon_K=10^{-3}.
\end{aligned}
```

来源：[数学算子][math]，完整实现：

```python
def make_prior(k, mode='centered', eps=1e-8, floor=1e-3):
    k = k.float()
    if k.ndim != 2 or not torch.isfinite(k).all():
        raise ValueError('Prior requires finite OxA matrix')
    if mode == 'centered':
        # Population std is well-defined for a one-element matrix.
        return (k - k.mean()) / (k.std(unbiased=False) + eps)
    if mode == 'clamped_log':
        if not 0 < floor < 1 or (k < 0).any() or (k > 1).any():
            raise ValueError('clamped_log requires K in [0,1], floor in (0,1)')
        value = k.clamp(min=floor, max=1).log()
        return value - value.mean(dim=-1, keepdim=True)
    raise ValueError('Unknown prior transform: ' + mode)
```

默认固定 $`\lambda_k=0.1`$。学习权重分支使用有界重参数化：

```math
\lambda_k=\sigma(\eta),
\qquad \eta_0=\log\frac{0.1}{0.9}.
```

来源：[修订模型初始化与评分][model]的局部摘录：

```python
if bool(cfg.MODEL.rev_learn_lambda):
    if not self.kcc_calib or not 0 < self.kcc_lambda < 1:
        raise ValueError('Learnable lambda requires active prior and initial lambda in (0,1)')
    self.rev_lambda_raw = nn.Parameter(torch.tensor(math.log(self.kcc_lambda / (1-self.kcc_lambda))))

weight = self.rev_lambda_raw.sigmoid() if hasattr(self, 'rev_lambda_raw') else self.kcc_lambda
```

在 [train.py][train] 中 `rev_lambda_raw` 使用独立优化器参数组、`weight_decay=0`，避免对 $`\eta`$ 的权重衰减人为将 $`\lambda_k`$ 拉向 0.5。此处是算子／接线说明，不是训练配置表。

常数 K 的 centered prior 为零；clamped-log 每行减均值不会改变条件 softmax。一般地，向条件 logits 加任意仅依赖对象的行常数，也不会改变本版联合概率。

### 3.3 路径 3：知识条件 head

知识 head 输出图像相关的 $`B\times N\times M`$ 耦合分数，作为**残差**加入保留的 CPF 条件分支：

```math
U_{b,o,a}=Z^{comp}_{b,o,a}+Z^{attr}_{b,a}
+\gamma H_{b,o,a},\qquad \gamma=0.1.
```

不是第一版的 head-only 替换，也不是独立属性项＋对象项＋静态 pair 偏置。三路在同一归一化概率模型中共同工作；head 全部算子见 §6。

### 4.2 构建对象知识 $`W_o^{\mathcal K}`$

```math
W_o^{\mathcal K}[o]
=\mathrm{Agg}(\mathrm{norm}(W_o[o]),d^o_{o,1},\ldots,d^o_{o,L};m^o),
\qquad L\in\{1,3,5\}.
```

对象、属性与父类别描述共享编码规则。来源：[资产构建器][assets]，`encode_assets` 内部的实际 `encode` 函数；`vectors` 为已按需读取的 GloVe 字典，`oov` 用于记录缺失 token：

```python
def encode(sentence):
    tokens = module.description_tokens(sentence)
    missing = [t for t in tokens if t not in vectors]
    oov[sentence] = missing
    retained = [vectors[t] for t in tokens if t in vectors]
    if not retained:
        raise ValueError('Entire sentence is OOV: ' + sentence)
    value = torch.stack(retained).mean(0)
    if value.norm() < 1e-8:
        raise ValueError('Zero description embedding')
    return F.normalize(value, dim=0)
```

描述 regex 分词、OOV 跳过和均值计算由此实现；GloVe SHA256 必须等于构建器声明的已审计文件。主组取同一固定语料的前 3 条，不依据验证结果挑选句子。

### 4.3 构建属性知识 $`W_a^{\mathcal K}`$

```math
W_a^{\mathcal K}[a]
=\mathrm{Agg}(\mathrm{norm}(W_a[a]),d^a_{a,1},\ldots,d^a_{a,L};m^a).
```

对象／属性使用同一聚合函数，随后处理语义银行的空描述类别。来源：[资产构建器][assets]，`materialize` 中的局部摘录；`dest` 为已复制好的新缓存目录，`bank/masks/evidence` 来自当前控制组：

### 4.4 构建全对象×属性 pair 知识

三种固定模板与第一版一致：

```text
a {object} that is {attribute}
the {attribute} {object}
{attribute} appearance of {object}
```

```math
E_{oa}=\mathrm{norm}\left(
\frac13\sum_{j=1}^{3}E(\mathrm{template}_j(o,a))
\right).
```

修订资产构建器复用原缓存的 pair blocks，不为本版另造 pair 描述。下面为 [原模板构建器][builder] 的实际局部循环；`normalize` 是该文件的末轴单位化 helper，`token_maps` 已应用原 CPF alias，`stage` 为构建中的缓存目录：

```python
attr_sums = torch.stack([torch.stack([glove[t] for t in token_maps["attribute"][a]]).sum(0) for a in attrs])
attr_counts = torch.tensor([len(token_maps["attribute"][a]) for a in attrs], dtype=torch.float32)
raw_k = torch.empty(len(objs), len(attrs))
for oi, obj in enumerate(objs):
    obj_tokens = token_maps["object"][obj]
    obj_sum = torch.stack([glove[t] for t in obj_tokens]).sum(0)
    sentences = []
    for fillers in FILLERS:
        filler_sum = torch.stack([glove[t] for t in fillers]).sum(0)
        means = (attr_sums + obj_sum + filler_sum) / (attr_counts + len(obj_tokens) + len(fillers)).unsqueeze(1)
        sentences.append(normalize(means))
    pair_embeddings = normalize(torch.stack(sentences).mean(0))
    proto = normalize(W_o_K[oi].unsqueeze(0) + W_a_K)
    raw_k[oi] = (pair_embeddings * proto).sum(-1)
    torch.save(pair_embeddings, stage / "W_ao_K" / ("obj_{:05d}.pt".format(oi)))
```

`FILLERS` 为 `(("a", "that", "is"), ("the",), ("appearance", "of"))`；GloVe 均值不编码词序，循环对应三个模板的词袋均值。全部 $`N\times M`$ 组合统一构建，不按 seen/unseen 换模板。**pair-level LLM 描述增强未实现**；`Rfull` 是 template-only 条件。

### 4.5 构建文本兼容性 $`K_{oa}`$

```math
\begin{aligned}
R_{oa}&=\mathrm{cos}\left(E_{oa},
\mathrm{norm}(W_o^{\mathcal K}[o]+W_a^{\mathcal K}[a])\right),\\
K^{text}_{oa}&=\frac{R_{oa}-\min_{o',a'}R_{o'a'}}
{\max_{o',a'}R_{o'a'}-\min_{o',a'}R_{o'a'}+10^{-8}}.
\end{aligned}
```

归一化前除以 2 不影响非零向量的方向。K 是文本相似性派生的连续偏置，**不是经过验证的可行性概率，也不是不可行组合的硬 mask**。

来源：[资产构建器][assets]，`materialize` 的实际局部摘录：

```python
eo = torch.load(dest / 'W_o_K.pt', weights_only=True)
ea = torch.load(dest / 'W_a_K.pt', weights_only=True)

similarity = F.cosine_similarity(ep, F.normalize(eo[:,None] + ea[None], dim=-1), dim=-1)
k = (similarity-similarity.min()) / (similarity.max()-similarity.min()+1e-8)
if fixed_k is not None:
    k = fixed_k.clone()
```

主 K 使用默认 mean、3 描述构建。描述条数、删除、错配及 attention 聚合的对照均固定该主 K；它们改变 Text K／描述银行，不同步改变 prior，避免将语料扰动与 prior 重构混为一个因素。

外部 feasibility 已提供校验与混合接口：

```math
K^{mixed}_{oa}=
\begin{cases}
0.5K^{text}_{oa}+0.5K^{LLM}_{oa},&\text{外部分数已提供},\\
K^{text}_{oa},&\text{外部分数缺失}.
\end{cases}
```

LLM-only 必须为全笛卡尔积提供分数；unknown 不等于 infeasible。实际接口要求标签与 `[object, attribute]` 轴完全一致，分数有限且在 `[0,1]`，记录 generator／prompt／生成时间，并显式排除 split membership 和 VAL／TEST 结果泄漏。**有效 LLM 分数资产尚未提供，接口不等于实验已完成**。

### 5.2 无 Feature K 的条件评分与 calibration

记 $`\widehat W_o,\widehat W_a`$ 为当前组读取的名称／知识表。未开启 feature head 时：

```math
\begin{aligned}
Z^o_{b,o}&=\mathrm{cos}(v_{o,b},\widehat W_o[o])/T,\\
Z^{attr}_{b,a}&=\mathrm{cos}(v_{a,b},\widehat W_a[a])/T,\\
Z^{comp}_{b,o,a}&=\mathrm{cos}\left(f_c(v_{o,b},v_{a,b}),
f_w([\widehat W_o[o];\widehat W_a[a]])\right)/T,\\
U^{MVP}_{b,o,a}&=Z^{comp}_{b,o,a}+Z^{attr}_{b,a},
\qquad T=0.05.
\end{aligned}
```

word composer 为 600→900→600→300，中间 BatchNorm＋ReLU；visual composer 为 600→300→300，使用输入 Dropout 与隐藏 ReLU。文本和视觉拼接均为 **object、attribute** 顺序。

所有修订组保留同一原生 composition 分支；feature 开启时只追加残差。来源：[修订模型][model]，完整 `formula_logits`，同时给出 MVP 和完整模型接线：

```python
def formula_logits(self, batch, objs, attrs):
    if not self.rev_enabled:
        return super().formula_logits(batch, objs, attrs)
    go, ga = self.tot_objs.repeat_interleave(self.num_attrs), self.tot_attrs.repeat(self.num_objs)
    # Same native composition branch retained for every revised group.
    words = self.compose(torch.cat((self._kcc_obj_embeddings(go), self._kcc_attr_embeddings(ga)), -1))
    vo, va, g, eo, ea = self.formula_features(batch)
    obj = self.classifier(vo, eo, scale=True)
    attr = self.classifier(va, ea, scale=True)
    comp = self.classifier(self.compose_visual(vo, va), words, scale=True)
    base = comp.reshape(-1, self.num_objs, self.num_attrs) + attr[:, None]
    delta = torch.zeros_like(base)
    if self.full_enabled:
        pair = self.full_pair_embeddings if self.full_use_pair else None
        delta = self.rev_gain * self.full_head(va, vo, ea, eo, pair)
    u = base + delta
    weight = self.rev_lambda_raw.sigmoid() if hasattr(self, 'rev_lambda_raw') else self.kcc_lambda
    score, lo, lc = joint_log_probability(obj, u, self.rev_prior if self.kcc_calib else None, weight)
    return {'obj': obj, 'attr': attr, 'comp': comp, 'conditional': u,
            'score': score, 'log_obj': lo, 'log_conditional': lc, 'delta': delta, 'image_feat': g}
```

返回值 `conditional` 是 **未加 prior 的 U**；`log_conditional` 已含 prior 和逐对象归一化；`score` 是联合 log 概率。属性 NLL 必须读取后两者之一，不能误用 `conditional` 并漏掉 prior。

## 6. Phase 3：特征层 knowledge-conditioned module

### 6.1 Coupled residual logit head

本版替换第一版可加分离的 factorized head，使视觉与对象、属性在同一项中交互。令秩 $`r=128`$，所有投影无 bias，投影后单位化：

```math
\begin{aligned}
q_b&=\mathrm{norm}(Q[v_{o,b};v_{a,b}]),
&q^p_b&=\mathrm{norm}(Q_p[v_{o,b};v_{a,b}]),\\
k^o_o&=\mathrm{norm}(K_o\widehat W_o[o]),
&k^a_a&=\mathrm{norm}(K_a\widehat W_a[a]),\\
k^p_{oa}&=\mathrm{norm}(K_pE_{oa}).
\end{aligned}
```

```math
\begin{aligned}
H_{b,o,a}
&=\frac{1}{T}\left(
\sqrt r\sum_{j=1}^{r}q_{b,j}k^o_{o,j}k^a_{a,j}
+\langle q^p_b,k^p_{oa}\rangle\right),\\
\Delta_{b,o,a}&=\gamma H_{b,o,a},\\
U_{b,o,a}&=Z^{comp}_{b,o,a}+Z^{attr}_{b,a}+\Delta_{b,o,a},
\qquad T=0.05,\quad\gamma=0.1.
\end{aligned}
```

无 pair head 分支去掉内积第二项；第一项仍是图像×对象×属性交互。head 输出先按分类温度缩放，再乘一次残差增益；prior 另在 §0 的条件归一化之前加入。

来源：[revision_math.py][math]，完整核心类：

```python
class CoupledHead(nn.Module):
    """Image-dependent object/attribute interaction; no BxOxAxD expansion."""
    def __init__(self, dim=300, rank=128, temperature=0.05, chunk=32, static=False):
        super().__init__()
        if rank < 1 or chunk < 1 or temperature <= 0:
            raise ValueError('Invalid head parameters')
        self.q = nn.Linear(dim * 2, rank, bias=False)
        self.ko = nn.Linear(dim, rank, bias=False)
        self.ka = nn.Linear(dim, rank, bias=False)
        self.qp = nn.Linear(dim * 2, rank, bias=False)
        self.kp = nn.Linear(dim, rank, bias=False)
        self.rank, self.temperature, self.chunk, self.static = rank, temperature, chunk, static

    def forward(self, va, vo, ea, eo, ep=None):
        visual = torch.cat((vo, va), -1)
        q, qp = F.normalize(self.q(visual), dim=-1), F.normalize(self.qp(visual), dim=-1)
        if self.static:
            q, qp = torch.ones_like(q) / math.sqrt(self.rank), torch.ones_like(qp) / math.sqrt(self.rank)
        ko, ka = F.normalize(self.ko(eo), dim=-1), F.normalize(self.ka(ea), dim=-1)
        pieces = []
        for start in range(0, len(eo), self.chunk):
            stop = min(start + self.chunk, len(eo))
            z = math.sqrt(self.rank) * torch.einsum('br,or,ar->boa', q, ko[start:stop], ka)
            if ep is not None:
                kp = F.normalize(self.kp(ep[start:stop]), dim=-1)
                z = z + torch.einsum('br,oar->boa', qp, kp)
            pieces.append(z / self.temperature)
        return torch.cat(pieces, 1)
```

### 6.2 Chunk-wise scoring

已实现 head 的 object chunk：每次至多 32 个对象，构造 $`B\times N_{chunk}\times M`$ 分数，最后沿对象轴拼接。不将图像特征展开为 $`B\times N\times M\times d`$。

**边界**：完整输出仍为 $`B\times N\times M`$，原生 word composer 也仍处理完整 $`NM`$ 文本组合；pair 投影有 chunk×属性×rank 的中间张量。因此不能据 head 的 chunk 声称已完成 C-GQA 端到端显存优化或验证。

### 6.3 Naive pair-wise MLP

未采用全笛卡尔积视觉／文本展开后拼接的 naive pair-wise MLP。当前实际 head 为 §6.1 的耦合低秩残差；保留的旧 `full_feature.py` 负责兼容初始化与 pair blocks 读取，其旧 head 随后被 `CoupledHead` 替换，不进入 `Rfeature/Rfull` 主评分。

### 6.4 Full Model 变体

`Rfeature`：Text K＋prior＋coupled residual head；`Rfull`：前者＋三类语义约束。二者均保留 CPF composition／attribute 基础评分，并使用归一化联合概率。

`Rfull_static_head` 将 $`q_b,q_b^p`$ 设为 $`\mathbf1/\sqrt r`$，只移除新增 head 的图像条件性；原生视觉分支仍工作。它保留参数定义，但 query 参数不再有效参与预测，不能宣称是严格有效容量匹配的对照。

### 6.5 Full Model 接口检查

检查 head 对图像／对象／属性的真实耦合、pair 开关、chunk 输出一致、残差增益只乘一次、原生 composition 保留、任务／AE 到 head 的梯度和初始化随机状态隔离。新 head 在 `fork_rng` 内用 `700000 + run_seed` 初始化，不消耗原生层／sampler 的外部随机流。

`full_delta_rms` 统计实际 $`\Delta=\gamma H`$ 的 RMS，不是整个 U 的 RMS。完整 CPU 与真实图像 smoke 检查位置见 §12；检查通过本身不等于新模型精度已经验证。

## 7. Logic loss adapter

### 7.1 概念节点与形状

本版“Logic”指知识层级／描述语义的**类别概率一致性约束**。不将描述相似性 sigmoid 解释为每条物理命题的独立真值，也不将 softmax 互斥类别事件用 max 合成为父节点。

| 银行 | 形状／语义 |
|---|---|
| OE、AE | $`N\times L\times300`$、$`M\times L\times300`$；每类 $`L=1,3,5`$ 个描述槽 |
| OE／AE mask | $`N\times L`$、$`M\times L`$；至少一个有效槽，全部删除时用名称回退 |
| parent embeddings | $`3\times8\times300`$；各层有效父类别数 8、5、3，剩余为零 padding |
| parent mask | $`3\times8`$，每层有效位置连续排列 |
| parent ids | $`3\times N`$；每层每个对象恰属于一个父类别 |

三层为人工重建的**标签 taxonomy**：细层 8 类→原 5 类→粗层 3 类，穷尽、互斥且嵌套。depth=1 使用细层 8 类；depth=2 使用 8＋5 类；depth=3 使用全部三层。不是将同一层重复三次，也不是加入全对象只有一个父节点的平凡根。

来源：[资产构建器][assets]，`hierarchy` 的实际分组核心：


这一 taxonomy 不声称是普遍成立的视觉事实；父名称与描述向量同样为冻结 GloVe300 编码。

### 7.2 节点分数构造

分类节点由**完整、未限制训练候选**的归一化联合概率得到：

```math
\begin{aligned}
p^o_{b,o}&=\exp\ell^o_{b,o},\\
p^a_{b,a}&=\sum_o\exp S_{b,o,a},\\
p^{pair}_{b,o,a}&=\exp S_{b,o,a}.
\end{aligned}
```

pair 是联合类别概率，不是 `sigmoid(S)`，目前没有新增第四个 pair 规则。父分类器在每一层的有效父类别内 softmax：

```math
q^h_{b,\ell,h}
=\mathrm{softmax}_{h\in\mathcal H_\ell}
\left(\mathrm{cos}(g_b,H_{\ell,h})/T_d\right).
```

OE／AE 使用每类有效描述余弦的 masked mean，再在**对象／属性类别轴** softmax：

```math
\begin{aligned}
z^{desc}_{b,c}
&=\frac{\sum_j m_{c,j}\mathrm{cos}(g_b,D_{c,j})}
{\sum_jm_{c,j}},\\
q^{desc}_{b,c}&=\mathrm{softmax}_{c}(z^{desc}_{b,c}/T_d),
\qquad T_d=0.1.
\end{aligned}
```

来源：[概率与描述算子][math]，完整函数：

```python
def descriptor_logprob(image, descriptions, mask, temperature=0.1):
    if temperature <= 0 or not math.isfinite(temperature):
        raise ValueError('Invalid description temperature')
    if mask.shape != descriptions.shape[:2] or not mask.any(-1).all():
        raise ValueError('Every category requires at least one active descriptor')
    cosine = torch.einsum('bd,ckd->bck', F.normalize(image.float(), dim=-1),
                          F.normalize(descriptions.float(), dim=-1))
    # Masked mean; removed slots contribute neither score nor denominator.
    z = (cosine * mask[None]).sum(-1) / mask.sum(-1)[None]
    return F.log_softmax(z / temperature, dim=-1)
```

描述被删除时不参与分子／分母；Text K attention 消融不改变这里的 masked mean 算子。OE／AE 都读取共享的投影全局 CLS `g`，并非独立冻结的 CLIP teacher；这些分数是相似性派生的类别分布，不是描述事实真值。

### 7.3 OI／OE／AE 语义损失

对分布 P、Q 定义 $`M=(P+Q)/2`$，使用自然对数：

```math
\mathrm{JS}(P,Q)
=\frac12\sum_cP_c\log\frac{P_c}{M_c}
+\frac12\sum_cQ_c\log\frac{Q_c}{M_c}.
```

每个样本先在类别轴求和，再对 batch 求均值；相同分布为零，取值不超过 $`\log2`$。两侧均保留梯度，不 `detach`。来源：[数学算子][math]：

```python
def js_divergence(logp, logq):
    # Mean over samples, sum over categorical events. No detached branch.
    if logp.shape != logq.shape:
        raise ValueError('JS probability axes differ')
    logm = torch.logaddexp(logp.float(), logq.float()) - math.log(2)
    return (0.5 * (logp.exp() * (logp - logm) +
                   logq.exp() * (logq - logm)).sum(-1)).mean()
```

设 $`\mathrm{Child}_\ell(h)`$ 为该层父类别对应的对象集合。因标签事件互斥，父概率应为 children 的**和**：

```math
\begin{aligned}
\widetilde p^h_{b,\ell,h}
&=\sum_{o\in\mathrm{Child}_\ell(h)}p^o_{b,o},\\
\mathcal L_{oi}
&=\frac1D\sum_{\ell=1}^{D}
\mathrm{JS}(\widetilde p^h_\ell,q^h_\ell),\\
\mathcal L_{oe}
&=\mathrm{JS}(p^o,q^{oe})+\alpha\,\mathrm{NLL}(\log q^{oe},y_o),\\
\mathcal L_{ae}
&=\mathrm{JS}(p^a,q^{ae})+\alpha\,\mathrm{NLL}(\log q^{ae},y_a),\\
\mathcal L_{logic}&=\mathcal L_{oi}+\mathcal L_{oe}+\mathcal L_{ae},
\qquad\alpha=0.1.
\end{aligned}
```

OE／AE 的 TRAIN primitive 标签锚点避免只追求两路分布彼此一致；它不构成句子级视觉真值监督，也不保证训练永不塌缩。OI 在选定层之间取均值，避免深度增加仅使损失线性放大。

来源：[修订模型][model]，完整 `revision_logic`：

```python
def revision_logic(self, logits, batch):
    lo = logits['log_obj']
    la = torch.logsumexp(logits['score'], dim=1)
    terms = []
    for level in range(self.rev_depth):
        ids, valid = self.rev_parent_ids[level], self.rev_parent_mask[level]
        ph = F.log_softmax(F.normalize(logits['image_feat'], dim=-1) @
                          F.normalize(self.rev_parent[level, valid], dim=-1).t() / self.rev_desc_temp, -1)
        # Categorical object labels are disjoint events: P(parent)=SUM children.
        child = torch.stack([torch.logsumexp(lo[:, ids == j], -1) for j in range(int(valid.sum()))], -1)
        terms.append(js_divergence(child, ph))
    oe = descriptor_logprob(logits['image_feat'], self.rev_oe, self.rev_oe_mask, self.rev_desc_temp)
    ae = descriptor_logprob(logits['image_feat'], self.rev_ae, self.rev_ae_mask, self.rev_desc_temp)
    oi = torch.stack(terms).mean()
    le = js_divergence(lo, oe) + self.rev_anchor * F.nll_loss(oe, batch['obj'])
    lae = js_divergence(la, ae) + self.rev_anchor * F.nll_loss(ae, batch['attr'])
    raw = oi + le + lae
    weight = beta_at(self.rev_epoch, self.bf_logic.beta, self.rev_delay, self.rev_ramp)
    return {'loss_oi': oi, 'loss_oe': le, 'loss_ae': lae, 'loss_logic_raw': raw,
            'loss_logic_weighted': weight * raw}, {'object': lo.exp(), 'attribute': la.exp(),
            'pair': logits['score'].exp(), 'oe': oe.exp(), 'ae': ae.exp()}
```

第一版的训练候选 `-inf` mask、pair sigmoid、父节点 max、单向 p-mean implication 均不在该函数中使用。旧文件／初始化中保留 `bf_logic_q` 不代表修订损失仍消费 q。

### 7.4 逻辑项权重

```math
\begin{aligned}
\mathcal L_{total}(t)&=\mathcal L_{task}+\beta(t)\mathcal L_{logic},\\
\beta(t)&=
\begin{cases}
0,&t\le d_{delay},\\
\beta_{max}\min\left(1,\dfrac{t-d_{delay}}{\max(1,d_{ramp})}\right),&t>d_{delay}.
\end{cases}
\end{aligned}
```

主组固定 $`\beta=0.01`$，即 delay=0、ramp=0；delayed 分支 delay=2、ramp=3，绝对 epoch 1／2 为零，3／4／5 的权重为 $`0.01/3`$、$`0.02/3`$、$`0.01`$，之后固定。

来源：[数学算子][math]，完整函数：

```python
def beta_at(epoch, maximum, delay=0, ramp=0):
    if epoch < 1 or maximum < 0 or delay < 0 or ramp < 0:
        raise ValueError('Invalid schedule')
    if epoch <= delay:
        return 0.0
    return maximum * min(1.0, (epoch - delay) / max(1, ramp))
```

`train.py` 在每个绝对 epoch 调用 `model.set_epoch(epoch)`；恢复训练不重置 warmup。权重只在 `revision_logic` 乘一次，任务函数不再乘一次；零权重 warmup 仍计算 raw loss 供检查，不将“乘零”误报为逻辑代码没有运行。

## 8. Attribute loss 的定义

### 8.1 从条件评分到属性 logits

U 的形状为 $`B\times N\times M`$，属性标签为 B。默认属性项先取 GT-object 切片，但输入为**已经加入 prior 的条件 log 概率**，不是第一版的 head raw U。

对象 logits 对同一对象切片而言是常数，无需加入条件属性 NLL；prior 随属性变化，不能漏掉。

### 8.2 GT-object conditioned attribute NLL

```math
\begin{aligned}
\mathcal L_{att}^{GT}
&=-\frac1B\sum_b\ell^{a\mid o}_{b,o_b,a_b}\\
&=\frac1B\sum_b\left[
-\widetilde U_{b,o_b,a_b}
+\log\sum_{a'}\exp\widetilde U_{b,o_b,a'}\right].
\end{aligned}
```

来源：[修订训练接线][model]，局部摘录：

```python
rows = torch.arange(len(batch['obj']), device=selected.device)
attribute = logits['log_conditional'][rows, batch['obj']] if self.rev_attr_mode == 'gt' else torch.logsumexp(logits['score'], 1)
lp, lo, la = F.cross_entropy(selected, batch['pair']), F.nll_loss(logits['log_obj'], batch['obj']), F.nll_loss(attribute, batch['attr'])
```

其中 `selected` 为按训练 pair 顺序抽取的联合 log 概率。默认 GT-object 是训练监督；推理不提供 GT object。诊断中的“给定 GT object 属性准确率”必须标为 oracle，不能代替实际组合预测。

### 8.3 Object-marginalized attribute NLL

已实现备选真实对象边缘属性分布：

```math
\begin{aligned}
\ell^a_{b,a}
&=\log\sum_oP(o\mid x_b,\mathcal K)P(a\mid o,x_b,\mathcal K)
=\mathrm{logsumexp}_{o}S_{b,o,a},\\
\mathcal L_{att}^{marginal}&=-\frac1B\sum_b\ell^a_{b,a_b}.
\end{aligned}
```

`Rfull_marginal_attr` 用该项替换 GT-object 属性项。它不是 $`\mathrm{CE}(\mathrm{logsumexp}_oU,y_a)`$：后者遗漏对象后验和每行条件配分项，不能等同于对象概率加权的 marginalization。代码见 §8.2 与 §9.1。

## 9. 训练与推理框架

### 9.1 核心损失接线

先按训练 pair 顺序从完整 S 取分数。pair CE 对训练候选**再次归一化**，相当于给定训练候选集合的负 log 概率：

```math
\begin{aligned}
P_{\mathcal C_{tr}}(o,a\mid x_b)
&=\frac{\exp S_{b,o,a}}
{\sum_{(a',o')\in\mathcal C_{tr}}\exp S_{b,o',a'}},
\quad(a,o)\in\mathcal C_{tr},\\
\mathcal L_{com}&=\mathrm{CE}(S^{tr},y_c),\\
\mathcal L_{obj}&=-\frac1B\sum_b\ell^o_{b,o_b},\\
\mathcal L_{task}&=\mathcal L_{com}+0.4\mathcal L_{obj}+0.6\mathcal L_{att},\\
\mathcal L_{total}&=\mathcal L_{task}+\beta(t)\mathcal L_{logic}.
\end{aligned}
```

训练 pair 限制不改变语义约束使用的完整 $`p^o,p^a`$。所有 `R*` 的对象／属性分类使用全 primitive 轴；只有 pair CE 使用训练候选。

来源：[修订模型][model]，完整 `formula_train_terms`：

```python
def formula_train_terms(self, batch, return_details=False):
    if not self.rev_enabled:
        return super().formula_train_terms(batch, return_details)
    logits = self.formula_logits(batch, self.train_objs, self.train_attrs)
    selected = logits['score'][:, self.train_objs, self.train_attrs]
    rows = torch.arange(len(batch['obj']), device=selected.device)
    attribute = logits['log_conditional'][rows, batch['obj']] if self.rev_attr_mode == 'gt' else torch.logsumexp(logits['score'], 1)
    lp, lo, la = F.cross_entropy(selected, batch['pair']), F.nll_loss(logits['log_obj'], batch['obj']), F.nll_loss(attribute, batch['attr'])
    task = lp + 0.4 * lo + 0.6 * la
    zero = task.new_zeros(())
    terms = {k: zero for k in ('loss_oi','loss_oe','loss_ae','loss_logic_raw','loss_logic_weighted')}
    nodes = None
    if self.bf_logic.enabled:
        terms, nodes = self.revision_logic(logits, batch)
    out = dict(loss_total=task+terms['loss_logic_weighted'], loss_cpf=task, loss_composition=lp,
               loss_object=lo, loss_conditional_attr=la, full_delta_rms=logits['delta'].square().mean().sqrt(),
               acc_pair=(selected.argmax(-1)==batch['pair']).float().mean(),
               acc_obj=(logits['obj'].argmax(-1)==batch['obj']).float().mean(),
               acc_attr=(attribute.argmax(-1)==batch['attr']).float().mean())
    out.update(terms)
    return (out, logits, nodes) if return_details else out
```

模型分支路由仍由 [FormulaMixin][fallback] 的以下实际方法提供；新版修订方法通过继承覆盖被调用：

```python
def train_forward(self, batch):
    if not self.formula_joint and not self.bf_logic.enabled:
        return super().train_forward(batch)  # exact original A/C branch
    return self.formula_train_terms(batch)
```

注释 A/C 为保留的历史命名；本版仅允许无知识 `A_native` 关闭 revision。`rev_enabled=False` 同时启用任何知识／logic／feature／联合公式开关会报错，避免旧错误配置静默运行。当前修订协议排除原生 minority augmentation，不能声称已补全 augmentation 下的新公式。

### 9.2 推理评分与候选集合

```math
S^{eval}_{b,k}=S_{b,o_k,a_k},
\qquad k^*=\arg\max_k S^{eval}_{b,k},
\qquad\hat c_b=(a_{k^*},o_{k^*}).
```

closed-world 读取 split 的合法 pairs，open-world 读取全属性×对象。评分网格按 object-major 存储，候选轴按数据集顺序取分数；候选概率若需要可再在当前集合内 softmax，argmax 本身不需要。

来源：[共享推理路由][fallback]，完整 `val_forward`；调用的 `self.formula_logits` 对 `R*` 为 §5.2 的修订方法：

```python
def val_forward(self, batch):
    if not self.formula_joint:
        return super().val_forward(batch)  # A/B/C: original CPF inference
    logits = self.formula_logits(batch, self.val_objs, self.val_attrs)
    pred = logits['score'][:, self.val_objs, self.val_attrs]
    if pred.size(1) != len(self.val_pairs):
        raise ValueError('Evaluation candidate order/count mismatch')
    return {'pred': pred, 'scores': {p: pred[:, i] for i, p in enumerate(self.val_pairs)}}
```

训练／推理共享评分定义，但 Dropout 与 BatchNorm 遵循实际 train/eval 模式；数值身份检查必须在相同模式与相同输入下进行。VAL 选 checkpoint 与后处理参数，TEST 不参与选择；旧 TEST 已被查看过，后续复验不能包装成全新未见 holdout。

描述删除算子如下，来源：[revision_math.py][math]。相同随机顺序取更长删除前缀，使 10／30／50% 在相同类数与条数下嵌套：

```python
def deletion_mask(n_classes, n_desc, fraction, seed):
    if not 0 <= fraction <= 1:
        raise ValueError('Deletion fraction outside [0,1]')
    order = torch.randperm(n_classes * n_desc, generator=torch.Generator().manual_seed(seed))
    mask = torch.ones(n_classes * n_desc, dtype=torch.bool)
    mask[order[:int(round(n_classes * n_desc * fraction))]] = False
    return mask.reshape(n_classes, n_desc)
```

seen/unseen bias 仅在 VAL 的预先固定网格 `[-5,5]`、步长 0.05 上选取：

```math
S^{\delta}_{b,c}=S_{b,c}+\delta\,\mathbf1[c\notin\mathcal C_{tr}],
\qquad\delta^*=\arg\max_{\delta}\mathrm{HM}_{VAL}(S^\delta).
```

平局选绝对值更小、再选数值更小的 bias；CW／OW 分别冻结后用于 TEST，不在 TEST 重选。对象单独错误／属性单独错误／二者错误是统计类别，不能自动归因为“知识错误”或“视觉错误”。

固定已训练权重关闭 prior 时，必须重新归一化条件分布，不能只将 S 减去 $`\lambda_k\Pi`$：

```math
\begin{aligned}
\ell^o_{b,o}&=\mathrm{logsumexp}_{a}S_{b,o,a},\\
A_{b,o,a}&=S_{b,o,a}-\lambda_k\Pi_{o,a},\\
S^{off}_{b,o,a}&=\ell^o_{b,o}+A_{b,o,a}
-\mathrm{logsumexp}_{a'}A_{b,o,a'}.
\end{aligned}
```

来源：[后处理算子][posthoc]，完整核心函数；此处依赖 `numpy as np`：

```python
def logsumexp(x, axis):
    m=np.max(x,axis=axis,keepdims=True)
    return (m+np.log(np.exp(x-m).sum(axis=axis,keepdims=True))).squeeze(axis)


def remove_prior(grid, prior, weight):
    # log P(o) is exactly the row marginal of the normalized full OW grid.
    lo=logsumexp(grid,2)
    adjusted=grid-weight*prior[None]
    return lo[:,:,None]+adjusted-logsumexp(adjusted,2)[:,:,None]
```

该诊断要求完整 OW 网格、使用 checkpoint 的实际有效 lambda 和相同 VAL-frozen bias；helped／harmed 为同权重读出比较，不是重新训练消融或语义因果标签。

## 12. 实现索引与验证

```text

                         ↓
CPF 视觉特征 → 原生 composition＋attribute logits
```
