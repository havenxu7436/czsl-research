## 4. 看日志、确认完成

```bash
tail -n 60 /tmp/czsl_clip_knowledge_probe_20261010_r2_driver.log
pgrep -af 'clip_knowledge_probe_20261010_r2/[p]robe.py'
tmux has-session -t clip_probe_r2_1010 2>/dev/null && printf 'TMUX_RUNNING\n' || printf 'TMUX_ENDED\n'
```

正常过程是新的 `SPLIT_AUDIT_PASSED` → 图片预检 → 权重核验或下载 → `CLIP_TEXTS` → `CLIP_IMAGES train` → `CLIP_IMAGES val` → 指标 → 结果 ZIP。当前工作目录中的 `split_audit.json` 保存划分核对结果，后续 unseen 指标只用 2337 张 unseen 图片，seen 指标用 877 张；编码仍对每张图计算全部 12×16 候选，不按真实标签删候选。

每 512 张刷新一次 `CLIP_IMAGES`，ETA 只对应当前 split 编码阶段，不含后续指标和打包。

完整完成必须看到：

```text
KNOWLEDGE_PROBE_COMPLETE OE_AE_GATE ... AE_GATE ... optimizer_steps 0 TEST_IMAGES 0
KNOWLEDGE_PROBE_ZIP_VERIFIED ... members
KNOWLEDGE_PROBE_EXPORT_COMPLETE /var/tmp/czsl_clip_knowledge_probe_20261010_r2.zip execution_passed True
```

gate False 可以是正常阴性结果；`execution_passed False` 是异常退出。两个状态不能混淆。

## 6. r2 若被中断：只恢复 r2，不恢复旧 v1

首先发完整日志。只有确认 r2 进程已退出、原因已排除时，才使用下面的恢复命令。旧版的 `TRAIN/VAL unseen pair overlap` 已修复；若新预检发生数量或 hash 异常，不能靠恢复绕过它。

```bash

  set -euo pipefail

    printf 'STOP: a probe process still exists.\n'
    exit 1
  fi
  if tmux has-session -t clip_probe_r2_1010 2>/dev/null; then
    printf 'STOP: original r2 tmux still exists.\n'
    exit 1
  fi
  if tmux has-session -t clip_probe_r2_resume_1010 2>/dev/null; then
    printf 'STOP: r2 resume tmux already exists.\n'

  test -s /var/tmp/czsl_clip_knowledge_probe_20261010_r2/release_identity.json

    'CUDA_VISIBLE_DEVICES=1 CUBLAS_WORKSPACE_CONFIG=:4096:8 /data/xhw/miniconda3/envs/cpf/bin/python -u /tmp/czsl_clip_knowledge_probe_release_20261010_r2/clip_knowledge_probe_20261010_r2/probe.py --work /var/tmp/czsl_clip_knowledge_probe_20261010_r2 --export /var/tmp/czsl_clip_knowledge_probe_20261010_r2_resume1.zip --resume > /tmp/czsl_clip_knowledge_probe_20261010_r2_resume1_driver.log 2>&1'
```
