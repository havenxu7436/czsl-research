### 这些结果说明什么

1. **复现核心已完成，但“堆叠全部组件就提高表现”的假设没有得到支持。** H 相对 A 的 TEST CW/OW AUC 分别低 12.6199/12.0558 个百分点。负结果仍是有效完成结果。
2. **当前先验配方是主要拖累之一。** D 比 A 差；E 比 C 差；H_uniform_prior 比 H 的 TEST CW/OW 分别高 8.9060/7.3901 点。真实 prior 比随机 prior 好，并不意味着比不用 prior 好。
3. **Text K 的收益存在 VAL/TEST 分歧。** C 在 VAL 高于 A，但 TEST CW/OW 分别低 1.1503/2.9546 点。不能只展示 VAL 的提升而宣称泛化提升，也不能混用此前 seed 0 或 v2 知识的最好值。
4. **logic 没有稳定增益。** B−A：TEST CW −0.0445、OW +0.5886；F−E 与 H−G 的 TEST 两设置都为负。这是单 seed 观察，不是显著性结论，也不能证明所有逻辑方法都无效。
5. **G/H 的正式运行填补了路径 3 的执行缺口，但当前带 prior 的配置没有改善 TEST。** G−E 的 TEST CW/OW 为 −3.2198/−1.5572；不能把它外推为“所有视觉条件知识模块都无效”。H−F 同时涉及 head、条件 CE 和属性逻辑 adapter，不能解释为单一变量效果。

## 3. 已完成的额外诊断：固定权重、仅改变 VAL 读出

利用保存的真实分数，按已知公式 `score_new = score_saved + (lambda_new - 0.1) * centered_prior` 做 VAL-only 离线诊断；原权重、原训练、原选模不变。所有 λ=0.1 回放与原评价完全一致。没有做新的 TEST λ 搜索。

|---|---:|---:|---:|---:|
| D | 33.0561 | 38.6258 | 22.1366 | 25.6508 |

| G | 38.2648 | 45.1527 | 22.4444 | 30.1398 |

这说明**至少读出阶段的 λ=0.1 静态偏置明显压低当前 VAL 表现**。当前 legacy 训练 logits 有 /0.05 温度，而推理用余弦尺度；相同 λ 在两个阶段相对视觉分数的强度不同，这是值得后续修正的具体机制。不能据此断定先验内容是唯一原因，或把上述数值填进“重新训练”的主表。

诊断网格含 λ=0/0.005/0.01/0.02/0.05/0.1，见 audit.json。若下一阶段以性能为目标，应先做 VAL 预先选定的先验尺度/关闭 prior 配对实验，保留旧表，并将新 TEST 结果标注为后续探索；不要换视觉骨干同时改多个因素。**本次截止前的复现扩展不根据已看到的 TEST 值改参数。**
