## 1. 当前实验背景与总体判断

当前最关键的问题是：正确的外部知识能否在图像和候选对象条件下产生额外收益。

- UT-Zappos 静态 v2 中，`C_text` 相对 `A_unit` 的三 seed 平均 CW AUC 提高约 `+3.067 pp`，OW AUC 提高约 `+4.131 pp`。
- 正确描述相对固定错配描述的平均 CW AUC 优势为 `+0.379 pp`，低于原先固定的 `+0.5 pp` 门槛；OW AUC 平均优势约为 `+1.980 pp`。原 CW gate 仍未通过。
- 描述影响具有类别差异：改善部分对象，同时破坏 Boat Shoes 等对象的识别，尤其是 `Leather × Boat Shoes`。
- 名称锚点 EKR、共享值对齐 EKR-v2 和 SG-EKR 的已有短预算实验，尚未证明正确描述稳定优于名称及错配对照。
- EKR-v2 已另立固定的 `3 → 10 epoch` 预算复核方案。这项复核可以检查短训影响；截至本次读取的本地记录，尚无十轮真实服务器结果。
- 新的知识条件概率模型仍处于设计阶段，核心是检验 `P(a | o,x,K)`，并保留共同强基线及同构归因对照。

## 2. Duplex：语义锚点 + 动态视觉原型

论文：*Semantically Guided Dynamic Visual Prototype Refinement for Compositional Zero-Shot Learning*。

来源：[2501.07114v2.pdf](C:/Users/llenovo/Desktop/CZSL/CZSL_paper/new/2501.07114v2.pdf)。重点阅读：第 4-8 页方法、第 10-13 页结果与消融。

### 2.1 关键 Idea

Duplex 同时维护语义原型与视觉原型。语义原型由 prompt learning 获得，用来提供语义结构；视觉原型从图像证据出发，负责细粒度判别。

从 seen 图像中拆出 state 和 object 视觉因子，再跨图像组合，构造包括 unseen pair 在内的反事实视觉表示。每个 mini-batch 建立标签条件的局部图，把同属性、同对象及反事实组合的信息聚合到相关原型。全局 prototype codebook 通过 EMA 持续更新，推理时直接使用已学到的原型，无需构图。

这里的 unseen 训练信号来自 seen 视觉因子的重组和候选标签结构，并不使用 unseen 图像标签。

### 2.2 实验中最值得关注的证据

论文在 UT-Zappos 上报告：C-S-O 基线的 CW AUC 为 `37.8`；加入全局视觉 codebook 后达到 `42.6`；再加入局部图达到 `46.2`。这说明视觉原型本身就有较大贡献，局部更新提供进一步增量。

另一个消融显示，固定文本模板下视觉原型模块收益很小，而与 soft prompts 配合后收益明显。视觉更新依赖较好的语义锚点。论文也指出，CGQA 的长尾分布会限制视觉原型收益。

### 2.3 对当前实验的借鉴

当前 EKR 主要通过 GloVe 描述或残差改变语义分数。Boat Shoes 等错误已经表现为视觉对象混淆，因此可以加入独立的 TRAIN 视觉原型证据，检验它能否补充文本分支。

一个低成本起点是复用缓存的 TRAIN 特征，构造视觉 pair prototype，并在固定基线上增加：

```text
score = 原 C_text 分数 + α × 视觉 pair 原型相似度
```

再分步比较静态全局原型、state/object 反事实组合和 EMA 更新。第一轮可以把视觉原型作为辅助实验，与当前知识条件概率主线分别验证。

若研究目标包括撤销描述造成的对象混淆，需要注意底座选择：名称底座允许完全退回名称分数；`C_text` 底座只能验证新增模块的增量。两者回答的问题不同，应在各自协议下比较。

### 2.4 边界与优先级

现有已训练特征上的 TRAIN 原型探针属于设计证据。若要声称 unseen composition 泛化，应建立真实组合留出训练与评价，避免把 backbone 已见过的组合当作新组合。

优先级：高。它与当前对象类别混淆的观察直接对应。

## 3. CZSL Survey：给当前路线定位

论文：*Compositional Zero-Shot Learning: A Survey*。

来源：[2510.11106v1.pdf](C:/Users/llenovo/Desktop/CZSL/CZSL_paper/new/2510.11106v1.pdf)。重点阅读：第 5-6 页问题定义与分类、第 27-33 页比较分析与未来方向。

### 3.1 关键 Idea

综述按 disentanglement 发生的位置，将 CZSL 分成四类：无显式解耦、文本解耦、视觉解耦和跨模态解耦。其分析围绕两个问题展开：primitive 能否被区分，以及 primitive 的表现如何随对象或属性上下文变化。

在其汇总的实验范围内，CLIP 方法整体优于旧 CNN 方法；文本解耦提供增益，但难以覆盖视觉上下文变化；视觉解耦在 open-world 下表现较可靠；跨模态方法有潜力，同时可能受到语义噪声和不可行组合干扰。

### 3.2 对当前实验的借鉴

当前正确描述的增量证据有限，与“文本语义无法独自解决视觉上下文”的研究问题相符。这使后续工作可以围绕下面的问题展开：

> 在图像和候选对象条件下，如何对齐、选择或拒绝外部知识，并证明正确知识产生了增量？

实验上继续同时报告 CW 和 OW。当前正确描述对错配描述的信号在 OW 更明显，值得分析，但原来声明的 CW 主指标仍应按原规则解释。

写相关工作时，可把现有路线放在条件属性建模与跨模态知识利用的交叉处，说明它如何处理上下文依赖，而不是只强调增加了描述输入。

### 3.3 边界与优先级

这篇没有可直接实现的单一模块，主要用于研究定位、比较协议与相关工作组织。其方法排名反映综述收集的文献范围，不能视为所有后续方法的排名。

## 4. H²EM：双层层级 + 双曲空间 + 难负样本

论文：*H²EM: Learning Hierarchical Hyperbolic Embeddings for Compositional Zero-Shot Learning*。

来源：[2512.20029v1.pdf](C:/Users/llenovo/Desktop/CZSL/CZSL_paper/new/2512.20029v1.pdf)。重点阅读：第 4-5 页方法、第 7-8 页消融。

### 4.1 关键 Idea

H²EM 同时建模 semantic hierarchy 和 conceptual hierarchy。前者表示 primitive 与父类的关系，例如 apple 属于 fruit；后者表示 composition 比对应 primitive 更具体，例如 sliced apple 蕴含 sliced 和 apple。

模型将视觉和文本表示映射到 Lorentz 双曲空间，用 entailment cone 约束父子关系，再通过 hard-negative alignment 拉开共享属性或对象的近邻组合。Hyperbolic Cross-Modal Attention 根据图像上下文动态调整文本表示。

### 4.2 实验中最值得关注的证据

双曲映射、层级约束和判别对齐联合使用时，论文报告的整体效果最好。层级损失需要适度：MIT-States 的消融中，小权重约 `0.1` 较好，权重过大会显著损害分类表现。

### 4.3 对当前实验的借鉴

最容易迁移的是难负样本设计。条件属性头可以提高“同对象难属性”的权重；组合分类时还可以关注“同属性难对象”。对于 `Leather × Boat Shoes`，优先关注相似鞋型之间的混淆，比均匀处理所有负类更贴合现有错误。

已有父类、OE 和 AE 知识也可以用于小权重层级正则。建议先在现有空间中验证层级关系是否有增量，再考虑双曲空间。

层级结构在类别多、长尾重的 CGQA 上可能更有价值，这是待验证的迁移假设。

### 4.4 边界与优先级

完整双曲改造会同时改变距离度量、分类器和知识表示，增加归因难度。当前优先借鉴难负样本和小权重结构约束；完整 H²EM 放在后续。

## 5. SPA：保持语义邻域，将 seen 更新迁移给 unseen

论文：*Structure-aware Prompt Adaptation from Seen to Unseen for Open-Vocabulary Compositional Zero-Shot Learning*。

来源：[2603.03815v1.pdf](C:/Users/llenovo/Desktop/CZSL/CZSL_paper/new/2603.03815v1.pdf)。重点阅读：第 4-5 页方法、第 8-10 页消融与分析。

### 5.1 关键 Idea

训练前，在冻结 CLIP 空间中为属性和对象确定 Top-K 语义邻居。训练时用 Structure-aware Consistency Loss（SCL）保持微调前后邻域相似度的概率分布，避免 prompt tuning 扭曲原有语义关系。

推理时，Structure-guided Adaptation Strategy（SAS）为完全 unseen 的 primitive 寻找相似 seen primitives，将它们训练得到的 prompt 位移加权迁移过去。

### 5.2 实验中最值得关注的证据

SCL 与 SAS 各自有效，联合使用效果更好。论文实验中 `K=5` 取得较好的折中，过大邻域会引入较不相关的概念。

### 5.3 对当前实验的借鉴

当前共享 value 对齐路线出现过 value drift，正确描述分支也未稳定超过名称对照。可以将 SCL 的思想用于描述 value 对齐层：

1. 在固定初始语义空间确定属性、对象的邻域。
2. 对齐后计算同一邻域内的相似度分布。
3. 用较小权重的 KL loss 保持局部结构。
4. 比较 `正确/错配知识 × 有无 SCL`，检验结构保持是否改善正确知识的增量。

这项实验可以帮助回答：对齐层是否在提高训练拟合的同时，破坏了可迁移的语义关系。

### 5.4 边界与优先级

论文的邻域来自 CLIP，当前 GloVe 邻域未必具有同样的视觉意义。迁移前应检查反义词、相似材料和相近鞋型是否被错误聚合。

标准 CZSL 中 primitive 通常都已在训练出现，所以当前主要需求是 SCL；SAS 更适合以后扩展到 OV-CZSL。OW 扩大组合候选空间，OV 则允许出现新 primitive，两者评价设置不同。

优先级：高，适合作为条件知识模块的正则候选。

## 6. FlowComposer：显式组合与残余纠缠利用

论文：*FlowComposer: Composable Flows for Compositional Zero-Shot Learning*。

来源：[2603.16641v1.pdf](C:/Users/llenovo/Desktop/CZSL/CZSL_paper/new/2603.16641v1.pdf)。重点阅读：第 4-5 页方法、第 7-8 页消融、第 11-13 页额外分析。

### 6.1 关键 Idea

分别学习 attribute flow 和 object flow，把视觉 primitive 表示运输到对应文本表示。Composer 根据样本预测两个速度场的组合系数，显式构造 composition velocity，而不是只通过 prompt 拼接隐式组合。

论文同时利用解耦后仍残留的跨分支信息：属性分支中的对象线索、对象分支中的属性线索以及组合分支中的 primitive 线索，都作为额外 flow 监督。

### 6.2 实验中最值得关注的证据

论文报告，直接学习 composition flow 容易过拟合 seen pair，并降低 unseen 表现；组合 primitive flows 更有效。参数匹配的普通 residual regressor 弱于 Flow Matching，说明应检验训练目标本身的贡献。

### 6.3 对当前实验的借鉴

当前条件知识方案已经有图像、对象与知识的交互，可以进一步把组合操作拆成可消融的部分：属性知识产生的表示或分数位移、对象条件产生的位移，以及样本相关的组合系数。

低成本起点可以是 residual composer。若有正信号，再比较普通回归与 Flow Matching，避免把额外参数带来的收益归因于 flow。

建议增加跨分支探针：用属性特征预测对象，用对象特征预测属性，并报告类别平衡准确率。如果远高于随机水平，说明仍存在跨分支信息，可以检验这部分信息能否辅助条件预测。

### 6.4 边界与优先级

完整方法的 flow 和 composer 参数量并不小，虽然单步推理控制了延迟，训练和工程成本仍需评估。仅采用显式 residual composer 时，应称为借鉴组合思想，不能等同于完整 FlowComposer。

优先级：中等，适合条件概率头跑通后开展。

## 7. PRPC：属性与对象双向纠错

论文：*Progressive Reasoning with Primitive Correction for Compositional Zero-Shot Learning*。

来源：[2607.05911v1.pdf](C:/Users/llenovo/Desktop/CZSL/CZSL_paper/new/2607.05911v1.pdf)。重点阅读：第 3-5 页方法与评价协议、第 6-7 页结果及消融。

### 7.1 关键 Idea

PRPC 将组合识别写成五步推理：先预测对象，再在对象条件下预测属性；用属性反过来纠正对象，再用更新后的对象校验属性，最终输出组合。

训练先用生成的结构化推理轨迹进行 SFT，再用 GRPO 根据最终答案、格式和中间步骤正确性进行优化。后续校验与纠错步骤获得较高奖励时，论文报告效果较好。

### 7.2 实验中最值得关注的证据

论文主动注入错误对象，验证后续步骤能否恢复。这种干预比单纯展示 attention 或中间解释，更直接检验纠错机制。

其评价包括开放生成的严格字符串匹配，以及生成文本经 CLIP 文本空间投影后的候选标签评价。理解结果时需要区分这两种接口。

### 7.3 对当前实验的借鉴

可以把双向纠错改造成轻量概率更新：

```text
P0(o | x)
    → P1(a | o,x,K)
    → P1(o | a,x,K)
    → P2(a | o,x,K)
    → joint score
```

第一版条件概率头先验证 `object → attribute`。后续独立消融再增加一次 `attribute → object` 回写，并分别报告各步 attribute、object 和 pair accuracy。

建议人为注入相似错误对象，统计纠正率和对原正确预测的破坏率。这能检验对象条件是否实际被利用，以及模型是否可以摆脱初始对象错误。

### 7.4 边界与优先级

当前知识条件概率首轮方案固定对象边缘，不能直接纠正对象分布。增加属性到对象回写需要另立实验协议。

完整 MLLM + CoT + GRPO 会改变模型、数据生成和评价流程，成本较高。当前优先借鉴双向更新和错误注入验证；论文的结果不能与现有 CPF 数值简单横比。

## 8. DIFFCZSL：扩散模型作为训练期教师

论文：*DIFFCZSL: Compositional Zero-Shot Learning Regularized by Diffusion Representations*。

来源：[2608.19871v1.pdf](C:/Users/llenovo/Desktop/CZSL/CZSL_paper/new/2608.19871v1.pdf)。重点阅读：第 5-7 页方法、第 9-12 页结果和消融、第 18-19 页稳定性与关系分析。

### 8.1 关键 Idea

从冻结扩散模型中提取图像与组合文本条件共同形成的中间层表征，经过池化和两个投影头，分别对齐到 CZSL 的视觉空间与文本空间。

通过双向对比蒸馏，正则化 image embedding 和 composition text embedding。扩散分支只在训练时使用，训练结束后移除，原有推理架构保持不变。

### 8.2 实验中最值得关注的证据

图像侧与文本侧蒸馏分别有用，联合使用最好。CleanDIFT 的无噪声特征较稳定，中后层通常比早层提供更合适的组合监督。

DIFF-Troika 在 UT-Zappos 的主要结果中，CW AUC 从 `41.7` 提升到 `46.2`。其 DINOv3 教师对照收益较小且不一致，提示需要检验教师表征类型的贡献。

### 8.3 对当前实验的借鉴

当前知识主要作为推理时的描述输入或分数残差。另一条可验证路径是把外部表征作为训练教师，让模型吸收辅助信息，并保持评价时的分数接口。

可以先离线提取 TRAIN diffusion features，再分别检验视觉侧、语义侧和双侧蒸馏。与当前归因标准相匹配的对照包括：

- 正确组合 prompt 与固定错配 prompt。
- image-only 教师与图像加组合文本条件教师。
- image、text 和双侧蒸馏。
- DINO 或普通视觉教师。

如果 EKR-v2 固定十轮预算结束后，正确描述仍没有对照优势，训练期蒸馏是值得单独投入的后续候选。

### 8.4 边界与优先级

当前 CPF 使用 GloVe 及其对应表示空间，论文使用 CLIP。迁移时需要可训练的接收模块和适当投影，不能假定同样的蒸馏损失在当前系统自动有效。

教师提取只使用 TRAIN 标签条件。验证和测试预测不应依赖真实组合标签来生成教师特征。

建议预先缓存冻结教师特征，并记录教师模型、层、prompt 和图像预处理。这样可以控制成本，也便于比较正确与错配条件。

## 9. 建议的实验顺序

下面是研究建议，不表示已经实现或运行这些新实验。

1. **完成既定 EKR-v2 `3 → 10 epoch` 预算复核。** 按原协议收集完整轨迹和对照排序，判断短预算筛选结果是否稳定。
2. **实现已有知识条件属性概率方案。** 保留共同冻结的强 `C_text` 参考、名称控制、正确知识、错配知识和普通融合对照，先验证新增条件知识的增量。
3. **若条件头有可解释信号，增加 SPA 式局部结构保持。** 用独立消融检查它是否降低语义漂移，并改善正确知识相对错配知识的表现。
4. **比较 H²EM 式难负样本。** 重点检验同对象属性混淆和同属性对象混淆，不同时引入完整双曲主干。
5. **独立测试 Duplex 式视觉 prototype 辅助分支。** 检查 Boat Shoes 等组的纠正、破坏和整体 CW/OW 表现。
6. **在另立协议下增加一次属性到对象回写。** 使用错误对象注入评价恢复能力，记录每一步的实际准确率。
7. **考虑 DIFFCZSL 式训练期蒸馏。** 同时验证正确文本条件和教师表征类型的贡献。
8. **将完整 Flow Matching、双曲主干、MLLM + RL 放到后续阶段。** 它们需要更大改造，适合在低成本机制验证得到依据后投入。

## 10. 可形成的研究命题与证据要求

一个与当前实验衔接较自然的候选命题是：

> 在共同强基线上，利用对象条件属性概率、局部语义结构保持和辅助视觉证据，提高外部描述的有效利用，并通过知识错配和对象错误干预验证机制。

建议先分别验证条件概率、结构保持和视觉原型的增量，再决定是否组合。只有所有模块合在一起涨点，无法区分哪个机制起作用。

最终主张需要由以下证据支持：

- 正确知识稳定优于同结构名称控制和固定错配控制。
- 增益出现在真实 unseen composition 评价，而非只有 TRAIN 探针。
- 对象条件干预带来与假设一致的变化，且有实际纠正收益。
- 坏知识下的回退与拒绝行为通过干预实验得到验证。
- 增益在固定预算、配对 seed 和跨数据集评价中保持，并报告离散程度和负结果。

当前首轮固定对象边缘的条件概率模型只重新分配同一对象下的属性概率。它的实验结果应按这个范围解释；对象纠错、知识拒绝和视觉可靠性需要各自的验证。
