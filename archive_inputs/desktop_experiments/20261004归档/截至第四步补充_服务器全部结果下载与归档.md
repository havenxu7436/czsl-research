## 3. 服务器 Bash：归档

归档可能读取数十 GB，建议复用现有 tmux。需要新会话时才执行：

```bash
tmux new-session -A -s czsl-results-export
```

在显示 `xhw@amax:...$` 的服务器终端中，整行执行：

```bash
/data/xhw/miniconda3/envs/cpf/bin/python -u /data/xhw/czsl_repro/backup_czsl_all_results.py --root /data/xhw/czsl_repro
```

不需要 `conda activate`、GPU 或管理员权限。开始会输出待归档体积与导出目录，随后逐包输出 `PACKING` / `READY`；大文件阶段约每20秒输出当前包已写入体积。

成功的末尾类似：

```text
EXPECTED_STAGE_COMPLETE=True
EXPORT_COMPLETE
REMOTE_EXPORT=/data/xhw/czsl_repro/exports/czsl_all_completed_实际时间戳_进程号
```

**复制最后的完整 `REMOTE_EXPORT` 路径**，用于本机下载；不要手工猜时间戳。

归档结束后还可在服务器核对所有输出。把路径替换成刚才的实际值：

```bash
(
  set -euo pipefail
  cd /data/xhw/czsl_repro/exports/czsl_all_completed_实际时间戳_进程号
  sha256sum -c SHA256SUMS
)
```

所有条目应为 `OK`。完整压缩包、`source_files.csv`（逐文件 hash）及 `SHA256SUMS` 都保留在服务器上。

### 若空间不足或中途失败

服务器空间检查采用偏保守的原文件体积估计。空间不足时，可指定你有写权限且容量足够的另一块磁盘：

```bash
/data/xhw/miniconda3/envs/cpf/bin/python -u /data/xhw/czsl_repro/backup_czsl_all_results.py --root /data/xhw/czsl_repro --out-root /你有写权限的磁盘/czsl_exports
```

打包中断、文件仍在被写入、目录链接循环或不可读取文件会报 `EXPORT_FAILED`。原始资产保留，草稿包留在原导出目录；处理原因后重新运行会生成新目录，不覆盖旧包。只有看到 `EXPORT_COMPLETE` 后才下载。

如果 `EXPECTED_STAGE_COMPLETE=False`，备份仍可成功：表示预期阶段检查发现缺失、状态异常或实际目录名不同。下载后查看 `stage_check.json` 的具体条目；不会改 status 或补造指标。脚本按文档中的默认目录检查，其他版本/诊断目录也全部保存在 `experiments` 包中。

## 4. 本机 Windows PowerShell：自动下载、校验、解压

本机打开一个新的 PowerShell。只替换 `$taskRemoteExport` 的字符串：

```powershell
$taskRemoteExport = '/data/xhw/czsl_repro/exports/czsl_all_completed_实际时间戳_进程号'

powershell.exe -NoProfile -ExecutionPolicy Bypass -File 'C:\Users\llenovo\Documents\ChatGPT\CZSL\output\backup\download_czsl_all_results.ps1' -RemoteExport $taskRemoteExport -SshTarget 'xhw@211.87.232.122' -Port 22 -LocalRoot 'C:\Users\llenovo\Desktop\CPF_all_results'
```

`-ExecutionPolicy Bypass` 只应用于这次新 PowerShell 进程，不修改系统的持久执行策略；脚本仅使用本机已有的 scp、tar 和 SHA256 工具。

本机首次连接时核对正常的 SSH 主机指纹，使用你自己的密码/密钥。脚本会用少量 scp 会话下载，不需要为每个包单独写命令。

脚本会：

1. 下载完成描述与 checksum 清单，核验服务器导出身份。
2. 检查本机空间；下载所有归档及元数据。
3. 逐文件比较本机和服务器 SHA256。
4. 将全部归档解压到同一 `files` 目录，保持原相对目录结构。
5. 写入本机下载与解压完成记录。

正常末尾出现：

```text
ALL_DOWNLOAD_HASHES_PASSED
LOCAL_BACKUP_COMPLETE
FILES=C:\Users\llenovo\Desktop\CPF_all_results\czsl_all_completed_...\files
```

若下载中断，**重新执行同一条下载命令**。已完整且 hash 正确的包会跳过；被中断的单个包重新传输，不是该包的字节级续传。无需重新在服务器打包。

如果解压曾中断，重试会保留旧部分解压目录，并使用新的 `files_retry_...` 目录；以最后输出的 `FILES` 路径为准。

### 本机 C 盘不够时

把 `-LocalRoot` 改为你容量足够的盘，例如确实存在的 D 盘：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File 'C:\Users\llenovo\Documents\ChatGPT\CZSL\output\backup\download_czsl_all_results.ps1' -RemoteExport $taskRemoteExport -SshTarget 'xhw@211.87.232.122' -Port 22 -LocalRoot 'D:\CZSL_results'
```

若只需要先保存完整归档、暂不解压，在下载命令末尾加 `-DownloadOnly`。此时 `ALL_DOWNLOAD_HASHES_PASSED` 就表示全部归档已下载并校验，之后可去掉该选项再次运行完成解压。
