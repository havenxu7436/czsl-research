# 训练图导出路径报错：检查与 v2 修复

截图中，三个文件 SHA256 校验通过，torch 环境检查也通过；任务在检查选中的训练图路径时停止。尚未创建图册输出目录，也没有启动训练。

v1 的 resolve_image 把两个情况都报成 FileNotFoundError：真实文件缺失，以及文件存在但因子目录软链接而位于配置根目录之外。因此仅凭截图不能认定数据缺失或根目录配错。日志中的 _images_extract 可能只是 images 或其子目录软链接展开后的实际位置。

## 1. 先在服务器执行只读检查

```bash
/data/xhw/miniconda3/envs/cpf/bin/python -I - <<'PY'
from pathlib import Path
data = Path('/data/xhw/czsl_repro/data/ut-zap50k')
relative = 'Boots/Ankle/Dr. Martens/8004440.365149.jpg'
logical_root = data / 'images'
root = logical_root.resolve()
target = (logical_root / relative).resolve()
print('IMAGES_IS_SYMLINK:', logical_root.is_symlink())
print('IMAGE_ROOT_REAL:', root)
print('TARGET_REAL:', target)
print('TARGET_WITHIN_ROOT:', root in target.parents)
print('FILE_EXISTS:', target.is_file())
try:
    print('FILE_SIZE:', target.stat().st_size)
    with target.open('rb') as stream:
        print('FILE_READ_OK:', stream.read(8).hex())
except OSError as error:
    print('FILE_ACCESS_ERROR:', type(error).__name__, 'errno=', error.errno)
candidate = data / '_images_extract' / 'ut-zap50k-images-square'
print('CANDIDATE_ROOT:', candidate)
print('CANDIDATE_FILE_EXISTS:', (candidate / relative).is_file())
PY
```

- FILE_EXISTS=True、FILE_READ_OK 正常、TARGET_WITHIN_ROOT=False：v1 对嵌套链接的路径检查导致误报。核对 CANDIDATE_ROOT 确实含 Boots、Shoes、Sandals 等原始图像树后，使用 v2 的显式 --image-root。
- FILE_EXISTS=False、errno=2：目标文件或路径节点当前不存在。先定位文件；不能通过换 seed、跳过图片或替换同名照片解决。
- errno=13：权限或目录遍历问题。记录路径，检查目录权限；换根目录不能代替权限修复。
- FILE_EXISTS=True 且 TARGET_WITHIN_ROOT=True：该文件当前能访问，保存输出。旧报错不能单凭这一次检查归因，随后用 v2 检查全部选中训练图。

仅在目标不存在时，搜索这个文件名，不扫描整个 /data：

```bash
find -L /data/xhw/czsl_repro/data/ut-zap50k -maxdepth 8 -type f -name '8004440.365149.jpg' -print
```

找到其他位置时，先核对原数据来源和 metadata 中的相对路径，再设正确根目录；不要创建假文件、批量改名或覆盖数据软链接。没有找到时需检查原数据目录或原图压缩包是否还完整，不直接启动下载/全量解压；/data 曾经空间不足。

服务器 Bash，以下根目录以第1节检查得到的实际图像树为准。给出的 _images_extract 路径来自截图，只在已核对该树正确时使用：

```bash
(
  set -euo pipefail
  CPF_PY=/data/xhw/miniconda3/envs/cpf/bin/python
  ROOT=/data/xhw/czsl_repro
  TOOL=/tmp/ut_train_review_20261006_v2
  IMAGE_ROOT="$ROOT/data/ut-zap50k/_images_extract/ut-zap50k-images-square"
  OUT=/tmp/ut_train_review_images_20261006_v1
  test -s /tmp/ut_train_review_20261006_v2.zip
  if [ ! -e "$TOOL" ]; then
    "$CPF_PY" -m zipfile -e /tmp/ut_train_review_20261006_v2.zip /tmp
  fi
  cd "$TOOL"
  sha256sum -c SHA256SUMS
  test -d "$IMAGE_ROOT"
  test ! -e "$OUT"
  test ! -e "$OUT.zip"
  "$CPF_PY" -I -u "$TOOL/export_train_review.py" \
    --data "$ROOT/data/ut-zap50k" \
    --knowledge "$ROOT/knowledge/kcc0601_v1/trusted_v1/ut-zap50k" \
    --image-root "$IMAGE_ROOT" --seed 20261006 --max-per-class 20 \
    --out "$OUT" --check-images-only
  "$CPF_PY" -I -u "$TOOL/export_train_review.py" \
    --data "$ROOT/data/ut-zap50k" \
    --knowledge "$ROOT/knowledge/kcc0601_v1/trusted_v1/ut-zap50k" \
    --image-root "$IMAGE_ROOT" --seed 20261006 --max-per-class 20 \
    --out "$OUT"
  sha256sum "$OUT.zip"
)
```

只有 SELECTED TRAIN IMAGE CHECK PASSED 后才导出，检查覆盖全部选中训练图，不能只凭一张图存在就判定目录全部正确。完成后仍按第七步第1.3节下载；输出 ZIP 名称保持一致。

若后面仍有 Selected TRAIN image absent，保存那个确切路径，按第1节检查，不改变固定样本或静默删掉缺失项。
