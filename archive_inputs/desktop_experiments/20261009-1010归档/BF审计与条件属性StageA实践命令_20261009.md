## 2. 本次真正执行什么

执行包：[conditional_attribute_stageA_release_20261009_r2.zip](C:/Users/llenovo/Documents/ChatGPT/CZSL/output/conditional_attribute_stageA_release_20261009_r2.zip)。本轮请使用这个带 `_r2` 的文件。


两个检查分别在子进程中运行，避免混用 B/F 和 C_text 的同名 Python 模块。

1. **B/F 最佳权重梯度诊断**：共同固定的 12 张 TRAIN 图片，3 个 batch×4 张；加载实际最佳 checkpoint，分别计算 CPF、OI、OE、AE、加权逻辑项在对象/属性视觉映射参数上的梯度范数和余弦。eval 模式与固定变换，无 optimizer step；验证内存中的参数/持久 buffer 未改变。它不代表整轮平均梯度，不等价于 Adam 更新方向，也不能单独证明因果。
2. **条件模块 Stage A**：先在 3214 张 VAL 上回放 C_text 的 CW/OW，失败则不继续提取 TRAIN。通过后提取 22998 张 TRAIN 的冻结 300 维属性特征和完整 12 对象×16 属性原分数。只保存必要缓存，不保存 ViT 中间 token。

固定锚点是 C_text_v2 seed 0 的第 6 轮权重：

```text

bank.pt SHA256:    94259cca60bdc132d26a6c26a799d823826152d4a9dcf60fe8bcc93e0cca0525
VAL CW AUC:       45.440386970321%
VAL OW AUC:       34.9373446065435%
```

这是另一 seed/更强文本版本的锚点，不能与 B/F seed 3351 直接做方法配对增益比较。

新 head 已实现为候选对象、图像与 OE/AE 的共享低秩交互；没有独立 pair lookup。它调整完整网格中的属性条件概率并保持原完整分数诱导的对象边缘；不是把原 CPF 辅助 object head 直接当作该边缘。关闭分支或初始零输出可回放原分数。完整网格归一化在先，再投影到原 CW/OW 候选，使用原 evaluator 和 bias 扫描。

P_name、P_K、P_perm1、P_perm2 的有效参数量相同，均为 57,760；P_generic 的普通拼接 MLP 多 3,104 个活跃参数，合计 60,864。这里明确报告差异，不把普通融合组描述成严格参数匹配。原语名称不打乱，两个固定错配只交换 OE/AE 归属，条目数与 mask 相同。

Stage A 用前 16 张 TRAIN 缓存检查五种 head，每种仅 3 个诊断优化步，共 15 步，然后恢复初始状态并丢弃这些 head。**基础模型更新 0 步；正式 pilot 更新 0 步。** 这不是五组训练结果，也不是 TRAIN 分折机制实验。

脚本在导入原代码前核对来源、配置、权重、bank、相关缓存、GloVe、split 和 metadata 的固定哈希，结束后复核。加载完整 checkpoint 为 strict；只在内存中关闭无用的预训练初始化下载，不修改原源码。读取 TRAIN/VAL 图，读取原 split 的词表/元数据；不打开 TEST 图片，不评估 TEST。没有逐张原始图像字节哈希的独立核验，缓存会保存自身哈希与图像/标签顺序。
