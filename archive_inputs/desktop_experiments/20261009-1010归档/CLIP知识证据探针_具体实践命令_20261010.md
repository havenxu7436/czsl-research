## 0. 这次究竟改变什么

保留现有 C_text CPF、StageA 缓存、Generic 架构和固定 25% 混合接口。本次不更新这些模型、不覆盖旧目录、不换 CPF 骨干、不重新生成知识，也不加固定 K 校准或逻辑损失。

唯一新增的是一个独立、冻结的 OpenAI CLIP ViT-L/14 教师，用图文匹配检验现有 v2 描述。不是完整重现 Troika＋LogiCZSL，也不是声称 CLIP 一定会改善 CPF。

本轮完整编码 TRAIN 22998 张和 VAL 3214 张；optimizer step = 0；不读取 TEST 图片或生成 TEST 分数。官方 VAL 用于一次锁定配方的开发筛选，不称最终独立验证集；此前也已用于实验开发。

| 组别 | 名称 | 额外描述 |
|---|---|---|
| T_name | 固定真实候选名称 | 无 |
| T_K | 同一套名称 | 正确 AE＋OE |
| T_perm1、T_perm2 | 同一套名称 | 原 StageA 两套固定错配 AE＋OE |
| T_AE | 同一套名称 | 仅正确 AE |
| T_AE_perm1、T_AE_perm2 | 同一套名称 | 仅固定错配 AE |

OE＋AE 是主检查；AE-only 是提前规定的定位对照，判断对象描述是否干扰属性辨别。每组合都是九个等权文本单元：三条 AE × 三条 OE；AE-only 每条重复三次；名称重复九次。固定逐句归一化、余弦均值和温度 0.05，不搜索模板、聚合权重或温度。

编码时为每张图计算全部 12×16 候选；评价时取真实对象下的全部 16 属性。这是 **GT-object 条件属性机制诊断**，不是最终推理成绩，不能把它的准确率当 CPF CW/OW AUC。它能够帮助区分“更容易认出鞋型”和“同一种鞋型里更能辨别材质”。

常见情况：

| 输出／状态 | 含义与处理 |
|---|---|
| `STOP: preserve existing path` | 重复首次启动的保护。先核对第一次进程和日志，不删除目录 |
| `Historical input changed` / `Wrong reviewed knowledge bank` | 旧资产与归档不一致；停止并发我日志，不跳过 SHA |
| `No exact image path` | CPF 路径和 metadata 原图路径均不可访问；不会猜同名图，发完整路径输出 |
| `CLIP checkpoint SHA mismatch` | 不是锁定的官方 ViT-L/14 权重；保留原文件，发路径与 hash |
| 下载超时／连接失败 | 已完成的图片预检保留，不能据此认定知识方法失败；可按下面方法补权重后恢复 |
| `Partial dependency directory` | 依赖安装中断，目录保留；发日志，由我核对后给恢复步骤，不改 cpf 环境 |
| CUDA OOM | 先确认是否他人占用 GPU；无并发时可在下面恢复命令添加 `--batch-size 16` |
| DataLoader worker 报错 | 发具体 traceback；若是 worker 资源问题可用 `--workers 0` 恢复，不掩盖图片损坏 |
| `execution_passed False` | 异常诊断 ZIP，不是成功结果；其中有 failure traceback，可以下载给我 |
| gate False + `execution_passed True` | 正常完成的阴性结果，下载分析，不继续追加训练 |

## 7. 我会怎样判断结果，再决定下一轮

主要看官方 VAL unseen 的**按组合平均条件属性准确率**，同时报告逐样本 micro，防止被 Leather 等高频类主导。两套错配逐个比较，不只取平均。

预设投入门槛（不是显著性或 SOTA 标准）：

1. 正确教师相对名称的 VAL unseen 组合 macro 至少 +1.0 个百分点。
2. 正确教师相对每套匹配的错配教师分别至少 +1.0 个百分点。
3. VAL unseen micro 不低于名称，TRAIN 组合 macro 不低于名称。

正确 OE＋AE 通过，才考虑完整知识教师；只有 AE-only 通过，才考虑 AE-only 教师。还要看逐类混淆、名称→知识净纠正、相对 C_text 的互补性，以及按组合 bootstrap 区间。不把相似度/NLL变好、正确仅胜错配、或单类提升直接当知识已有效。

如果两个门槛都不通过：不进入五组教师正式训练；保留 Generic＋25% 的工程增益结论，只针对 TRAIN 失败做一次描述可见性／适用性检查。该结果只限制当前冻结教师、描述与配方，不证明所有知识或视觉语言模型都无效。

## 8. 通过后才实现的教师 pilot：保持原方案的归因问题

这一节是下一阶段设计，不是现在可执行的训练命令；本发布包不含正式教师训练程序。先收到探针结果再锁定训练实现，避免在无信号时继续消耗预算。

默认保持原 Generic 的 60864 参数、原初始化／训练顺序／十轮预算，以及固定 `0.75*q_base + 0.25*q_head` 推理读出。原标签 CE 仍作用于未混合 head，不能同时改成混合 CE 后把收益都归给教师。

教师 pilot 仅比较无教师、名称教师、正确知识教师、两套错配教师。**学生的知识输入在所有教师组中固定一致**，默认沿用当前正确 v2 知识槽；不能教师换成错配时又同时改学生语义槽。这样新变量才只有教师监督的内容。无教师参考可在严格重放一致后复用已有 G_K，不直接把任何未核验旧曲线算作严格对照。

教师只提供 TRAIN 上的样本相关条件分布，增加匹配强度的 KL 监督；不让 VAL/TEST 标签进入训练，不用组合存在性过滤候选。名称和错配教师同架构、同温度、同额外优化预算。正确教师必须超出无教师、名称及两套错配，才能把新收益归给知识内容，而不只是 CLIP 或蒸馏。

这仍服务于原 0601 路径 3：“知识直接参与条件属性估计”。如果学生推理时继续读取显式知识槽，可以继续研究 `p(a|x,o,K)`，但还需要知识替换／撤除和未见组合对照证明它真的被利用。若以后把学生也改为名称输入、只在训练目标中使用知识，论文主张必须收窄为 `p(a|x,o;θ_K)`，不能把纯训练监督写成推理时显式知识条件。

正确教师 pilot 有独有增量后，才考虑改 CPF 内部属性视觉交互、适用性学习、多 seed 和跨数据集；本轮不同时开展这些改造。
