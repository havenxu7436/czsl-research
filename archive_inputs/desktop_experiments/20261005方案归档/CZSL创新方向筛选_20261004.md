# CZSL 创新方向筛选与投入建议

日期：2026-10-04。依据：当前 A/C/D/E 的 UT-Zappos 验证结果、lambda 后处理选择结果、实际 CPF 代码快照，以及用户提供的 USG 方案。本文提出的是待检验的研究假设；未运行新实验，也未改变服务器文件。

## 1. 当前最合理的结论

**如果优先目标是用现有资产尽快得到可信的增量结果，建议先做“视觉与对象条件下的知识增量选择”，以 C 为起点，而不是继续扩大固定 K 的 lambda 搜索。**

它的具体形式是：保留 C 已有的平均知识表示，把各条描述相对于平均描述的差异单独保存；根据当前图像和候选对象，选择其中能提供额外判别信息的部分，允许选择“本次不补充知识”。暂称 **EKR-CPF：Evidence-conditioned Knowledge Residual CPF**。

这里的“最可靠”是相对投入顺序：已有文本增益提供了起点，模块小，有明确退回 C 的路径，可以早期排除无效机制。**目前没有任何一个新 idea 已被证明会超过 C，更不能保证发表。**

上一轮更倾向 USG，是因为它的研究问题比较清楚。本轮用户强调收益可靠性和可执行性，因此把已有文本证据置于结构不确定性假设之前。USG 仍值得小规模验证，但不建议直接投入完整随机图、条件头和多项正则的全套实验。

## 2. 已有结果支持什么

下面全部是当前单数据集、单 seed、MVP 预算下的 **validation** 指标，单位为百分数；不是最终 test 结果。

| UT-Zappos 验证指标 | A | C | C−A，百分点 |
|---|---:|---:|---:|
| CW AUC | 39.470 | 44.262 | +4.791，以未四舍五入数计算 |
| CW HM | 54.841 | 57.894 | +3.053 |
| OW AUC | 25.492 | 32.079 | +6.587 |
| OW HM | 37.269 | 46.367 | +9.097 |

这支持“在当前设置中，知识文本有用”，不能直接证明条件路由、图传播或鲁棒知识学习有效。跨 seed、MIT-States、C-GQA 的稳定性仍需验证。

Dpost 和 Epost 在已检查的 `{0, 0.025, 0.05, 0.1, 0.2}` 网格与约束下选到 lambda=0，说明本次没有找到可采用的正强度固定校准。它不等于所有形式的外部知识都无效，也不等于所有正 lambda 在所有指标上都下降。

当前知识是 `bulk_trusted_unverified` 的重构版本。结构检查通过、OOV 较低、pending_review=0，都不能代替语义正确性验证。

## 3. 四个可以考虑的 idea

下表的收益判断是依据现有资产作出的定性判断，不是统计成功率。所有“创新空间”都需要进一步通过最近邻方法与机制对照检验。

| 优先级 | Idea 与具体机制 | 为何可能有收益 | 相对成本与风险 | 创新边界 |
|---|---|---|---|---|
| **1，主线** | **EKR：条件知识增量选择。** C 的平均知识保持不变；描述差异进入小型图像/对象条件路由；设置零补充选项 | 直接承接 C 的文本收益；避免重复放大平均语义；知识无额外信息时可以退回 C | 成本较低；主要风险是 GloVe 描述差异没有视觉意义，或收益只来自普通注意力 | 研究点是“平均知识之外的增量证据是否具有条件用途”，不是门控、多描述或残差本身 |
| **2，备选** | **CBK：同对象易混淆属性的判别知识学习。** 用 train 内同对象错误建立属性混淆组，训练描述差异支持的相对分类间隔 | 将泛化描述改成局部判别信息；若 C 的错误集中在同对象属性混淆，问题与损失更匹配 | 中等成本；需先看错误分布；硬负样本也可能增加噪声或强化训练共现 | 新增价值必须超过普通 hard-negative loss、条件属性头和类频率重加权 |
| **3，备选** | **VKD：按可靠性筛选的条件知识蒸馏。** 训练时使用描述教师，只蒸馏在 train 内独立划分上改善标签似然的信号；推理时用学生 | 减少推理知识分支与错误文本干扰；适合训练有益、推理开销受限的情况 | 中等成本；教师若无增益，蒸馏不会创造增益；需要独立 train 内校验，避免自证可靠 | 蒸馏本身不是创新；需要证明条件筛选比普通蒸馏和阈值置信度筛选更有效 |
| **4，独立路线** | **USG-Lite：知识关系不确定性建模。** 按现有方案学习 OI/OE/AE 候选边概率，并平均多张图的预测 | 如果关系结构本身有用且噪声可识别，可能改善识别与受污染知识下的稳定性 | 较高成本；确定图、随机边、KL、采样数、校准协议均需对照；结构价值尚未被当前 C 结果证明 | 候选贡献是任务相关的外部知识关系不确定性；不能只靠“随机边+MC”宣称首次或有效 |

### 3.1 CBK 的最小筛选实验

1. 从 train 的独立诊断划分上记录 C 的错误，区分“对象正确、属性错误”与“对象错误”。
2. 对对象正确的错误统计属性混淆组，至少有足够支持数才使用，不根据 test 错误挖负样本。
3. 使用相同预算比较普通 CE、普通同对象 hard-negative、描述差异约束三个版本。
4. 若普通 hard-negative 已解释全部收益，保留为训练改进，不单独包装成知识创新。

对象条件属性已是已有研究主题，CANet 明确讨论对象和图像条件下的属性表示；因此，新增条件输入本身不足以构成贡献。[CANet 原论文](https://arxiv.org/abs/2305.17940)

### 3.2 VKD 的最小筛选实验

1. 首先要求知识教师在独立 train 内划分或 validation 上优于 C。
2. 对照普通蒸馏、按教师置信度筛选、按额外知识的标签似然改善筛选。
3. 筛选规则只能使用 train 内标签；正式 validation 用于预先限定的配置选择，test 只用于最终评价。
4. 若教师不优于 C，停止蒸馏路线。若选择性蒸馏与普通蒸馏相同，只保留部署价值。

### 3.3 USG 的最小筛选实验

只先完成同输入的三个版本：C、确定性关系加权、USG-Lite。确定图与随机图均需使用 C 的知识起点，而不能让 USG 独占更丰富的文本。

若确定图不优于 C，先查关系表示与普通描述加权是否等价；若随机图不优于学习均值图和匹配采样次数的 EdgeDrop，不进入完整条件 USG。这样可以降低一次引入多个机制造成的归因困难。

## 4. 为什么不直接推荐“多原型”“加门控”“换 CLIP”

这些技术可以是合理组件，但现在直接作为创新点风险较高。

| 最近邻工作 | 已有覆盖 | 对本项目的限制 |
|---|---|---|
| CPF | 通过文本描述与对象指导的视觉关注改善组合表示 | “把描述放进 CPF”首先应算强基线或知识输入变体 |
| CANet | 图像与对象条件属性表示 | 不能把一般的 `attribute(x, object)` 作为新命题 |
| EVA | 专家适配与语义变体对齐 | 不能把多专家、图像相关语义选择本身当成空白方向 |
| ClusPro | 原语内多原型发现与更新 | 不能把从单原型改成多原型当成独有贡献 |
| LGPro | 用语言描述初始化并约束视觉原型 | “LLM 描述指导多原型”已有直接近邻；本项目需比较机制而非换名字 |

来源：[CPF](https://openaccess.thecvf.com/content/ICCV2025/html/Wu_A_Conditional_Probability_Framework_for_Compositional_Zero-shot_Learning_ICCV_2025_paper.html)、[CANet](https://arxiv.org/abs/2305.17940)、[EVA](https://arxiv.org/abs/2506.20986)、[ClusPro](https://arxiv.org/abs/2502.06501)、[LGPro 作者稿](https://openreview.net/pdf/9f7909c7a01f43fca8a0f9ec0f7258e97882e802.pdf)。此处只使用方法内容，不依据网页模板判断 LGPro 的会议录用类型。

检索覆盖这些近邻，不构成全领域无重复证明。准备论文前，还需对“知识残差、文本去冗余、带空选项注意力、稳健蒸馏”等机制做完整检索，并选择兼容 backbone 的代表方法复现。

## 5. 推荐怎样投入

**先选 EKR 作为唯一主线，USG 保留为独立候选。** 具体设计见：[EKR-CPF 完整设计](C:/Users/llenovo/Documents/ChatGPT/CZSL/EKR-CPF_条件知识增量选择_实验设计方案.md)。

推荐顺序：

1. 冻结当前 A/C 和 lambda 诊断结论；完成已计划的 MIT/C-GQA A/C 检查，确认知识输入问题值得继续。
2. 从同一个 C checkpoint 开始，做 EKR 小分支和普通条件适配器对照，先冻结 CPF 主干。
3. 若初筛有增益，增加普通注意力、静态权重、去对象条件、去差异中心化、文本打乱对照。
4. 只有当 EKR 优于强对照且跨 seed 稳定，再做全模型匹配预算微调与最终 test。
5. 如果收益只来自额外训练或普通融合，按真实结果记录为工程改进；不继续叠加模块追求一个看起来复杂的模型。

“保留 C 的已有收益”和“新模块带来创新增益”是两个判据。论文中的新增效果必须以 **EKR−C** 为核心；不能把已有的 C−A 全部重新归给 EKR。
