## 1. 先给判断

**当前版本不应直接进入原阶段 C；值得再做一次有明确对照、预算有限的结构改进。** 诊断支持“已训练分支依赖正确的描述映射”，但描述分支在 TRAIN 和 VAL 上均弱于名称对照。现有空槽没有表现出有效拒识功能，对象条件的实际作用也小。

优先解决的是：**保留有效的名称基底，单独检验描述的增量价值，再判断是否需要学习描述值与视觉特征之间的对齐。** 当前证据不支持先扩训练轮数、放大残差系数，或把对象交互和拒识损失一起堆入模型。

旧阶段 B `proceed=false`、旧语义归因 gate 均保持不变。本诊断没有训练、没有新模型性能结果，也不等于通过研究门槛。

| N_shuffle | 42.999192 | +0.180552 | 29.500758 | +0.035886 |

N_clean 对 N_name 的 CW AUC 差为 **−0.256764 pp**，对重新训练的 N_shuffle 差为 **−0.132762 pp**。本次只是重新读取相同最佳权重，指标精确一致，所以不能把这次诊断计作一个新的训练 seed 或一次新的性能提升。

## 4. 新发现：正确映射有相对价值，但不是“语义贡献已经成立”

冻结同一个已训练 N_clean，保留属性自身名称的原始向量，换成其他属性的 AE 描述，再推理：

| 描述排列 seed | CW AUC (%) | Δ vs 原 N_clean (pp) | OW AUC (%) | Δ vs 原 N_clean (pp) |
|---|---:|---:|---:|---:|
| 11 | 42.757602 | -0.108829 | 29.334185 | -0.167573 |
| 22 | 42.706835 | -0.159596 | 29.415959 | -0.085800 |
| 33 | 42.624158 | -0.242273 | 29.415959 | -0.085800 |

三次排列都使 AUC 下降；平均下降 **CW 0.170232 pp、OW 0.113058 pp**。名称对照 N_name 更换 AE 后，全量分数完全不变，说明这项诊断没有把描述输入泄露进名称对照。

这支持：当前分支对描述映射敏感，正确匹配比这三种错配更合适。**它仍不能证明模型理解了描述事实，或证明描述优于名称基线。** 固定描述也可能提供类别代码或分布特征；推理时破坏一个已学映射会产生分布变化。

特别注意两种 shuffle 对照的区别：

- `N_shuffle_original` 是用错配字典重新训练并选择最佳权重的模型。
- `N_clean_ae_permutation_*` 是正确字典训练好的同一模型，在推理时临时更换描述。

因此“推理错配下降”与“训练错配对照比 clean 更强”可以同时出现，不能互相替代。

另外，当前 clean 值向量经过四槽均值中心化。更换 AE 后会重新计算均值，所以连名称槽的中心化 key/value 也会变化。这个干预测的是**整套描述映射变化的作用**，不是在完全固定名称残差的条件下，仅测 AE 槽的独立因果贡献。三组排列也不是三组训练 seed，不构成统计显著性证明。

## 5. 没有明显的“TRAIN 有优势、VAL 丢掉优势”模式

定义 margin 为真实组合分数减去当前最强错误组合分数；每次都重新寻找最强错误组合。CE 采用原分数温度 0.05。margin 越大越好，CE 越小越好。

| 视图 | N_name margin Δ vs N0 | N_clean margin Δ vs N0 | N_name CE Δ vs N0 | N_clean CE Δ vs N0 |
|---|---:|---:|---:|---:|
| TRAIN 平衡子集 | +0.004772 | +0.002712 | -0.099285 | -0.053875 |
| VAL CW | +0.004507 | +0.002110 | -0.116192 | -0.054496 |
| VAL OW | +0.004453 | +0.002099 | -0.115494 | -0.054209 |

描述分支在 TRAIN 和 VAL 都改善了总体平均 margin/CE，但名称分支在两边均改善得更多。因此，当前证据更支持“描述分支还不够强”，没有定位出一个清晰的、只在 VAL 才出现的竞争力丢失。不能据此直接诊断过拟合或保证增加训练有效。

TRAIN 这里只是 498 张按 pair 平衡采样的图像，使用固定 VAL 变换、83 个训练候选。VAL 使用不同的候选集合和组合分布；两边绝对 CE/margin 不应直接当作同分布泛化差距，只适合在各自视图内部配对比较。

改善幅度也解释了为什么预测几乎没变：OW 基础模型的 margin 中位数约 **−0.218447**，而 clean 平均只加 **0.002099**。70.41% 的 VAL 样本 margin 上升，但很多样本仍远未跨过决策边界。

在 **bias=0 的诊断点**，OW clean 只改变 11/3214 张预测（0.3423%），纠正 0 张、破坏 2 张，所有变化都是属性变化，对象变化 0 张。此时 seen 的平均 margin 变化为 −0.002770，unseen 为 +0.003926；unseen 正确率仍为 7.103124%。这说明很多变化只是轻微调整 seen/unseen 的相对分数，并没有足够纠错幅度。

这不是“原生 AUC 没有收益”的另一个证明：bias=0 是曲线上的一个点，AUC 汇总不同 seen/unseen 偏置，判断是否过性能门槛仍应使用原先固定的原生 AUC 与保护指标。

## 6. 两个机制尚未发挥预期作用

### 6.1 空槽没有表现出可靠拒识

VAL CW clean 的全候选平均空槽权重为 **0.059593%**；真实候选平均为 **0.070234%**。在全部 CW/OW 候选注意力中，空槽权重大于 0.5 的项数都是 0；不是把 0.059593 当作 5.9593%。

错配 AE 后，真实候选的平均空槽权重从 0.070234% 变为 **0.053189%**，没有出现平均拒识增强。直接移除空槽并重归一化，CW/OW 原生 AUC 都不变，预测也不变；平均分数变化只有约 9.0e−7 / 7.4e−7。

结论限定在这个已训练权重：**当前空槽没有显示出拒绝这些错配输入、或改善实际预测的功能。** 不能声称“已有可靠性控制”。训练没有给它清晰的坏知识拒识目标，是一种待验证的解释；本实验并未单独证明失败原因。

N_name 的 CW 平均空槽权重约 76.66%，说明空槽并非代码上不能工作，但两类分支的固定值几何结构不同，不能仅凭这个差异决定应当把 clean 的空槽调到多少。

### 6.2 对象条件有数值影响，但作用小

只错配对象名称上下文后，平均分数变化为 CW **3.30e−5**、OW **3.83e−5**，约为原分支平均绝对残差的 **1.63% / 2.30%**。两种视图各只改变 1 个原 clean 预测；正确数不变，AUC 变化仅约 +0.007953 / +0.006684 pp。

另一个检查不依赖这一次排列：OW 中，同一图像、同一属性，跨 12 个对象的残差偏离对象均值的平均绝对量，只占平均绝对残差约 **1.56%**。两项证据共同指向当前对象条件依赖较弱。

这是一项排列与一个权重上的诊断，不等于证明对象信息永远无用。当前也没有依据把“强对象条件推理”作为已经成立的创新主张。

## 7. 下一步优先路线与停止条件

### 第一优先：保留名称基底，检验描述增量

当前的两个分支虽然可训练参数数目相同，函数结构并不相同：

```text
N_name:  四槽都是名称；value = 名称单位向量 / 2
N_clean: 名称 + 三条描述；value = (各槽单位向量 - 四槽均值) / 2
```

clean 同时加入描述、改变名称值向量、消去槽共同成分。它与 N_name 的差距可能包含值构造带来的影响，不能全部解释为“描述质量差”。这仍是待检验的原因，不是本次已经证明的根因。

建议另立 v2：所有候选实验共享同一个冻结名称基底，描述作为额外分支；描述增量的初始化应能精确退化回该名称基底。可先测试以自身名称为锚的描述差向量，让名称基底不随描述错配和中心化一起改变。

```text
shared baseline = frozen A_unit score + frozen N_name residual
v2 score = shared baseline + description increment
description value candidate = (description unit vector - own-name unit vector) / 2
initial description gain = 0
```

这只是一个最小改动的候选设计，**名称差向量并不保证更好或具有论文创新性**。第一轮先隔离这个问题；若描述仍在 TRAIN 上弱于等参数名称对照，再单独检验共享的低秩 value 投影是否能改善与 CPF 属性特征的对齐。不要同一轮同时改变名称底座、value、对象查询和损失。

新 pilot 至少保留以下对照，额外分支保持相同参数容量、数据、预算、初始化规则与选择策略：

| 项目 | 用途 |
|---|---|
| 共享名称基底、描述增量关闭 | 验证确实有增量收益 |
| 正确描述增量 | 候选方法 |
| 固定错配描述增量 | 检验正确描述归因 |
| 同等容量的名称增量 | 排除只靠额外适配容量获得收益 |

先用 seed 0、小预算 3 轮做筛选。原先 0.2 pp 的 pilot 标准可在新 v2 协议里事先重新固定，必须同时超过共享基底、名称增量和错配增量，并沿用 HM/OW 保护条件；旧 gate 文件不修改。通过后才考虑 3351、2026 的配对确认，而且这些 seed 的共享名称底座也需要在相同规则下准备，当前 seed 0 权重不能替代所有 seed。

### 第二优先：增量有效后，再训练拒识

只有正确描述增量先有稳定贡献，才值得另加 TRAIN 内知识错配的可靠性训练，让模型学会在不可靠输入下回退到名称基底。坏知识检测损失、正确描述性能损失、同等预算对照要分别验证。当前不能把“空槽很小”直接当作加一项拒识损失就会提升 AUC 的证明。

### 暂后：更复杂的对象交互

现有对象条件效应很弱；在值构造与描述增量仍不成立时，扩大对象交互结构会增加归因难度。待描述增量通过对照后，再判断需要什么对象条件，并用去对象/上下文错配和跨对象差异检验真实贡献。

### 明确止损

如果这个有限 v2 pilot 仍不能超过名称与错配对照，停止继续堆叠该描述残差路线；保留结果，再依据完整资料选择新假设。不删除负 seed、不用观察结果后放宽门槛、不直接重跑原阶段 C，也不因为当前失败就把全部 CPF 基线与审核工作判为无意义。

## 8. 目前能和不能对导师汇报什么

可以说：基础实验及权重回放完整；正确映射在冻结模型干预中相对错配有优势，但描述模型弱于名称对照；空槽拒识和对象条件作用未达到预期，下一步将先隔离名称值构造与描述增量。

不能说：已经完成有效 EKR；描述语义贡献已被严格证明；有三个新训练 seed；空槽具有可靠拒识；已证明对象条件创新；提高训练预算一定能成功。

当前样本仍是 UT、seed 0、已用于开发的 VAL。不能从这轮结果估计一个可信的“成功概率百分比”。论文级结论需要多 seed 配对确认、独立最终评价和相关工作核查。

本轮对照都是现有 EKR 分支的输入干预，**没有转向随机语义图，也没有构建新的图结构。** 前序实验给出了基线、排错证据和明确的失败边界，可以复用来支持下一轮设计。
