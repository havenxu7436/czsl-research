## 3. 每句具体填什么

| 填写项 | 写法 |
| --- | --- |
| 知识类型 | 视觉形态／材料来源／性能触感／名称锚点；必要时可拆分同一句不同部分 |
| 可见性 | 可见／部分可见／未显示／非直接视觉；低分辨率看不清必须明记 |
| 支持证据 | 图板文件名＋面板编号，说明看到的形状、结构、外观 |
| 反例或证据不足 | 面板编号＋原因，如“粗跟与 narrow 不符”“内衬未显示” |
| 跨组合检查 | 材料描述跨鞋型、对象描述跨材料检查，避免绑定单一另一因素 |
| 共享与重复 | 是否与别的类别共有；本类三句是否只换同义词 |
| 处理 | 保留／改写／移出可见描述／待核验 |
| v2 英文候选 | 保留时填原句；改写时写候选短句并记录改动依据 |

来源、透气、防水、柔软等知识可以正确而不直接可见，不能都按“图上看不出”判错。若决定保留，应记录其类型；若移出视觉描述，说明是否另保留。视角没有显示的部位，也不能直接推断不存在。

面板编号只在本图板内有效；不要只写“第2张”。若要查具体文件身份，可查看 selected_train_images.json：各类别 selected 数组第一个元素对应面板1，第二个对应面板2，以此类推。

## 4. 两个已实际查看的填写示例

以下为助手对两张图板的初步观察，帮助示范记录方法；不是84句已完成核验，也不是已冻结的修订。

### Heels：不要把整个类别限制为细跟

图板：[Heels 训练图板](<C:/Users/llenovo/Desktop/UT_description_review/ut_train_review_images_20261006_v1/boards/o_07_shoes_heels.jpg>)。

- 原句：`elevated narrow heel`。
- 图像观察：面板1、9、13、17能看到细跟；面板2、5、20为较宽的跟，面板6、15、18可见坡跟样式。
- 处理草稿：改写，去掉对整个类统一要求 `narrow` 的限定。
- 英文候选：`footwear with a raised heel`，仍待复核。面板11、12、19跟部较低，该表达的覆盖与区分性仍有限，不能把它当作全部类别样本的充分定义，也不能直接凑成三句近义话。
- 因此这组先解决明显范围问题，再与本类其余两句一起决定最终三句。

### Oxford：不要把对象类统一绑定 leather

图板：[Oxford 训练图板](<C:/Users/llenovo/Desktop/UT_description_review/ut_train_review_images_20261006_v1/boards/o_09_shoes_oxfords.jpg>)。

- 原句：`structured leather quarters`。
- 图像观察：面板2、7、12、17标签为 Canvas，其中2、7有布面外观；同类还有 Synthetic 样本。可见图板的材料范围较宽，要求统一 leather 不合适。
- 处理草稿：改写或换一个有依据的对象结构线索；不能仅凭 Canvas 标签断定每个部件都不含皮革。
- 新句暂不强填：面板17、18的鞋面看不到鞋带，因此也不能直接换成要求全类均有封闭系带的句子。先记录数据集实际外观范围，再选择较可靠的对象线索。

这一步不改 metadata 的标签，也不把范围较宽的样本自动当作数据错误。

## 5. 这一节怎样算完成

完成26句 P1 后继续58句 P2；每类三句都要检查覆盖、共享与重复。最终核验表要包含84句的处理结论、证据或非视觉知识的保留理由、候选英文、实际复核人与日期。

保持16材料＋12对象的标签、顺序、每类三句以及原 GloVe 设置。某类暂时无法形成三句可靠候选时，保持 draft 并说明原因，不强行补词。性能／来源知识不必全部删除，但不能伪称图像直接支持。

表中所有“待核验”须解决或明确保留为尚未完成；未完成的草稿不能直接当作已经批准的训练字典。

## 6. 核验结束后再接训练

依次进行：

1. 从已核验的表生成独立 v2 `ae_dict.json`、`oe_dict.json`、逐句改动记录与来源／SHA256；保留原 v1。
2. 建立 v2 缓存和 bank，接入 v2 实验路径。目前旧 `make-configs` 仍固定旧缓存并检查旧 hash，不能只改文件名直接开跑。
3. 固定三 seed＝0、3351、2026；新增 `C_text_v2` 和 `C_shuffle_v2` 各3项、每项10 epoch。名称对照 A_raw／A_unit 只有来源和协议一致时才能复用，否则补齐。共新增6项或12项训练。
4. 汇总新 v2 gate：C_text_v2 相对 A_unit 和 C_shuffle_v2 的三 seed 平均 CW AUC 都至少＋0.5 pp，分别至少2/3 seed为正，并满足原其余 guards。旧 gate=false 保持原样。
5. v2 门槛通过后，进入同一锚点、同一预算的 R0／R3／R5／R7 四组 EKR 小实验；未通过时按原停止条件决策，不能仅凭完成图像核验宣称可以正式进入 EKR。

这一步的作用是产生更有依据的知识候选。是否带来收益，仍需后面的配对训练验证。
