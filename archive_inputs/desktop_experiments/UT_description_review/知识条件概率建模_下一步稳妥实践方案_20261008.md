# 知识条件概率建模：下一步稳妥实践方案

日期：2026-10-08。状态：设计方案；尚未实现服务器训练包，尚未运行新模型。这里的超参数和筛选规则是拟定设置，不是已证实最优设置。

推荐主线：在现有强 C_text 基线上，建立可回放基线的属性条件概率模型；用候选对象、图像和经审阅的 OE/AE 知识形成低秩属性证据，并直接用条件似然训练。先验证这一步，再增加 OI、逻辑损失和联合微调。视觉原型仅作为辅助诊断，不作为主线。

## 1. 依据与需要修正的判断

原方案核心是知识参与 P(a | o,x,K)，而不是任意加入一个条件分布。原文件第 0 节和第 3.3 节明确提出知识条件属性预测及可微知识模块。

CPF 本身已用对象、属性和组合概率进行训练，论文推理时采用加法融合。本地冻结源码的推理是三项未缩放 cosine 分数相加。因此，不能把“新增 softmax”当成知识贡献，也不能声称原 CPF 没有概率训练。要验证的是正确知识进入属性条件分布后，是否带来额外收益。

## 2. 范围：先验证原方案中的一个核心命题

第一阶段只检验：在共同冻结的强 C_text 模型上，正确的 OE/AE 知识能否改善候选对象下的属性概率，并转化成组合预测增益。

这属于原方案路径 3。知识仍来自 OE/AE 等外部语义来源；不把 TRAIN 视觉均值改名为 K，不引入随机语义图。

第一阶段保留：backbone、v2 知识原文、GloVe 编码、split、原 evaluator、CW/OW、相同 seed 和图像顺序。

第一阶段只新增：候选对象条件的低秩知识模块、条件分布归一化、对应条件似然损失。

第一阶段关闭：静态 compatibility prior、额外 logic loss、复杂多描述路由器、独立可训练 pair lookup、backbone 微调。OI 原文保留，后续作为对象语境增量单独检验，不在首轮同时接入全部组件。

所有控制共享 C_text 的已有知识和权重。因此，名称对照表示“没有新增描述分支”，不是整个模型从未使用知识。第一阶段证明的是新增条件知识的增量；完整的总知识消融需在后续用 A_unit/名称起点重建同一组对照。

## 3. 概率设计：先保住基线，再引入知识

### 3.1 为什么不直接丢掉原组合分支

把三项原分数直接换成原 object head 与新 attribute head 的概率乘积，既改变知识模块又改变融合规则，可能丢掉原组合分支的信息。下降后很难判断原因。

首轮采用原完整分数定义的参考联合分布。这是新模型的明确概率定义，不声称它等于 CPF 论文的原 object head。

设 s_B(x,o,a) 为冻结 C_text 在完整对象×属性网格上的原分数，T=0.05 固定，不进行温度搜索。定义：

$$
P_B(o,a\mid x)=\frac{\exp(s_B(x,o,a)/T)}{\sum_{o',a'}\exp(s_B(x,o',a')/T)}.
$$

其对象边缘分布与属性条件分布为：

$$
P_B(o\mid x)=\sum_a P_B(o,a\mid x),\qquad
P_B(a\mid o,x)=\operatorname{softmax}_a(s_B(x,o,a)/T).
$$

这里的 P_B(o|x) 是冻结原联合分数诱导的对象边缘，可能与原对象辅助分类器的分布不同。B 的参数和已有文本输入共同固定；本轮新加入的 K_cond 只改变属性条件分布，不改变这个边缘分布。

### 3.2 知识进入条件属性概率

用实际依赖 x、候选 o、属性 a 和知识的模块生成 Delta_K：

$$
P_\theta(a\mid o,x,K_{\mathrm{cond}};B)
=\operatorname{softmax}_a\left(\frac{s_B(x,o,a)+\Delta_\theta(x,o,a,K_{\mathrm{cond}})}{T}\right).
$$

$$
P_\theta(o,a\mid x,K_{\mathrm{cond}};B)
=P_B(o\mid x)P_\theta(a\mid o,x,K_{\mathrm{cond}};B).
$$

这是明确的知识条件联合模型。它不是对原分数任意 sigmoid，也不把 GloVe cosine 当成事实成立概率。K_cond 是新增的条件知识；若讨论整个模型的全部 K，必须把 B 已有知识的依赖也交代清楚。

### 3.3 与原 evaluator 接口保持一致

令 LSE 表示 logsumexp。原分数单位下的等价读出为：

$$
s_\theta=s_B+\Delta_\theta
-T\left[\operatorname{LSE}_a\left(\frac{s_B+\Delta_\theta}{T}\right)
-\operatorname{LSE}_a\left(\frac{s_B}{T}\right)\right].
$$

该表达式是 T log P_theta 加一个只依赖图像的常数。它保留对象边缘，并让知识重新分配每个对象下的属性质量。

Delta=0 时直接返回原 s_B，精确回放原分数及 evaluator 输入。这解决“换概率头就把基线换没了”的混淆。

必须先在完整属性×对象网格定义分布，再应用原 CW/OW candidate mask；不能先在 CW 子集重归一化、在 OW 子集又定义另一模型。seen/unseen bias 扫描仍按原 evaluator 执行。加 bias 后的评分用于原 AUC/HM 评价，不再宣称每个扫描点仍是同一归一化联合概率。

关闭知识只证明接口正确，不能证明知识有效。该分布分解本身也不作为创新主张。

## 4. 最小知识模块：从条件交互开始，不再先堆路由

### 4.1 输入与结构

使用已审阅 UT v2 的 OE 和 AE。各条描述保留原文、类型、归属和 mask；首轮在类型内固定平均编码，不学习多描述 attention。

记 f_a(x) 为冻结模型的 300 维属性特征，e_o/e_a 为原语名称表示。k_o、k_a 为名称与 OE/AE 经不同类型投影形成的低秩表示。候选形式为：

```text
q(x,o) = LayerNorm(U_v f_a(x) + U_o e_o)
k_o = U_name e_o + U_OE mean(OE[o])
k_a = V_name e_a + V_AE mean(AE[a])
r(o,a,K) = LayerNorm(k_o * k_a)
Delta(x,o,a,K) = c * tanh(w_out dot (q(x,o) * r(o,a,K)) / sqrt(rank))
```

`*` 是逐元素乘法。rank=32、c=0.10 为拟定初值。类型投影共享于所有标签；不设置每个 pair 的独立参数。候选对象通过 q 与知识语境同时进入属性估计。

最后的 w_out 零初始化，其余投影正常初始化。初始 Delta=0，输出复现 B；第一步 w_out 可获得梯度，之后上游投影获得梯度。不能把所有层和全局乘子同时置零，导致整条路径无梯度。

这里的 Delta 是条件概率 head 内部的图像—对象—知识证据。与先前 SG-EKR 的固定描述 cosine value 加全局 gain 不同，但仍是待验证的低秩原型，不能因结构变化就断言一定改善。

低秩交互、残差和归一化都是已有通用组件。研究贡献必须由正确知识对照、对象条件消融、泛化与关系利用证据建立。

### 4.2 为什么先固定描述聚合

当前最关键的问题是正确知识能否在条件属性任务中产生增量。先去掉可自由改变描述权重的路由，可以避免同时解释“是否选对描述”“value 是否漂移”“null 是否退化”“全局 gain 是否变号”。这只是降低首轮归因复杂度，不是证明平均表示最优。

同知识普通拼接/MLP 融合是必须保留的对照。如果普通融合更好，应优先采用有正确知识证据的简单实现，不为保留一个结构名称反复调模块。

### 4.3 训练目标

在训练图像的真实对象 o_star 下，监督全部属性类别：

$$
\mathcal L_{\mathrm{cond}}
=-\log P_\theta(a_\star\mid o_\star,x,K_{\mathrm{cond}};B).
$$

对象边缘冻结时，加上 -log P_B(o_star|x) 即联合负对数似然，但这项是常数，不会更新对象预测；不能宣称首轮联合微调了对象头。

不只在该对象的 seen 属性子集上计算 CE。所有实验使用相同完整属性词表，不使用训练组合频次或 seen/unseen 身份构造知识惩罚。推理对所有候选对象评分，不能用对象 argmax 硬选一路。

首轮不额外加入逻辑损失、蒸馏损失或多套损失系数。使用小模块、固定证据幅度与 weight decay 限制变化；若仍有灾难性退化，诊断并另立有限修订，而非不断叠加新损失。

## 5. 首轮实验：五个训练身份与一个冻结参考

| 身份 | 新分支内容 | 回答的问题 |
| --- | --- | --- |
| B_frozen | C_text 原模型，无新增训练 | 强基线与精确回放 |
| P_name | 同条件交互结构，只新增名称输入 | 参数、额外训练和候选对象作用 |
| P_K | OE/AE 正确归属的类型交互模块 | 主要候选 |
| P_generic | 同 OE/AE 条目，用共享拼接 MLP 普通融合 | 特定交互结构是否必要 |
| P_perm1 | 与 P_K 同结构，OE/AE 归属固定错配 1 | 正确知识内容的作用 |
| P_perm2 | 与 P_K 同结构，OE/AE 归属固定错配 2 | 减少依赖一个偶然置换 |

第一轮 OI 关闭，因此 perm 控制只需覆盖 OE/AE。原语名称不打乱；条目数量、类型和可用性 mask 保持匹配。两个无固定点置换在新 VAL 评估前固定，全部保留结果，不能挑最弱的一个比较。

P_name 和 P_K 采用相同可训练投影结构；名称对照的额外语义槽用同类名称编码填充，避免用不同 mask 暗示身份。P_generic 需按有效更新参数量匹配或明确报告差异，不能挂不参与 forward 的参数伪造匹配。

同 seed、同基础 checkpoint、同数据顺序、同固定 transform、相同优化步数和选择规则。初始化共享的张量逐项核对，不能因控制的构造消耗 RNG 导致初始参数不同。

首轮在冻结特征缓存上训练，因此不存在 backbone 新训练的公平性混淆；也要明确冻结 backbone 已经看过 TRAIN。名称与打乱控制不是新的独立数据集重复。

## 6. 执行阶段与固定预算

### 阶段 A：来源与回放检查

1. 使用 UT v2 C_text seed 0 的既定最佳 checkpoint，不从多个旧 checkpoint 再挑最有利起点。
2. 核对 source、config、checkpoint、字典、bank、词表和 evaluator 的 hash；确认静态 prior 关闭。
3. 导出一次完整 TRAIN/VAL 的冻结属性特征和完整网格原分数。TRAIN 22998 张、VAL 3214 张，词表 16 属性×12 对象。缓存仅存必要 300 维特征和 192 个分数，不保存全层 patch token。
4. 每个 split 的图像身份、标签和候选顺序配对；缓存生成使用 eval 模式、确定变换。本轮小模块训练使用共同固定缓存，不声称与原完整增广训练完全相同。
5. Delta=0 回放原 CW/OW；核对完整网格到 CW 的公共候选一致性。
6. 检查条件分布之和、联合分布之和、对象边缘保持、有限值、梯度、对象条件变化及断点恢复。

归一化用 log_softmax/logsumexp，不能用概率截断掩盖下溢；评估 tie 处理采用原 evaluator。关闭分支走直接返回原分数的路径。

只有真实来源和数值接口通过才继续。已看到完整性失败时，先解决失败，不跳过 hash 或配对。

### 阶段 B：TRAIN 内机制检查

固定按图像 ID 的分折方式，为每个 TRAIN pair 保留诊断图像。首先只在 TRAIN 内训练/检查小模块；诊断 fold 不参与这次 head 的优化。比较条件属性 NLL、宏平均属性准确率与名称/错配对照。

重要边界：基础 checkpoint 已训练过完整 TRAIN，故这不是独立验证集或严格未见组合泛化。TRAIN 内结果只用于排查退化、梯度和知识利用，不替代 VAL 结论。

工程诊断后恢复同一初始新 head 状态，按完整 TRAIN 重训正式 pilot。不能把 fold 检查权重悄悄接着训练来改变预算。

### 阶段 C：UT seed 0 固定预算 pilot

拟定共同设置：

```text
anchor: UT v2 C_text seed 0，既定最佳 checkpoint
new backbone optimizer steps: 0
new head rank: 32
epochs: 10（完整固定预算，不在第3轮宣布收敛）
batch_size: 256（缓存特征；显存不足时所有组同步改并先冻结协议）
optimizer: AdamW
learning_rate: 1e-3
weight_decay: 1e-4
score_temperature: 0.05
bounded_evidence_c: 0.10
static_prior_weight: 0
logic_weight: 0
trainable: 新条件知识 head；基础模型全部冻结
checkpoint_selection: 每组 epoch 0–10 按同一 VAL CW AUC 规则选中
```

设置来源是小模块试验的保守初值，不是全模型最优超参数。不在看到新 VAL 结果后循环调整 rank、c、temperature 和句子。3、5、10 轮只是轨迹记录；三轮下降不能证明所有版本都已收敛。

首轮共五个小 head × 10 epoch；不是五个 ViT 从头训 10 epoch。冻结特征一次提取即可复用。服务器实际耗时需用首批计时外推；不把旧 SG-EKR 的每轮耗时套用到缓存训练。

### 阶段 D：固定方案确认

若 seed 0 有正确知识增量，锁定结构和设置，再做 seed 3351、2026。每个 seed 使用自己的 C_text checkpoint、特征和分数，不跨 seed 混用表示。包括同结构名称与两种错配对照；确认阶段报告全部 seed 及配对均值/标准差。

随后加 P_static（同知识、不读取图像）、P_no_object（移除知识利用中的候选对象交互）、P_OI（在已确认 head 中加入父类语境）、P_OI_shuffle。OI 只用于类型语境，不把父类关系当成每张图必然具有的属性规则。

若 P_generic 是明显更好的候选，可以冻结它作为后续主实现，但须补它自己的匹配名称/错配对照，不能拿 P_K 的错配结果证明 P_generic。

用 A_unit/名称起点重复匹配实验后，才可讨论全部新增 K 的效果。这个确认必须同时保留强 C_text 参考，不能因名称起点更容易涨点就避开强基线。

### 阶段 E：第二数据集与完整模型

UT 工程接口通过后可安排 MIT-States 的知识来源审查；不能用旧未复核词义直接开大训练。

当前本地 MIT AE 里 `bent` 是 "fixed in your purpose / resolute"，不是可见物理弯曲；`browned` 使用皮肤晒黑义，`brushed` 使用轻轻擦过义，未必符合数据集中所有视觉用法。这至少证明存在需要审阅的多义词，不据这几个例子宣称所有 MIT 知识都错。

先对全词表按视觉语义做有来源的系统审核，使用标签含义和 TRAIN 图，不使用 VAL/TEST 错误挑句子；所有标签同样处理，保存原文、修改理由与固定版本。旧 MIT C−A CW 为 −0.315 pp、OW −0.010 pp，亦不能断言第二数据集必涨。

第二数据集的试验和 UT 同样预定并完整报告。不能在 UT 失败后寻找一个正数据集，替换原主结果。先一个配对 seed，再按固定规则扩展三 seed；若需换文本编码器，单独比较同编码器的名称/正确知识/错配知识，不将编码器变化的收益归给条件模块。

只有条件知识得到重复支持，才进入完整模型：

- 小学习率解冻原属性映射；全部主要对照同步解冻，并增加相同训练预算的 C-budget。
- 再按原方案比较外部 logic loss、条件知识、二者普通组合与条件逻辑适配；逻辑项每次只加一类，不将典型描述变成硬事实。
- 若换成原 object 辅助头的显式边缘，另设同读出的匹配概率基线，不能把此前可回放读出与新读出混在同一增益表。
- 完整方法锁定后再评估新方法的 TEST，并完成三数据集正式比较。

## 7. Gate 的正确用法与结果分支

旧 gate=false 保持有效，新模型使用独立 protocol 和报告。原静态文本 +0.5 pp 门槛不是这个新条件模型的逻辑前提，可以另开探索协议，不能修改旧文件假装过关。

建议在新评估前固定下列投入筛选条件；它们是预算规则，不是统计显著性标准：

| 层次 | 条件 | 后续处理 |
| --- | --- | --- |
| 来源/实现 | hash、split、配对、回放、完整归一化、梯度均通过 | 这是有效实验前提；失败先修复 |
| seed 0 性能 | P_K 相对冻结强 C_text CW AUC 至少 +0.20 pp | 有必要进一步确认，非成功证明 |
| seed 0 内容归因 | 相对 P_name 与两种 perm 的平均 CW AUC 分别至少 +0.10 pp；逐项差值均完整报告 | 决定是否投入正确知识确认 |
| 保护项 | 相对 C_text CW HM ≥−0.5 pp、OW AUC ≥−0.5 pp、OW best-unseen ≥−2 pp | 明确记录取舍，不删掉退化指标 |
| 三 seed | P_K 相对 C_text 平均 CW AUC ≥+0.5 pp，至少2/3 seed 为正；相对名称与每个 perm 的平均差值为正 | 重复性筛选；不是三个 seed 就证明显著 |
| 结构主张 | 相对 generic/static/no-object 有支持，且第二数据集确认 | 决定能否宣称特定机制贡献 |

“没到 0.20，但所有正确知识对照同向且只有小幅正数”可以保留为弱探索结果；若追加验证，必须明确另立预算，而不是宣称原筛选通过。不能看结果后无上限增加 seed 或搜索。

不同结果对应不同产出：

1. P_K 超过强 C、名称、错配：锁定模型做确认。
2. P_K 与 P_name 同涨：新增容量/条件适配有用，未证明新增知识；保留工程基线。
3. P_K 与 perm 同涨：正确归属尚无优势，降低此知识实现优先级。
4. P_generic 的正确知识对照有效且更强：采用简单实现，缩小对特殊结构的新颖性主张。
5. GT-object 属性明显改善但组合指标不改善：这说明可能存在对象边缘或候选竞争瓶颈，不可自动写成 gate 通过。最多另立一次所有对照同步的属性/对象映射微调检查，不进入无期限调参。
6. 只有 NLL 改善、准确率与 AUC 不改善：记录概率拟合变化，不称为识别收益或机制成功。

## 8. 最低交付物与运行可靠性

每阶段保存 protocol、知识/代码/配置/权重/缓存 hash、全部逐轮记录、有效参数量、优化步数、每组 CW/OW、选中 epoch、逐图配对分数和条件属性诊断。

条件属性诊断同时报告 seen/unseen pair、GT-object 全词表属性准确率、宏平均准确率、NLL，以及对名称/错配的纠正与破坏。GT-object 仅用于诊断，不用于正式推理。

断点使用原子写入的 last checkpoint，包含 model、optimizer、scheduler（若有）、RNG、已完成 epoch 与累计步数。恢复从 last 而非 best；完成记录只在全部评估写入成功后生成。磁盘不足或文件不完整时保留诊断，不自动覆盖旧 run。

新输出放独立 /var/tmp 目录，原 /data 结果只读。新方案不假定旧 scripts 已实现。服务器执行包必须按真实接口实现并检查后交付，本文不提供不存在脚本的运行命令。

## 9. 为什么推荐这一顺序

它保留已有强基线和知识投入；关闭分支时可精确回放；知识直接进入归一化属性条件模型；监督目标与原方案一致；首轮只训练小 head，可以低成本完整跑固定预算；错误知识、容量、融合、概率读出与对象条件都有可区分的对照。

这提高的是实验有效性和失败后可定位性，不是已经验证的涨点概率。仍然不能给出可信成功百分比。潜在瓶颈包括 GloVe 表达能力、鞋材质标签的视觉可分性、冻结特征信息和开发验证集反复使用。

本地已用 27 组合成 float64 情形检查第 3 节的归一化、对象边缘保持、联合概率等价性和零分支原分数回放，数值检查通过。记录在同目录 `probability_identity_checks.json`。这不是新模型梯度检查、真实 evaluator 回放或性能实验；服务器实现仍需完成阶段 A 的真实核验。
