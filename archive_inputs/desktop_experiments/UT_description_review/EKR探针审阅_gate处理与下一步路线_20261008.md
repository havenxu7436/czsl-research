# EKR 探针审阅、gate 处理与下一步路线

日期：2026-10-08

## 1. 当前判断

TRAIN-only 支持探针完整通过技术审计，但科学判定为 `support_screen_passed=false`。这个 false 不应被理解为“所有 EKR 都失败”，它只否定了一个更具体的假设：**把属性名称和三个描述槽直接平均后，整体效果不如只使用属性名称。**

探针同时给出了三个继续研究的依据：

1. 正确描述相对 shuffle 的同对象宏观 margin 增加 `+0.02684`，两个内部半折都是正数；
2. 16 个属性中有 12 个正确描述优于 shuffle，说明描述与属性的正确对应关系确实携带信号；
3. 48 个 AE 描述槽中有 34 个呈正向 one-vs-rest 分离，但有 14 个是负向槽。所有槽等权使用会把有效与有害描述混合。

问题出在“如何选择描述”，而不是描述完全没有信息。另一方面，正确描述均值仍比名称低 `-0.00458` margin，只在 8/16 个属性上优于名称，因此不能把当前描述均值方案称为有效改进。

视觉属性原型在同对象候选中的两个内部半折准确率为 51.81% 和 53.41%，明显高于名称向量的 40.16% 和正确描述均值的 34.94%。所以：

- 若优先保持文本语义路线，最后一次最合理的小改动是 **支持筛选固定值 EKR**；
- 若优先追求数值收益，后备方向应是 **视觉 primitive 原型检索 EKR**；
- 两者都与随机语义图路线分开。

## 2. 哪些 gate 可以调整

### 2.1 永远不能忽略的 gate

以下属于实验完整性，而不是研究偏好：

- 数据、bank、checkpoint、源代码与协议哈希；
- 图像 ID、标签、候选顺序和评价配置的逐项配对；
- A_unit 与 N_name 共同底座冻结；
- 主对照具有相同参数量、初始化、训练轮数和数据顺序；
- 只能用 VAL 选 epoch，TEST 不能参与选择；
- 中断恢复必须从已提交 epoch 开始；
- 失败结果、旧 gate 和负 seed 必须保留。

这些 gate 一旦忽略，结果就无法审计。

### 2.2 不能为了让旧结果通过而忽略的 gate

- 旧 v2 的 `proceed=false` 不能改写。它仍然表示可学习值对齐失败。
- 原先 `CW AUC +0.2 pp` 不能事后改成 `+0.08 pp`，所以 `V_clean_fixed` 仍是未通过。
- `correct_mean >= name` 不能从报告中删除，因为它直接说明原始描述均值没有超过名称基线。

可以在一个**新协议和新输出目录**中重新定义下一阶段 gate，但不能追溯性地修改旧判定。

### 2.3 可以从“硬停止条件”降为“诊断条件”的 gate

探针的复合 `support_screen_passed` 可以拆开：

- `correct > shuffle` 的三项条件已经通过，应保留为描述对应关系确有信号的证据；
- `correct >= name` 的两项条件失败，只阻止继续使用“全部描述均值”，不应阻止测试“筛掉有害槽”的新机制；
- `margin >= 0.01` 和“至少 11/16 属性为正”是探索性阈值，不是统计定律。下一阶段可以作为报告项，不必继续充当总开关。

原来的单 seed `+0.2 pp` 也可以在**新 pilot 中前瞻性地**改为 `+0.10 pp`，因为新 pilot 的目的只是决定是否值得跑更多 seed。正式确认仍必须看多 seed 的配对一致性，不能只依靠降低后的单 seed 阈值。

## 3. 推荐的主路线：SG-EKR-CPF

名称：Support-Gated EKR，中文可写为“视觉支持筛选的固定语义路由”。

核心改动只有一个：保留原始 GloVe value，不再学习 value projection；用 TRAIN 特征提前筛掉跨半折不稳定或有害的 AE 描述槽。

### 3.1 生成支持 mask

继续使用已审阅的 498 张平衡 TRAIN 图像，每个已见 pair 有 6 张，按图像 ID 固定分为两个半折，每个 pair 在每折各 3 张。

对属性 $a$ 的第 $r$ 个 AE 槽，在半折 $f$ 上计算同对象条件支持：

$$
s_{a,r}^{(f)}=
\frac{1}{|\mathcal O_a|}
\sum_{o\in\mathcal O_a}
\left[
\operatorname{mean}_{i:y_i=(a,o)}\cos(z_i,e_{a,r})
-
\operatorname{mean}_{i:y_i=(a',o),a'\ne a}\cos(z_i,e_{a,r})
\right].
$$

其中 $z_i$ 是冻结 CPF 的属性特征，$e_{a,r}$ 是冻结描述向量。只使用 TRAIN，不读取 VAL/TEST。

mask 规则在运行前固定：

$$
m_{a,r}=1
\quad\Longleftrightarrow\quad
\min\left(s_{a,r}^{(0)},s_{a,r}^{(1)}\right)\ge 0.005.
$$

- 属性名称槽始终保留；
- AE 槽只有在两个半折都达到阈值时保留；
- 某属性没有合格 AE 时退化为 name-only；
- mask、每折支持值和输入哈希全部保存；
- 不按 VAL AUC 改 mask，也不手工挑属性。

### 3.2 路由器

沿用 v2 的 query/key/null/gain 结构，删除可学习 `value_down/value_up`。固定残差为：

$$
\Delta s(x,a,o)=
\eta\sum_{r:m_{a,r}=1}
\alpha_r(x,a,o)
\left\langle
\widehat f_a(x),\frac{e_{a,r}}{2}
\right\rangle.
$$

总分为：

$$
s_{\mathrm{new}}(x,a,o)=s_{B_{\mathrm{name}}}(x,a,o)+\Delta s(x,a,o).
$$

所有 value 固定；只训练 query、key、null 和一个有界全局 gain。这样直接针对 v2 已发现的 value drift 问题。

### 3.3 seed-0 pilot 的三个等容量分支

| 分支 | 输入槽 | 用途 |
|---|---|---|
| `G_name` | 只保留名称 | 检查新增路由器本身是否带来收益 |
| `G_support` | 名称 + TRAIN 稳定支持的正确 AE | 主方法 |
| `G_shuffle` | 与 `G_support` 相同 mask，但 AE 内容使用冻结 shuffle 映射，名称不变 | 检查收益是否来自正确描述对应关系 |

三项参数量、初始化、batch 顺序、3 个 epoch 和评价预算必须完全相同。共同底座仍为冻结的 `B_name`。旧 `V_clean_fixed` 作为“全部槽”历史消融引用，不进入新主 gate，也不需要重训。

### 3.4 新 pilot 的前瞻性 gate

只有同时满足以下条件才进入 router 多 seed 确认：

1. `G_support - B_name` 的 CW AUC 至少 `+0.10 pp`；
2. `G_support - G_name` 的 CW AUC 至少 `+0.10 pp`；
3. `G_support - G_shuffle` 的 CW AUC 至少 `+0.10 pp`；
4. `G_support` 的 CW HM 相对 B_name 不低于 `-0.5 pp`；
5. `G_support` 的 OW AUC 相对 B_name 不低于 `-0.5 pp`；
6. `G_support` 的 OW best-unseen 相对 B_name 不低于 `-2 pp`。

OW 只作保护条件，不用于选择 epoch。epoch 仍在 0、1、2、3 中按 CW AUC 选第一个严格最大值；epoch 0 是关闭新增残差的共同底座。

这不是放水：新 gate 仍要求同时超过底座、名称路由和 shuffle，只是把单 seed 的效果阈值从探索性的 0.2 pp 调整为 0.1 pp。旧实验的结论不变。

## 4. 通过后的确认顺序

若 seed-0 新 pilot 通过：

1. 固定 support mask 和全部超参数；
2. 在同一冻结 B_name checkpoint 上运行 router seeds `0、3351、2026`；
3. 每个 seed 都运行 `G_name、G_support、G_shuffle`；
4. 报告三个配对增量，不删除负 seed；
5. 要求 `G_support` 相对 B_name、G_name、G_shuffle 的平均 CW AUC 均大于 0，且至少 2/3 seed 为正；
6. 同时报告均值、标准差和每个 seed 的原始值；3 个 seed 不声称统计显著性；
7. 只有确认通过后，才在锁定配置下评价 TEST。

若预算允许，最终论文级结论应使用 5 个 router seed 或跨数据集验证，而不是靠 3 个 seed 给出显著性结论。

## 5. 若 SG-EKR 仍失败

停止当前 GloVe 分数残差路线，不再尝试学习 value projection、增加 epoch 或扩大 rank。转入视觉 primitive 原型检索：

- TRAIN 内为属性和对象建立对象平衡的视觉原型；
- 输入图像检索相近 primitive 原型；
- 将检索证据作为 CPF 的条件残差；
- 保留无检索、错配检索和等容量路由器对照。

这一方向获得数值收益的依据更强：当前两个半折的同对象视觉原型准确率为 51.81% 和 53.41%，而名称向量为 40.16%。但视觉原型检索本身已有相关工作，论文创新点必须放在“CPF 条件概率中的证据路由和归因控制”，不能只声称建立了原型库。
