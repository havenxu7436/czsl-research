## 4. 推荐主路线：跨对象视觉证据的 CPF 验证

工作标签建议为 `VP-CPF`，route ID 为 `cross_object_visual_evidence_v1`。它是独立新假设，不继续沿用 SG-EKR 的语义贡献主张，也不引入随机语义图。

### 4.1 先用最强、可复用的 CPF 作为主基线

正式比较优先使用已完成的 `C_text` 三 seed checkpoints。前序匹配协议中，其均值 CW AUC=44.540%、OW AUC=32.261%，强于 A_unit。只超过 43.123% 的 seed-0 B_name 不足以说明优于当前已有最佳 CPF 配置。

其中 C_text seed 0 的现有 VAL CW AUC=45.440387%、OW AUC=34.937345%，选中 epoch 6。它与 B_name 的训练方式不同，不能把二者差值当作单一机制的因果效果；但它是下一轮应该面对的更强工程起点。

`C_text` 的旧语义 gate 仍为 false；把它作为工程起点，不意味着已经证明正确外部描述的贡献。新方法必须相对同 seed 的 C_text 比较。

第一个 smoke 可复用当前 A_unit/B_name 缓存检查接口；不能把这个弱起点的 smoke 当成最终主表。

### 4.2 属性原型由 TRAIN 图像形成

先按训练组合分别平均单位属性视觉特征，再对对象均匀平均：

```text
pair_mean[a,o] = mean(unit(attr_feature(x))) for TRAIN images with labels (a,o)
global_proto[a] = unit(mean_over_objects(pair_mean[a,o]))
```

这样每个对象给属性原型相同权重，避免图像数量大的组合主导原型。不要把对象名称或组合频次作为静态 feasibility 分数加入模型。

第一项 `VP_global` 使用该属性全局原型，0 个新可训练参数。它负责验证视觉证据的最基本增量价值，是必须保留的简单基线。

### 4.3 在属性条件分布内融合，保存原对象分组的质量

将冻结基础模型的全候选分数在对象内归一化，形成诊断条件分布。视觉原型也在同一候选属性集合内归一化。新分数为：

```text
T = 0.05
p_B(a | x,o) = softmax_over_attributes(score_B(x,a,o) / T)
p_V(a | x,o) = softmax_over_attributes(visual_evidence(x,a,o) / T)
p_new = (1-beta) * p_B + beta * p_V
score_new = score_B + T * (log(p_new) - log(p_B))
```

性质：beta=0 时精确回放基础模型；beta 非负；按对象求和的 `exp(score/T)` 保持不变，因此不会借该模块直接改变对象分组的总质量。

这是对原 native 分数构造的条件归一化，不声称这些分数就是 CPF 原训练头输出的精确概率。上述质量保持性质成立于融合时、seen/unseen 评估偏置施加之前；不能声称 bias 扫描的每个点也保持相同对象概率。

实现使用 log_softmax 和 logaddexp，在 log 空间求混合；beta=0 直接返回原分数。不能通过截断小概率偷偷改变归一化质量。

部署计算使用完整属性×对象候选网格，再由原 evaluator 应用 CW/OW mask。不要分别在已屏蔽的 CW 与 OW 子集内重建两个不同预测器。只用已保存的 CW 子集分数无法完整执行这一版本，先导出完整网格分数。

第一轮固定 beta=0.20、证据为 cosine/2、T=0.05。它们是依据 TRAIN 诊断提出的新候选规则，在读取新 VAL 结果前冻结；不继续扩大 beta、temperature 或 rank 搜索。

### 4.4 只有 global 有增量后，再检验对象条件

第二项 `VP_cross_object` 保留每个已见组合的原型。评价候选 `(a,o)` 时，优先从属性 a 在其他对象上的视觉原型检索；第一版固定排除源对象等于候选对象的槽，防止靠同组合记忆解释收益。

具体候选规则：

```text
eligible = source prototypes (a,o_source) with o_source != o
retrieval_logit = cosine(query_attr_feature, pair_mean[a,o_source]) / 0.20
                  + cosine(frozen_object_name[o], frozen_object_name[o_source]) / 0.20
attention = softmax_over_eligible_sources(retrieval_logit)
visual_evidence(x,a,o) = sum(attention * cosine(query, source_proto)) / 2
```

查询、候选对象和源视觉证据都参与选择；第一版仍不训练额外模块。缺少跨对象支持时使用 global_proto，并统计 fallback。这个规则是待验证候选，不是已证明优于 global 的实现。

对应消融：删除对象名称相似项，但保留相同源槽与排除规则；再做固定对象上下文置换。若完整版本不优于它们，只报告视觉证据有用，不宣称对象条件检索贡献。

第一轮预算：一个 C_text seed 的完整 TRAIN/VAL 提取，以及 CPU 原型/分数计算。最多投入两 GPU 小时含排错；没有完整 backbone 重训，通常只需要远少于该上限的前向计算，实际以服务器计时为准。

pilot 未通过，不扩展网格、不追加 seed、不改描述、不重复读取 TEST。pilot 通过再导出另两个 seed，不先一次性建立所有候选模型。

## 8. 研究产出与新颖性的边界

视觉检索和原语原型已有明确研究先例：

- [RAPR，AAAI 2024](https://ojs.aaai.org/index.php/AAAI/article/view/28043)：利用 TRAIN 属性/对象表示库检索并增强原语表示。
- [ClusPro，ICLR 2025](https://arxiv.org/abs/2502.06501)：多个聚类原语原型、原型对比与解相关学习。
- [CPF，ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/html/Wu_A_Conditional_Probability_Framework_for_Compositional_Zero-shot_Learning_ICCV_2025_paper.html)：对象与属性条件依赖及文本增强视觉特征。

所以“建一个视觉原型库”本身不够作为新颖性主张。若所有阶段成立，可研究的贡献是：维持基础分数对象分组质量的属性证据融合、跨对象源原型转移、排除同组合记忆，以及对应机制证据。它是否达到论文创新标准，还需要与最近邻方法实现和实验比较。

若只得到 VP_global 涨点，它是有效工程基线。若 conditional 与负对照也稳定胜出，才进一步考虑方法贡献。若都失败，现有结果仍能形成完整基线、语义归因负结果和表示诊断材料，但不能保证足以单独投稿。

前序投入已经排除了归一化、描述聚合、描述修订、名称锚点、value 对齐、槽支持筛选等多个候选解释，建立了可复用权重与审计链。它们有研究价值；继续沿同一负方向堆叠实现才会降低后续投入效率。
