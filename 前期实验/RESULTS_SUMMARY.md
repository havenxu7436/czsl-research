# 前期实验结果汇总

## 01–15 证据链

| 阶段 | 问题 | 归档结论 |
|---|---|---|
| 01 | CPF 基线与知识资产是否可复现 | 建立后续所有对照的共同基线 |
| 02 | MVP 对照与固定 prior 校准 | 验证训练与后处理评价链 |
| 03–04 | UT 语义归因 v1/v2 | 完成语义归因和逐图分析，暴露知识收益的不稳定性 |
| 05–09 | 名称锚点、EKR、支持掩码与预算扩展 | 从 3 epoch 扩展到 10 epoch，逐步排除冻结、共享值和支持权重问题 |
| 10 | CPF + LogiCZSL B/F | 完成四组 10 epoch 对照 |
| 11–12 | 条件属性 preflight 与 pilot r2 | 完成梯度检查、缓存和五组 10 epoch/固定混合评价 |
| 13 | Generic 知识对照 | 正确知识未优于随机置换，且 G_K 没有新优化步骤 |
| 14 | 冻结 CLIP 知识探针 | 七种固定配方没有显示正确知识的稳定优势 |
| 15 | TRAIN 逐句知识审查 | 收益集中在少数属性，且不是 held-out 泛化证据 |

更早阶段的完整实验设置和表格仍在各阶段 README 中；下面固化阶段 13–15 的关键原始结果，确保删除 CSV 后仍可审阅。
