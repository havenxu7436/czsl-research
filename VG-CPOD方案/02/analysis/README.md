![已见支持质量和条件属性迁移](confirmed/figures/03_transfer.png)

A5 相对 A1，将 TEST 未见图像的已见概率质量从 82.26% 降至 73.49%，未见条件属性准确率从 17.63% 升至 23.64%。相比同 β 的 A6，A5 未见条件属性准确率的三个 seed 差值为 −0.053 / −0.582 / −1.745 点；平均少识别对 15 张未见图像，已见图像则平均多识别对 56 张。

VAL 未见条件属性准确率 A5/A6 为 21.81% / 16.05%，TEST 为 23.64% / 24.43%。这说明 CP 对不同未见组合的迁移程度不同。

三类负向组合平均合计少识别对约 102.7 张；Canvas–Shoes.Loafers 多识别对 52 张，其他组合也有收益。这些变化相互抵消后，表现为未见总体少 15 张。下一轮优先检验局部视觉证据能否改善材质在不同物体间的迁移。

## 5. OW 工作点与训练轮数

A5 相对 D0 的 TEST OW AUC 提高 0.699 点，但固定 VAL bias 的 OW HM 为 40.638，对比 D0 的 42.063 仍低 1.425 点。精确 VAL bias 仅将 A5 提高至 40.764；其 TEST 曲线最高 HM 约为 41.780，D0 约为 43.215。下一轮同时记录 AUC 与固定 VAL bias 的 HM。

A1 三个 seed 最佳轮为 8/6/6，A5 为 8/8/6；峰值到第 10 轮的 VAL CW 平均回落分别为 0.551 / 0.285 点，继续保持 10 轮。详细数值见 [history.csv](confirmed/tables/history.csv)。
