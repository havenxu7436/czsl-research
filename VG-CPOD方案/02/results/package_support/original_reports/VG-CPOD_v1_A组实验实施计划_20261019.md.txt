## 2. 本次公式改动

前向仍为原 V1 的全局静态修正：

$$
\begin{aligned}
u_i&=A_ue_i^a,\qquad v_j=A_ve_j^o,\\
\Delta U_{bji}&=\rho\kappa\,g_b^\top W_c(u_i\odot v_j),\\
P(a_i,o_j\mid x_b)&=P(o_j\mid x_b)P(a_i\mid o_j,x_b).
\end{aligned}
$$

定义训练组合概率质量与支持损失：

$$
\begin{aligned}
Z_s(x)&=\sum_{(a,o)\in\mathcal{C}^s}P(a,o\mid x),\\
\ell_{\mathrm{support}}&=-\log Z_s(x),\\
\ell_{\mathrm{pair}}&=-\log P(y\mid x)+\log Z_s(x),\\
\ell_{\mathrm{cond}}+\ell_o&=-\log P(y\mid x).
\end{aligned}
$$

将任务损失改为：

$$
\begin{aligned}
\ell_{\mathrm{task}}(\beta)
&=\frac{1.5}{1+\beta}
\left[\ell_{\mathrm{pair}}+\beta(\ell_{\mathrm{cond}}+\ell_o)\right]\\
&=1.5\ell_{\mathrm{pair}}
+\frac{1.5\beta}{1+\beta}\ell_{\mathrm{support}}.
\end{aligned}
$$

β=0.5 精确恢复原任务损失；β=0.25、0.1 分别把支持项系数从 0.5 降至 0.3、0.13636，同时保持组合内排序项系数 1.5。代码对 β=0.5 保留原运算顺序，方便直接比较。

适配器与 CP 的学习率共享原十轮余弦进程，使用固定比例：

$$
\begin{aligned}
\eta_t&=\eta_{\min}+\frac{\eta_{\max}-\eta_{\min}}{2}
\left[1+\cos\left(\frac{\pi t}{T-1}\right)\right],\quad t=0,\ldots,T-1,\\
\eta_t^{\mathrm{adapter}}&=\eta_t,\qquad
\eta_t^{\mathrm{CP}}=s_{\mathrm{CP}}\eta_t,\quad
s_{\mathrm{CP}}\in\{1,0.3,0.1\}.
\end{aligned}
$$

本数据集 T=3600。适配器参数为 `Bo/Co/Bc/Cc`；V1 的 CP 参数为 `Au/Av/Wc`。分组学习率降低 CP 的实际更新量；梯度仍按原公式统一裁剪。

## 3. 已实施的代码改动

| 文件 | 改动 |
|---|---|
| `vgcpod/model.py` | `task_aux_beta` 控制归一化任务损失；新增 `task/support` 日志 |
| `vgcpod/engine.py` | `make_optimizer` 建立参数组；`set_learning_rates` 在每步保留 `lr_scale`；每轮同一 VAL 前向评 CW/OW |
| `vgcpod/engine.py` | 记录未见条件属性准确率、完整 joint 的已见组合概率质量、中心化修正 RMS、被裁剪步骤比例 |
| `run.py` | 没有显式 `--variant` 时，采用配置文件中的模型，A6 因而读取 V0 |
| `configs/round_a/A1.json`–`A6.json` | 保存每组完整超参与实验编号 |
| `round_a.py` | 三卡任务分配、日志、自动续训、完成组跳过和独立组汇总 |
| `scripts/start_round_a_tmux.sh` | 启动持久 tmux 会话，传入当前环境的绝对 Python 路径 |
| `references/original_v1.json` | 原 V0/V1 的三 seed 指标和缓存身份，用于同 seed 对照 |

损失实现：

```python
beta = self.cfg.get('task_aux_beta', 0.5)
task = (pair + 0.5 * cond + 0.5 * obj) if beta == 0.5 else (
    1.5 / (1.0 + beta) * (pair + beta * (cond + obj)))
support = -torch.logsumexp(s[:, train_mask], dim=-1).mean()
```

学习率分组使用 `cp_lr_scale`，调度的关键行是：

```python
for group in optimizer.param_groups:
    group['lr'] = eta * group['lr_scale']
```

单独建立参数组后仍写 `group['lr'] = eta` 会抹掉比例，本次实现已处理这一点。
