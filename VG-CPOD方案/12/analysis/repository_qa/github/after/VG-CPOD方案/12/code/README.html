12 · 代码与修订

原运行源码位于vgcpod_v1_roundK。配置、资产和验证按平行目录保存，成员映射供materialize恢复原包。相对11 J组的完整差异见source_changes.patch。

1. Wd独立学习率组

engine.py的make_optimizer在配置含dynamic_readout_lr_multiplier时，将Wd从普通CP组移出：

if separate_dynamic:
    scale = cp_scale * multiplier
    groups.append({'params': [model.Wd], 'name': 'dynamic_cp',
                   'lr_scale': scale, 'lr': cfg['lr'] * scale})

adapter组为Bo/Co/Bc/Cc，CP组为Au/Av/Bvis/Wc，dynamic_cp只含Wd。三个组的lr_scale分别为1、0.3、0.09或0.03。set_learning_rates将同一余弦日程乘组倍率。无新配置键时保持原J1参数分组与顺序。

本轮model.py与mean_gate_eval.py和J组逐字一致，继续使用separate读出、原损失及TRAIN均值评估。可训练参数147,456，新增参数为0。

2. 从真实Adam状态核验更新

新增readout_diagnostics.py：

  1. 按模型与优化器参数顺序，将checkpoint中的参数ID映射为Wc/Wd。
  2. 读取step、exp_avg、exp_avg_sq、β₁/β₂、ε、lr及lr_scale，做Adam偏差修正。
  3. 分别输出矩阵范数、一阶／二阶矩、归一化方向和学习率乘自适应方向的范数。
  4. 对native选中、exact选中和末轮checkpoint分别记录，并报告动态／静态比值。

该诊断中的更新范数对应最后一步自适应项；weight decay单独执行。诊断模型初始化保留调用方Torch RNG。
