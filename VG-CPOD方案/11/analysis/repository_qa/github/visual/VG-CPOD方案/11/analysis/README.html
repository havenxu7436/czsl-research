4. 下一轮的依据：Adam 使梯度尺度与步长尺度分离

4.1 当前前向公式核查

令 $a_{ij}=(A_ue_i^a)\odot(A_ve_j^o)$，$h_{bj}=\gamma_{bj}-\mathbf{1}$，当前 J1 使用：

$$U_{bji}=U^{\mathrm{base}}_{bji} +\rho\kappa g_b^\top W_s a_{ij} +\rho\kappa g_b^\top W_d(a_{ij}\odot h_{bj}).$$

$W_s$ 在代码中为 Wc。两路共享属性／物体因子；$W_s=W_d=W_c$ 时精确恢复 I2。均值评估分别使用静态项与 $W_d$ 的均值动态项，预测复算一致。当前需要优化两路学习率的配置。

4.2 checkpoint 直接显示的优化器尺度

seed 动态/静态：一阶矩范数比 动态/静态：Adam 自适应步长范数比
3351 0.0304 0.9528
3352 0.0264 0.9986
3353 0.0208 0.9625

一阶矩和自适应步长取自选中 checkpoint 最后一个训练 step 的 AdamW 状态。步长范数使用带偏差校正的一阶／二阶矩和该 step 学习率重建，统计自适应项，weight decay 单独执行。Wd 的一阶矩范数约为静态读出的 2%–3%，其自适应步长范数约为静态读出的 95%–100%。

Adam 的核心递推为：

$$\begin{aligned} m_t&=\beta_1m_{t-1}+(1-\beta_1)G_t,\\[4pt] v_t&=\beta_2v_{t-1}+(1-\beta_2)G_t^{\odot2},\\[4pt] \widehat m_t&=\frac{m_t}{1-\beta_1^t},\qquad \widehat v_t=\frac{v_t}{1-\beta_2^t},\\[4pt] \Delta\theta_t^{\mathrm{Adam}}&=-\alpha_t \frac{\widehat m_t}{\sqrt{\widehat v_t}+\epsilon}. \end{aligned}$$

以上除法与开方均逐元素执行。若整段梯度历史统一乘以正数 $c$，从零矩状态开始，则：

$$\widehat m'_t=c\widehat m_t,\qquad \widehat v'_t=c^2\widehat v_t,\qquad \Delta\theta'_t=-\alpha_t\frac{\widehat m_t}{\sqrt{\widehat v_t}+\epsilon/c}.$$

当 ε 项较小时，缩小梯度主要被二阶矩归一化抵消。真实两路梯度并非统一常数缩放；上表是实际 checkpoint 中两路优化器状态的测量。它说明 η=0.25 下的小门控，仍可通过独立 Wd 学出较大的分数修正。直接改变 Wd 的学习率可以明确改变其更新步长。
