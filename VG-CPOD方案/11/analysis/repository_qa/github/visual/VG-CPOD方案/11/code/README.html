11 · 代码与修订

原运行源码位于vgcpod_v1_roundJ，配置、资产、说明与验证按平行目录保存；映射供materialize恢复原包。相对10 I组的全部差异见source_changes.patch。

1. 两路独立读出

model.py保留Wc作为静态Ws，新增零初始化Wd；原有参数的随机初始化序列保留。新分支的核心计算为：

static_modes = (readout @ self.Wc) * v[None, :, :]
dynamic_modes = (readout @ self.Wd) * (gamma - 1) * v[None, :, :]
static = rho * kappa * torch.einsum('bor,ir->boi', static_modes, u)
dynamic = rho * kappa * torch.einsum('bor,ir->boi', dynamic_modes, u)
cond = base + static + dynamic

cp_readout_mode="separate"启用上述分支。I2配置沿用共享分支；J1输出额外保存cp_static/cp_dynamic。Au/Av共享、矩阵Wd新增24,576个参数，两路联合训练。

2. 均值评估与幅值日志

mean_gate_eval.py先使用当前模型的静态输出，再通过Wd、TRAIN均值门控减1和原因子计算动态输出。这样两路矩阵都参与均值条件，最后重算条件softmax与联合分布。

engine.py记录两路原始MSE和沿属性维中心化MSE，按图像数汇总后计算epoch RMS。日志是训练epoch各batch前向权重的统计。J1仍使用原adapter与CP两个AdamW参数组，Wc/Wd属于相同CP组；LR均为3e-4→3e-6。
