## 2. 公式与权重选择

### 2.1 中心化视觉 CP 修正

属性与物体模式分别为 $u_i=A_u e_i^a$、$v_j=A_v e_j^o$。门控公式继续使用：

$$
\begin{aligned}
q_{bjk}
&=2\sigma\!\left(\frac{(f^o_{bj})^{\top}(B_{\mathrm{vis}})_{k:}^{\top}}{\tau_\gamma}\right)-1,\\
\gamma_{bjk}
&=1+\frac{\eta}{2}\left(q_{bjk}-\frac{1}{r}\sum_{\ell=1}^{r}q_{bj\ell}\right).
\end{aligned}
$$

每个图像／物体查询的模式均值为 1。E1 的条件 logits 修正为：

$$
\begin{aligned}
\Delta U^{\mathrm{E1}}_{bji}
&=0.15\kappa\,g_b^{\top}W_c
\left(u_i\odot v_j\odot\gamma_{bj}\right),\\
U_{bji}&=U^{\mathrm{base}}_{bji}+\Delta U^{\mathrm{E1}}_{bji},\\
\log p(a_i,o_j\mid x_b)
&=\log\operatorname{softmax}(S_b)_j
+\log\operatorname{softmax}(U_{bj:})_i.
\end{aligned}
$$

在相同输入和参数下，E1 修正是 D1 的 1.2 倍。E1 从对应 seed 的初始化重新训练，参数轨迹由各自训练过程决定。

### 2.2 native／exact 独立保存

令 $A^{\mathrm{native}}_t$、$A^{\mathrm{exact}}_t$ 为第 $t$ 轮 VAL CW 的两种 AUC。分别选择首次严格最大值：

$$
\begin{aligned}
t^*_{\mathrm{native}}
&=\min\left\{t\in\{1,\ldots,T\}:A^{\mathrm{native}}_t
=\max_{1\le s\le T}A^{\mathrm{native}}_s\right\},\\
t^*_{\mathrm{exact}}
&=\min\left\{t\in\{1,\ldots,T\}:A^{\mathrm{exact}}_t
=\max_{1\le s\le T}A^{\mathrm{exact}}_s\right\}.
\end{aligned}
$$

实现中，两个最优值分别维护，只有新值严格大于已有最优值才更新。相同 AUC 保留较早的 epoch。

| checkpoint | 含义 |
|---|---|
| `best_native.pt` | VAL CW native AUC 最优权重 |
| `best.pt` | `best_native.pt` 的逐字副本，沿用主流程接口 |
| `best_exact.pt` | VAL CW exact AUC 最优权重 |
| `last.pt` | 最新完整 epoch，包含两条最优值、优化器与随机状态 |

根目录 `metrics.json`、`predictions/`、`curves/` 保存 native 选择的主结果；`exact_selection/` 保存 exact 选择的附加结果。两种权重都导出 VAL/TEST、CW/OW 预测与曲线。

**权重选择与 bias 校准分开处理。** 两种选中权重都沿用当前流程：在各自 VAL 上选取 CW/OW native bias，再固定应用到 TEST。exact 权重的命名指 checkpoint 选择依据；其评价同时报告 native/exact AUC 和固定 VAL bias 的 HM。

### 2.3 两种选中权重的均值门控评估

每个选中权重用全部 TRAIN 图像统计各物体查询、各模式的均值：

$$
\bar\gamma_{jk}
=\frac{1}{N_{\mathrm{train}}}\sum_{b=1}^{N_{\mathrm{train}}}\gamma_{bjk},
\qquad \gamma^{\mathrm{mean}}_{bjk}=\bar\gamma_{jk}.
$$

统计不使用图像标签，均值张量为 `[object, rank]`。固定同一 checkpoint，分别导出动态门控和均值替换后的 VAL/TEST 结果，各条件使用自己的 VAL bias。

每个 seed 完成 native、exact 两项均值评估，共 **6 项**；全部复用权重和特征缓存，优化步数为零。每张卡在训练完成后顺序处理自己的两项评估。

## 5. 服务器启动与查看进度

### 5.1 激活环境并启动

```bash
conda activate vgcpod_v1
cd /data/xhw/vgcpod_project
unzip -o vgcpod_v1_roundE_20261020.zip
cd /data/xhw/vgcpod_project/vgcpod_v1_roundE

bash scripts/start_round_e_tmux.sh --gpus 1 2 3
tmux attach -t vgcpod_E
```

按 **Ctrl+b**，松开，再按 **d**，离开 tmux 后继续运行。GPU1/2/3 为物理卡号，各子进程内部使用 `cuda:0`。启动器保存激活环境的 Python 绝对路径。

默认数据与对照目录：

```text
/data/xhw/vgcpod_v1_runs/cache_ut_clip_l14
/data/xhw/vgcpod_v1_runs/roundA_20261019
/data/xhw/vgcpod_v1_runs/roundC_20261020
/data/xhw/vgcpod_v1_runs/roundD_20261020
```

本轮输出目录为 `/data/xhw/vgcpod_v1_runs/roundE_20261020`。

### 5.2 查看进度与结束状态

```bash
tail -f /data/xhw/vgcpod_v1_runs/roundE_20261020/launcher.log
```

查看三个 seed 的 epoch 日志和整轮退出码：

```bash
tail -n 10 /data/xhw/vgcpod_v1_runs/roundE_20261020/logs/E1_seed3351.log
tail -n 10 /data/xhw/vgcpod_v1_runs/roundE_20261020/logs/E1_seed3352.log
```

`RUNNING` 表示本轮还在运行；**0** 表示三项训练、六项门控评估和汇总全部完成。主日志同时出现 `ROUND_E_COMPLETE ... training_jobs 3 mean_gate_jobs 6`。

`tail -f` 持续等待新内容，按 Ctrl+C 退出查看即可。完成后 tmux 保留终端。非零退出码时，主日志与 `round_e_status.json` 保存具体错误和任务日志路径。

### 5.3 中断后继续

上一轮进程退出后执行：

```bash
conda activate vgcpod_v1
```
