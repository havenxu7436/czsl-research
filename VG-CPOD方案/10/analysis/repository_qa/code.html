1. 原始残差分支与共享均值

model.py在原train_residual路径旁新增train_centered：

if self.gate_input == 'train_residual':
    gate_input = F.normalize(fo - self.gate_fo_mean[None], dim=-1,
                             eps=c.get('gate_residual_eps', 1e-12))
elif self.gate_input == 'train_centered':
    gate_input = fo - self.gate_fo_mean[None]

两种分支都使用固定gate_fo_meanbuffer；后续sigmoid、η=0.25模式中心化和全局g的CP读出相同。I2只通过配置把tau_gamma设为0.56。

engine.py的模型构造条件扩展为接受train_residual和train_centered，两种输入都调用原均值加载函数。gate_features.py仅将H1专用提示改为TRAIN中心化通用提示，统计与加载计算沿用H版本；mean_gate_eval.py逐字沿用H组。checkpoint保存并恢复固定buffer，native／exact评价直接读取保存的均值。
