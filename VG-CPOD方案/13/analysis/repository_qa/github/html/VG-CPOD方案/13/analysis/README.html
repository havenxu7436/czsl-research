VG-CPOD 13 · L组：完整数据分析与下一步实验方案

报告日期：2026-10-23；实验归档日期：2026-10-22。数据集：UT-Zappos，CLIP ViT-L/14。分析对象：trustcpf_conditional_v2_results_20261022_232124.tar.gz 内的九组完整训练、VAL/TEST 逐图像预测和模型权重。

建议结束当前“冻结视觉特征＋静态知识残差”的扩展，把下一轮集中在可训练视觉下的属性判别：同一物体、同一位置先比较两个属性，再汇聚局部证据。安排 Global、Pool-first、Compare-first 三组，每组三个 seed，共九次训练，使用物理 GPU 1、2、3。

这个决定来自三条相互关联的结果：Knowledge 比 Base 平均提高 0.6170 CW AUC、0.6001 OW AUC，但 Shuffle 达到更高均值；Knowledge 在三个 seed 的 CW 上均低于 Shuffle。进一步看预测，Knowledge 的主要变化是减少未见样本被判成该物体的已见搭配；在未见候选之间比较时，它没有提高准确率。知识分支确实参与了训练，残差也足够大，因此继续增加效用建模、选图或噪声实验，已经偏离当前最有价值的问题。

本文件先交代完整数据证据，再给出一套可以直接据此实现的下一轮方案。新方案中的视觉机制是待检验的研究假设；本次已完成的是结果重算、实现分析和公式核验。

负 alpha 的精确含义来自：

$$T_0+\alpha(T_K-T_0)=(1-\alpha)T_0+\alpha T_K.$$

这是有符号的外推组合，不是知识置信度。由于 $T_K$ 本身也在训练，alpha 为负不能单独解释为“知识是错误的”。也没有理由仅因为负号而加 sigmoid 限制后重跑整条链路。

4.2 为什么 Shuffle 也能获得收益

令 $g(x)$ 是冻结 CLIP 的全局特征；$e_a,e_o,e_{ao}$ 为固定文本向量；$z_a,z_o$ 为训练后的知识原型。当前完整条件分数可以合并为：

$$\begin{aligned} c_{ao}(x)&=g(x)^\top v_{ao},\\[4pt] v_{ao}&=\kappa e_{ao}+B_c C_c^\top e_{ao}\\[4pt] &\quad+\rho\kappa W_c\left[(1-\alpha)(A_u e_a\odot A_v e_o) +\alpha(A_u z_a\odot A_v z_o)\right]. \end{aligned}$$

训练完成后，$v_{ao}$ 与图像无关。类型消息、原型更新和 CP 组合最终都变成静态分类器权重；条件 logits 对冻结的 $g(x)$ 仍是线性函数。它能改变原有视觉表示上的边界，却没有引入新的、随图像变化的局部语义证据。softmax 与联合归一化是后续概率运算，不改变这个条件打分层的性质。

两份 CP 项相加的张量 CP 秩上界可以到 64，但它们共享同一个 $W_c$，视觉方向仍落在至多 32 维的共同子空间。把“秩上界变大”写成“增加了新的视觉信息”是不成立的。

这给出一个与数据一致的机制解释：真实附件和打乱附件都给训练提供了可调整的静态参数化。模型利用这些自由度重排候选，而真实附件的语义对应关系没有额外胜出。

4.3 与此前路径合并后的决策

v1 的 capacity 优于效用选择，说明当时复杂的关系效用流程没有压过简单参数化。本轮恢复 G0 后，Knowledge 仍被同容量 Shuffle 超过；两轮结果共同削弱了继续投入静态外部知识选择的理由。

另外，历史 β=0.05 的实验曾将 unseen 条件属性准确率提高至约 25.19%，但 TEST CW/OW 均值约为 34.03/24.35，低于 G0 的 34.51/25.18。仅调整训练支持集的偏好可以改变属性指标，却未形成更好的联合识别。这也是下一轮继续使用既有 β=0.075、把精力放到视觉学习上的依据。

因此，本轮结果归档为静态知识路径的阶段性结论；下一轮直接进入一套完整的视觉判别比较。原有噪声、选图、效用审计不再进入下一轮训练队列。

5. 下一轮拟议主方案：可训练视觉中的“先比较，再汇聚”

5.1 问题、定位与三组比较

研究问题：两个属性是否应先在同一个图像位置进行比较，再汇聚其对同一物体的判别证据？ 常规非线性局部汇聚允许每个属性分别寻找高响应位置；这些位置可以不同，也可能由共同响应推动。先比较逐位置差值，可以把任务梯度直接分配到区分属性的证据上。

当前预测只包含全局 logits，没有 patch 响应，所以它不能直接证明“共同局部响应”已经是当前错误的成因。下一轮将这一定义明确的机制放进同参数对照中验证。目标同时包含减少已见搭配误选、改善多候选未见内部排序和提升联合 AUC。

这条主线延续此前 VG-CPOD 的局部判别方向，并把规模收敛到 UT-Zappos 的九次训练：

模型 视觉能力与条件读出 本轮回答的问题
R0：Global 可训练视觉 Adapter，条件头读取 CLS 让现有全局评分器获得视觉任务梯度能改善多少
R1：Pool-first 同一 Adapter 与评分器；逐属性先汇聚 patch 响应 普通局部证据学习相对全局读取的收益
R2：Compare-first 同一 Adapter 与评分器；同位置先比较，再汇聚并还原属性 logits 比较与汇聚顺序本身是否有价值

R2−R1 是核心机制比较；R1−R0 说明局部读取带来的变化。三组的可训练参数集合、数量、优化器步数和选模规则相同。历史 G0 作为已有参考，无须新增一组复训。

条件属性学习已在 CANet（CVPR 2023） 中研究；CPF（ICCV 2025） 使用条件概率框架和条件视觉细化；FILIP 已使用视觉—文本 token 级晚交互。因此，Adapter、局部 token 或条件概率分解本身都不能作为创新结论。本方案的待验证贡献集中在“同位置成对比较后再边缘化”的算子及其对未见组合判别的作用。

本地 G0/CPF＋CP 是当前工程中的条件概率评分实现，不能直接称为原 CPF 完整模型的复现；原论文的视觉细化等组件与本地基座不同。

5.2 共同视觉模型与评分器

使用同一份 OpenAI CLIP ViT-L/14、224×224 输入。视觉 Transformer 隐藏维度 1,024，最后层投影维度 768，patch 数为 256。冻结预训练主权重，在最后四个视觉 block 的 MLP 旁加入 bottleneck64 的并行 Adapter。以列向量记每个 token，在注意力残差之后的 $h$ 上计算：

$$\begin{aligned} \widetilde h&=\operatorname{LN}_2(h),\\[4pt] h'&=h+\operatorname{MLP}(\widetilde h) +0.1\,U_b\operatorname{GELU}(D_b\widetilde h),\\[4pt] D_b&\in\mathbb R^{64\times1024},\qquad U_b\in\mathbb R^{1024\times64}. \end{aligned}$$

Adapter 不带 bias，$D_b$ 以标准差 0.01 的高斯分布初始化，$U_b=0$。零输出初始化使初始视觉前向等于原 CLIP。模型在最后层对 CLS 和 patch 使用 ln_post、视觉投影与 L2 归一化，得到 $g,p_n\in\mathbb R^{768}$。官方默认前向只输出 CLS；下一轮要显式返回 patch，并将这条路径接入梯度。CLIP 官方模型实现

各组从同 seed 的 G0 载入头参数。冻结文本向量和 $A_u,A_v$，训练 $B_o,C_o,B_c,C_c,W_c$ 以及视觉 Adapter。与 v2 相比，物体头也参与更新，以便改进约 70% 的独立物体识别。

共同条件评分函数对任意视觉向量 $v$ 定义为：

$$\begin{aligned} u_a&=A_u e_a,\qquad v_o=A_v e_o,\\[4pt] R(v,a,o)&=\kappa v^\top e_{ao} +(v^\top B_c)(e_{ao}^\top C_c)^\top +\rho\kappa v^\top W_c(u_a\odot v_o). \end{aligned}$$

保持 CP rank32、低秩头 rank8、$\kappa=20$、$\rho=0.15$。R0 使用 $U_{ao}=R(g,a,o)$。R1/R2 使用相同的局部响应与物体条件位置权重：

$$r_{nao}=R(p_n,a,o),\qquad w_{no}=\frac{\exp(\kappa p_n^\top e_o)}{\sum_{k=1}^{N}\exp(\kappa p_k^\top e_o)}.$$

$w_{no}$ 对同一物体的全部属性相同，随视觉 Adapter 训练而变化。训练和推理都对所有候选物体计算，实际推理不提供真实物体标签。

同一参数初始化不意味着三组的初始预测相同：R0 延续全局读出，R1/R2 从一开始就使用各自的局部读出。应保存 epoch0 的 VAL 结果说明读出转换的起点；正式选模仍统一使用 epoch1—10。

5.3 R1 与 R2 的精确定义

R1：先分别汇聚，再比较。

$$\ell_{ao}=\log\sum_n w_{no}\exp(r_{nao}),\qquad U^{\rm pool}_{ao}=\ell_{ao}-\frac1A\sum_b\ell_{bo}.$$

减去属性均值不改变 softmax，只使两组都采用零和 logits。

R2：先逐位置比较，再汇聚。 对属性对 $(a,b)$：

$$\begin{aligned} \delta_{n,ab,o}&=r_{nao}-r_{nbo},\\[4pt] Z^{+}_{ab,o}&=\sum_n w_{no}\exp(\delta_{n,ab,o}/2),\\[4pt] Z^{-}_{ab,o}&=\sum_n w_{no}\exp(-\delta_{n,ab,o}/2),\\[4pt] m_{ab,o}&=\log Z^{+}_{ab,o}-\log Z^{-}_{ab,o}. \end{aligned}$$

这是两个方向对称的局部能量配分函数之对数比。若定义二元概率 $q=Z^+/(Z^++Z^-)$，则 $m=\log[q/(1-q)]$。系数 $1/2$ 保证单 patch 时 $m_{ab,o}=r_{1ao}-r_{1bo}$。

成对 log-odds 一般不满足传递一致性，需要投影成同一组多类 logits。UT 只有 16 个属性，直接使用全部 120 个无序属性对，不引入稀疏图超参数：

$$U_o=\underset{\mathbf1^\top U=0}{\operatorname{argmin}} \frac12\sum_{a<b}\left[(U_a-U_b)-m_{ab,o}\right]^2.$$

由于 $m_{ba,o}=-m_{ab,o}$，第 $a$ 个分量的一阶条件为

$$A U_a-\sum_bU_b-\sum_bm_{ab,o}=0.$$

代入零和约束得到唯一解：

$$\boxed{U^{\rm compare}_{ao}=\frac1A\sum_bm_{ab,o}}.$$

完整图在零和子空间上的 Hessian 是 $A I$，因此解唯一。计算只需成对 margin 的行均值，无须求逆、图网络或额外训练损失。将 R1 的 $m_{ab}=\ell_a-\ell_b$ 代入同一投影，恰好恢复 $\ell_a-\overline\ell$，所以 R1/R2 的比较确实落在局部边证据的计算方式上。

5.4 算子能解决什么，不能由公式直接推出什么

固定位置权重，给某物体全部属性在位置 $n$ 加上共同响应 $h_{no}$，R2 的差值保持不变：

$$r'_{nao}=r_{nao}+h_{no} \quad\Longrightarrow\quad \delta'_{n,ab,o}=\delta_{n,ab,o} \quad\Longrightarrow\quad m'_{ab,o}=m_{ab,o}.$$

分别做非线性汇聚通常不具备这个性质。例如两属性在三个位置的响应为 $(4,0,0)$、$(0,3,0)$，位置权重均匀，给两者都加 $(0,5,0)$：

方法 添加共同项前的 a−b 分数 添加共同项后
R1：分别汇聚后相减 +0.9411 −2.6825
R2：先比较再汇聚 +0.4274 +0.4274

这个例子说明两种算子不同，尚不代表真实图像上的性能。实际图像变化还可能改变 $w$，完整模型需要端到端评价。

尤其要结合本轮错误模式澄清：R2 不会自动去掉已见搭配偏好。 如果加入属性特有、位置无关的偏置 $b_{ao}$，有

$$\begin{aligned} r'_{nao}&=r_{nao}+b_{ao},\\[4pt] m'_{ab,o}&=m_{ab,o}+b_{ao}-b_{bo},\\[4pt] U'_{ao}&=U_{ao}+b_{ao}-\frac1A\sum_b b_{bo}. \end{aligned}$$

类别偏置会被保留下来。因此，新机制的目标是学习足以区分属性的图像证据，而不是在代数上保证 seen/unseen 去偏。若只提高完整候选下的准确率，却不改善多候选未见排序，应继续解释为偏好变化。

其梯度具有明确的局部作用。令

$$\pi^{\pm}_{n,ab,o}=\frac{w_{no}\exp(\pm\delta_{n,ab,o}/2)}{Z^{\pm}_{ab,o}},\qquad \left.\frac{\partial m_{ab,o}}{\partial\delta_{n,ab,o}}\right|_{w} =\frac{\pi^+_{n,ab,o}+\pi^-_{n,ab,o}}{2}.$$

这个偏导非负，对位置求和为 1；支持与反对该属性的差异位置都可以接收梯度。实际训练同时通过 $w$ 反传。单 patch 时，该机制退化为普通属性响应减去均值；多 patch 才能产生新的汇聚行为。

上述反对称性、共同项不变性、类别偏置传递、单位置极限、完整图正规方程和梯度恒等式均已用 float64 构造数组核验，最大误差小于 10⁻¹⁵。数学定义已核验，实际识别表现由下一轮九组训练评价。

5.5 概率与训练目标

物体分支与条件分支共同形成联合分数：

$$\begin{aligned} S_o(x)&=\kappa g^\top e_o+(g^\top B_o)(e_o^\top C_o)^\top,\\[4pt] p(o\mid x)&=\operatorname{softmax}_o S_o(x),\\[4pt] p(a\mid o,x)&=\operatorname{softmax}_a U_{ao}(x),\\[4pt] J_{ao}(x)&=\log p(o\mid x)+\log p(a\mid o,x). \end{aligned}$$

继续使用 G0 的训练目标。对训练真值 $y$ 与训练组合集合 $\mathcal C_{\rm tr}$，令

$$\begin{aligned} \ell_{\rm pair}&=-J_y+\log\sum_{c\in\mathcal C_{\rm tr}}\exp J_c,\\[4pt] \ell_{\rm support}&=-\log\sum_{c\in\mathcal C_{\rm tr}}\exp J_c. \end{aligned}$$

因为 $\ell_{\rm cond}+\ell_{\rm obj}=-J_y=\ell_{\rm pair}+\ell_{\rm support}$，原损失可严格改写为：

$$\begin{aligned} \mathcal L &=\frac{1.5}{1+\beta}\mathbb E\left[\ell_{\rm pair}+\beta(\ell_{\rm cond}+\ell_{\rm obj})\right]\\[4pt] &=1.5\,\mathbb E\ell_{\rm pair}+\frac{1.5\beta}{1+\beta}\mathbb E\ell_{\rm support}\\[4pt] &=1.5\,\mathbb E\ell_{\rm pair}+\frac9{86}\mathbb E\ell_{\rm support},\qquad\beta=0.075. \end{aligned}$$

支持集项会把概率质量向训练组合集中，这是目标函数的明确性质；本轮数据尚不能将全部已见搭配误选归因于这一项。三组保持同一个目标，直接观察视觉算子能否带来更好的组合判别。
