# L组条件知识残差：合理性复核与最终执行方案

本轮定位为一组集中的机制实验：检验正确知识能否在已验证的强 CPF 基底上改善条件属性判别。正式执行 Base / Knowledge / Shuffle × 三 seed，共 9 次训练；GPU1/2/3 各负责一个 seed。现有 v1 的效用预测与选图路线已经结束。

## 1. 合理的部分

历史 G0 的三 seed TEST 平均约为 34.51 CW / 25.18 OW，明显高于当前 v1 的基底。恢复它的评分参数化可以避免在一个明显偏弱的起点上解释知识作用。完整静态 CP 始终保留，消除了上一版 capacity 用完整三元项、图组仅用三元差分的函数形式差异。

v1 中，robust 给定真实物体后的属性准确率为 37.90%，capacity 为 28.13%；robust 的联合物体命中率却更低。因而本轮固定物体概率，把修改集中到条件属性项，是与现有误差证据一致的选择。该物体命中率来自联合 top-1，不能据此断言独立物体头是唯一原因；新版会同时保存物体 logits 与条件 logits，直接区分两者。

三组对照覆盖主要问题：Knowledge−Base 衡量整个分支，Knowledge−Shuffle 在参数量相同的分支间比较正确知识附件。两个差值一起报告，避免把增加参数的作用算作知识内容的作用。

## 2. 公式复核发现的可辨识性问题

前一份方向方案允许属性和物体 CP 投影 $A_u,A_v$ 与知识消息同时自由训练。设属性文本行矩阵为 $E_a$，属性因子为 $U=E_aA_u^\top$。当文本矩阵具有满行秩时，对任意目标因子 $U_*$，都可以取：

$$
A_u^\top=E_a^{+}U_*+N,
\qquad E_aN=0.
$$

因此原始属性文本经自由投影就能表达任意该词表上的低维属性因子。物体一侧同理。改变知识原型后再自由更新两套投影，知识几何与投影参数可能互相补偿，最终差异不容易归于知识内容。

另一个代数事实是，本轮残差形式可写为：

$$
T_0+\alpha(T_K-T_0)=(1-\alpha)T_0+\alpha T_K.
$$

它是两个共享视觉读出的 CP 项之和，CP 秩上界为原秩的两倍；这不保证实际秩加倍。Knowledge 相对 Base 的提升可能包含表示容量变化，所以 Shuffle 必须保留。这一结构本身不是已经确立的新方法贡献。

## 3. 已落实到代码的两项优化

**固定 G0 已学好的属性／物体 CP 投影。** 三组都冻结 $A_u,A_v$，同时冻结物体评分的 $B_o,C_o$。共同可训练参数为 $B_c,C_c,W_c$。Knowledge 与 Shuffle 另外训练类型消息矩阵 $L_t,R_t$ 和标量 $\alpha$。这样保留了一个稳定的 primitive 坐标系，减少知识原型与自由投影之间的补偿；语义内容的收益仍通过真实／打乱附件比较判断。

**降低已有条件头的续训学习率。** G0 已经完成训练并经过 VAL 选模，继续训练采用原学习率的 1/5：$B_c,C_c$ 使用 $2\times10^{-4}$，$W_c$ 使用 $6\times10^{-5}$。新消息参数保持 $3\times10^{-4}$，新标量 $\alpha$ 使用 $10^{-3}$。三组共同参数使用相同配方，不增加学习率网格。

| 项目 | 最终设置 |
| --- | --- |
| 数据 | 现有 UT-Zappos natural split；精确复用 G0 全局 CLIP 缓存 |
| 初始权重 | 三个 G0 的 best_native.pt，原选中 epoch 为 8、8、9，已随包提供 |
| 冻结 | CLIP、文本、$B_o,C_o,A_u,A_v$ |
| 三组共同训练 | $B_c,C_c,W_c$，共 36,864 个参数 |
| 知识两组新增训练 | $L_t,R_t,\alpha$，新增 73,729 个；合计 110,593 个 |
| 知识 | OI12、OE36、AE48，确定性聚合；Shuffle 使用 seed7101 的固定附件映射 |
| 初始残差 | $\alpha=0$，$L_t$ 高斯标准差0.01，$R_t=0$；三组初始输出与原 G0 完全一致 |
| 训练 | 10 epochs、batch64、AdamW、梯度范数裁剪1.0 |
| 调度 | 逐 epoch 余弦衰减，最后一个 epoch 为初始学习率的1% |
| 选模 | epoch1–10 的 VAL CW native AUC 最大值；相同值选更早 epoch |
| 评估 | 同一权重评价 CW/OW；TEST 的 bias、temperature 均来自对应 world 的 VAL |

训练目标继续使用 G0 的 $\beta=0.075$ 配方，不加入新损失。代码记录 G0 起始 VAL AUC，便于判断续训相对初始点的变化；它不参与 epoch1–10 的选模候选。

## 4. 这轮能够回答什么

主指标是 CW/OW AUC 与 Knowledge−Base、Knowledge−Shuffle 的逐 seed 差值。同步报告未见组合的真实物体条件属性准确率、真实属性对最强错误属性的 margin、独立物体 top-1、联合物体命中率，以及 alpha 和残差幅值。

Knowledge 同时优于另外两组，说明在稳定基底和固定 primitive 坐标下，正确附件能够提供有用的条件信息。只有相对 Base 的优势，主要应解释为新增分支或容量带来的收益。如果两项差值都没有清楚增益，本轮已经完成知识方向的主要验证，后续投入转向此前讨论的可训练局部视觉判别。

**研究价值判断：这套方案适合做下一轮集中的知识机制实验；其直接性和可解释性优于继续扩展 v1 的效用链。它的当前目标是检验知识增益，论文方法的创新定位要建立在该增益及其机制结果之上。**
