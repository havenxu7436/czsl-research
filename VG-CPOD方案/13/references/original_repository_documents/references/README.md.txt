# v2 证据与版本演进

[v1结果与分析入口](../../v1/analysis/README.md)提供选择下一轮方向的依据。[VG-CPOD G0阶段](../../../VG-CPOD方案/08/README.md)提供强CPF＋静态CP基底；三个G0最优权重随v2包保存，来源SHA256见[资产记录](../configs/trustcpf_conditional_v2/assets/provenance.json)。

最终v2保留完整静态CP，冻结物体评分与属性／物体投影，使用共同条件读出加知识残差。与早期方向相比，两项已落地修改是冻结Au/Av，以及把已有条件头学习率降到历史配方的1/5。最终执行以[修订方案](../REVISED_PLAN.md)、[公式代码](../FORMULAS_AND_CODE.md)和[default.json](../configs/trustcpf_conditional_v2/configs/default.json)为准。
