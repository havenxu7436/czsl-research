# VG-CPOD v1 实验结果分析

数据日期：2026-10-18。实验：UT-Zappos / 冻结 CLIP ViT-L/14 / 主矩阵 3 seeds。

**本轮的最佳 CW 模型是静态全局修正 V1，最佳 OW 模型是 D0。完整 VG-CPOD（V5）的 CW 固定偏置 HM 有提升，但 CW AUC 接近 D0，OW AUC 下降。下一轮优先修复未见组合的属性迁移，再检验视觉门控和视觉伙伴机制。**

- V1 相对 D0：TEST CW AUC **+2.144** 点，三个 seed 全部提升；OW AUC **−1.135** 点。
- V5 相对 D0：TEST CW AUC **+0.385** 点，仅一个 seed 提升；OW AUC **−3.704** 点，三个 seed 全部下降。
- V5 的 TEST CW HM **+5.954** 点，OW HM **−7.072** 点。CW 的单点校准收益与 OW、未见组合识别的退化同时存在。
- 三项核心对照中，局部读出使 CW AUC 下降 **1.461** 点，视觉门控再下降 **0.941** 点，视觉伙伴相对均匀伙伴变化 **−0.043** 点。当前完整实现未形成稳定的联合收益。

本报告的主 AUC 为与原训练选择一致的 **AUC_native**；同时用 **AUC_exact** 检查完整临界偏置曲线。AUC 以面积乘 100 计，差值单位为绝对点数。HM 为使用对应 **VAL** 集选出的偏置在 TEST 上计算的调和均值，不用 TEST 最优偏置代替。

表中的“均值 ± 标准差”使用三个 seed 的样本标准差。对照差值先在相同 seed 内相减，再计算均值与标准差；它与分别计算两组标准差后相减不同。

```math
\begin{aligned}
\Delta_s &= m_s^{\mathrm{new}}-m_s^{\mathrm{ref}},\\
\overline{\Delta} &= \frac{1}{3}\sum_{s=1}^{3}\Delta_s,\\
\mathop{\mathrm{SD}}\nolimits (\Delta) &= \sqrt{\frac{1}{2}\sum_{s=1}^{3}(\Delta_s-\overline{\Delta})^2}.
\end{aligned}
```

### 3.1 局部读出：当前最明确的负向变化

V1L−V1 的 CW AUC 为 −1.461 点、OW AUC 为 −3.374 点，后者三个 seed 全部下降。GT-object 属性准确率从 V1 的 36.04% 降到 V1L 的 30.62%。

动态模型也有同方向证据：V2 相对使用全局特征的 V3，CW AUC 下降 0.579 点，三个 seed 全部下降；GT-object 属性准确率下降 4.862 点。类别查询读出在当前冻结 CLIP 特征上削弱了对条件属性识别有用的信息，是优先检查的位置。

### 3.2 视觉门控：补回部分属性识别，联合 CW AUC 继续下降

V2−V1L 的 GT-object 属性准确率提高 1.235 点，三个 seed 全部提高；但 CW AUC 下降 0.941 点，三个 seed 全部下降。OW AUC 均值提高 0.720 点，逐 seed 差值为 +1.671、−2.148、+2.638，方向不一致。

门控改善了部分条件属性分数，但这项改进没有转化为稳定的组合排序收益。下一轮需要同时记录条件属性与联合组合指标，检查修正幅度、物体概率和候选归一化之间的关系。

### 3.3 视觉伙伴：实际效果接近均匀聚合

V5−V4 的 CW AUC 为 −0.043 点、OW AUC 为 +0.011 点；完整扫描差值分别只有 −0.007 和 +0.002 点。CW HM 在三个 seed 均下降，平均 −0.446 点。

V5−V2 的 GT-object 属性准确率提高 0.938 点，但均匀伙伴 V4 也有相近提升。这部分收益主要由辅助属性分支及其损失贡献，视觉伙伴分配本身几乎没有额外收益。

### 3.4 错配门控：已学成近常数，需补更直接的图像依赖测试

V6 的选中 epoch 门控均值为 **1.9887**，池化方差约 **0.000034**，接近公式上界 2。V2 对应均值 **1.1217**、方差 **0.2470**。V6 的训练曲线从第二个 epoch 起已接近饱和常数。

V6 的结果说明模型能够适应错配输入并把门控变成近常数。它比较了两种分别训练后的解，而固定 checkpoint 上的门控置换，才直接测量预测对图像匹配关系的依赖。现有方差同时混合图像、物体和模式三个轴；下一轮应分别记录各轴方差。

## 5. 机制诊断：伙伴分布、正交约束与训练进程

![门控、正交损失与伙伴分布诊断](figures/04_mechanisms.png)

### 5.1 视觉伙伴分布过平，缺少选择性

对每个图像和属性的伙伴分布，定义熵和相对均匀分布的 KL：

```math
\begin{aligned}
H(\pi)&=-\sum_{j=1}^{12}\pi_j\log\pi_j,\\
\mathrm{KL}(\pi\Vert U)&=\log 12-H(\pi),\qquad U_j=\frac{1}{12}.
\end{aligned}
```

V5 默认温度 0.1 下，平均熵 **2.47184**，均匀熵为 **2.48491**；归一化熵 **99.47%**，平均 KL 为 **0.01307 nats**，`exp(平均熵)` 为 **11.84/12**。温度降到 0.05 后，该数仍为 **11.39/12**。

伙伴分布由冻结的属性查询特征与物体文本计算，熵跨 epoch 保持不变是实现的自然结果。分布接近均匀，与 V5/V4 的近零差值一致。只在 0.05–0.2 范围调温度，本轮几乎没有改变最终指标。

V5 选中 epoch 的加权属性辅助 CE 约为 **0.1924**，加权 JS 约为 **0.00184**，相差约 **105 倍**。这描述当前损失数值尺度；下一轮同时测量它们对共享参数的梯度范数，以确定各项约束对更新的实际影响。

### 5.2 正交损失改变了基，但准确率收益接近零

V5 的选中权重模式基有效秩约为 **11.51/32**，V7 为 **9.82/32**；平均行间绝对余弦从 V7 的 **0.196** 降到 V5 的 **0.149**。这里有效秩按 Gram 特征值的参与率计算：

```math
G=BB^\top,\qquad r_{\mathrm{eff}}=\frac{(\mathop{\mathrm{tr}}\nolimits G)^2}{\mathop{\mathrm{tr}}\nolimits (G^2)}.
```

正交项确实减少了模式基的相关性，但 V5−V7 的 CW AUC 为 **−0.120** 点，三个 seed 全部下降；OW AUC 为 **+0.018** 点。当前权重下，它改善了基的几何形状，准确率变化很小。

当前损失为 `||BBᵀ−I||²_F / r²`，权重 0.001。V5 在选中 epoch 的加权正交项约占总损失 **0.105%**。继续调该项时，应按模式基几何与梯度尺度确定权重，并保留无正交对照。

## 7. 下一轮实践顺序

### 第一步：用已有 checkpoint 做诊断，不增加训练组数

1. **读取同一个 V2/V5 checkpoint，分别测试真实门控、重复随机置换门控、固定 `γ=1`、固定每个物体和模式的平均门控。** 沿用该 checkpoint 的 VAL 偏置，同时重算整条 AUC 曲线。这样直接测量图像匹配和动态变化带来的预测增量。
2. **输出修正与基线 logits 的均方根、条件属性 margin 变化、各模式贡献。** 在 VAL 按已见/未见组合汇总；在本轮 TEST 的 Suede 组合上解释分数变化。分别输出图像轴、物体轴、模式轴的门控方差与接近 0/2 的比例。
3. **比较 V4/V5 的实际伙伴因子。** 测量 `π` 相对均匀的 L1/KL、`πV` 相对均匀伙伴均值的变化，以及修正 logits 的差异。熵高说明选择性弱，因子与 logits 的变化能量直接说明它对预测的作用。

现有本地备份足够复算预测指标和分析权重；上述前向诊断在服务器读取已有 `g/fa/fo` 特征缓存完成。

### 第二步：先解决读出与修正强度，用小矩阵选方向

保留 **D0、V1、V2** 的现有结果作为基线，固定 rank32、CLIP、数据划分、10 epochs 和验证选择规则。先用 seed3351 比较以下三组新增设置：

| 新设置 | 具体变化 | 主要检验 |
|---|---|---|
| A | V1 的 CP 修正幅度 `ρ` 改为原值的 1/4 | 静态修正减弱后，未见属性与 OW 能否恢复 |
| B | V2 的 CP 修正幅度 `ρ` 改为原值的 1/4 | 动态修正是否同样受幅度影响 |
| C | V2 的读出换为归一化的 `0.5g + 0.5f_o`，门控结构保持不变 | 补回全局信息能否改善纯局部读出的退化 |

三组初筛均先沿用原优化配置。它们是分别相对原 V1 或 V2 的单因素变化，后续再组合表现最好的因素。若修正幅度在训练中迅速被可训练权重补偿放大，下一步显式约束修正能量或归一化因子，而不继续只缩小 `ρ`。

使用 **VAL CW AUC、VAL OW AUC、VAL 未见组合 GT-object 属性准确率** 联合判断；主 checkpoint 继续按预先固定的 VAL CW 规则选择。优先补齐改善 CW 且减少 OW/未见属性退化的设置到 seed3352/3353，再汇报完整 TEST 结果。

### 第三步：在条件分支稳定后重做伙伴选择

先让伙伴权重对图像或属性产生清晰的选择性，再跑视觉伙伴与均匀伙伴的等参数对照。可从相似度中心化/标准化、top-k 支持集或可训练投影中选择一种单独实验；记录熵、有效伙伴数、伙伴因子变化及梯度。候选与支持关系仅由训练数据构造。

保留“只有属性辅助 CE”“再加 JS”“均匀伙伴”“视觉伙伴”几个明确对照。当前 V4/V5 同时包含辅助 CE 和 JS；拆开它们可判断已有属性收益来自哪一项。视觉伙伴取得相对均匀伙伴的稳定配对收益后，再投入多数据集验证。

**建议的资源分配是：先做已有权重诊断，再做三组单 seed 初筛，补齐有效设置的另外两个 seed，最后重新投入伙伴分支。**
