## 发布校验

```bash
python tools/verify_release.py
```

`release_manifest.json` 记录包内文件SHA256。实验运行另外记录实际特征manifest、源码、配置、种子、环境和checkpoint身份。

这些测试用于验证实现。正式准确率、耗时和显存结果在服务器真实数据训练后生成。
