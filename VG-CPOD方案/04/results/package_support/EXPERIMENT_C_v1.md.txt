# VG-CPOD 方案 v1：C 组实验实施方案

日期：2026-10-20。框架：冻结 CLIP ViT-L/14；数据：UT-Zappos。

本轮同时运行 C1、C2 和原 B3 的一次补 seed。C1 测量静态修正幅度的收益；C2 研究模式均值为 1 的局部视觉调制；B3 的 seed3352 检查上一轮小幅组合增益的重复性。

## 2. 已实现的公式与推导

### 2.1 CP 修正与概率分解

设全局图像特征为 $g_b\in\mathbb{R}^{d}$，物体查询特征为 $f^o_{bj}\in\mathbb{R}^{d}$。属性、物体模式分别为：

$$
u_i=A_u e_i^a\in\mathbb{R}^{r},\qquad
v_j=A_v e_j^o\in\mathbb{R}^{r},\qquad
W_c\in\mathbb{R}^{d\times r}.
$$

本轮均使用全局特征读取 CP 修正：

$$
\begin{aligned}
\Delta U_{bji}
&=\rho\kappa\,g_b^{\top}W_c
\left(u_i\odot v_j\odot\gamma_{bj}\right),\\
U_{bji}&=U^{\mathrm{base}}_{bji}+\Delta U_{bji},\\
\log p(a_i,o_j\mid x_b)
&=\log\operatorname{softmax}(S_b)_j
+\log\operatorname{softmax}(U_{bj:})_i.
\end{aligned}
$$

$S_b$ 为物体 logits。基础条件 logits 和物体 logits 沿用 A5。张量轴为 `[batch, object, attribute]`。

### 2.2 C1：静态 1.25 倍幅度对照

C1 设置 $\gamma_{bj}=\mathbf{1}_{r}$，并将 ρ 从 0.1 改为 0.125。在相同参数下：

$$
\Delta U^{\mathrm{C1}}_{bji}
=0.125\kappa\,g_b^{\top}W_c(u_i\odot v_j)
=1.25\,\Delta U^{\mathrm{A5}}_{bji}.
$$

它等价于在 ρ=0.1 的静态修正上使用恒定 1.25 的模式系数。C1 从头训练，Bvis 冻结。

### 2.3 C2：模式均值为 1 的局部弱门控

先从局部特征计算模式响应，再沿最后一个模式轴中心化：

$$
\begin{aligned}
z_{bj}&=\frac{B_{\mathrm{vis}}f^o_{bj}}{\tau_{\gamma}},
\qquad q_{bj}=2\sigma(z_{bj})-\mathbf{1}_{r},\\
\bar q_{bj}&=\frac{1}{r}\sum_{k=1}^{r}q_{bjk},\\
\gamma^{\mathrm{C2}}_{bjk}
&=1+\frac{\eta}{2}\left(q_{bjk}-\bar q_{bj}\right),
\qquad \eta=0.25.
\end{aligned}
$$

模式均值满足：

$$
\frac{1}{r}\sum_{k=1}^{r}\gamma^{\mathrm{C2}}_{bjk}
=1+\frac{\eta}{2r}\left(\sum_{k=1}^{r}q_{bjk}-r\bar q_{bj}\right)=1.
$$

由于 $q_{bjk}\in(-1,1)$、$q_{bjk}-\bar q_{bj}\in(-2,2)$，因此：

$$
\gamma^{\mathrm{C2}}_{bjk}\in(1-\eta,1+\eta)=(0.75,1.25).
$$

中心化在每张图像、每个物体内部进行。约束固定模式系数的算术均值，各模式对 logit 的贡献仍由 u、v、Wc 决定。

令 $P=I_r-\mathbf{1}_{r}\mathbf{1}_{r}^{\top}/r$，则梯度形式为：

$$
\gamma^{\mathrm{C2}}=\mathbf{1}_{r}+\frac{\eta}{2}Pq,
\qquad
\frac{\partial\gamma^{\mathrm{C2}}}{\partial z}
=\eta P\operatorname{diag}\!\left(\sigma(z)\odot[\mathbf{1}_{r}-\sigma(z)]\right).
$$

代码使用 PyTorch 自动求导，已用有限差分检查任务损失对 Bvis 的梯度。

### 2.4 保留 A5 的训练目标

$$
\begin{aligned}
\mathcal{L}_{\mathrm{task}}(\beta)
&=\frac{1.5}{1+\beta}\left[
\mathcal{L}_{\mathrm{pair}}+
\beta(\mathcal{L}_{\mathrm{cond}}+\mathcal{L}_{\mathrm{obj}})\right]\\
&=1.5\,\mathcal{L}_{\mathrm{pair}}
+\frac{1.5\beta}{1+\beta}\,\mathcal{L}_{\mathrm{support}},
\qquad\beta=0.1.
\end{aligned}
$$

支持集合项为 $\mathcal{L}_{\mathrm{support}}=-\log\sum_{(i,j)\in\mathcal{C}_{\mathrm{train}}}p(a_i,o_j\mid x)$，系数为 0.13636。C2 加入原正交项：

$$
\mathcal{L}_{\mathrm{C2}}
=\mathcal{L}_{\mathrm{task}}
+\frac{0.001}{r^2}
\left\lVert B_{\mathrm{vis}}B_{\mathrm{vis}}^{\top}-I_r\right\rVert_F^2.
$$

C1 使用静态分支，正交项为零；属性辅助与伙伴分支保持关闭。

## 3. 代码改动与输出

## 7. 单独运行、续训与补 seed

单独运行 C2：

```bash
conda activate vgcpod_v1
cd /data/xhw/vgcpod_project/vgcpod_v1_roundC
CUDA_VISIBLE_DEVICES=2 python -u run.py train \
  --cache /data/xhw/vgcpod_v1_runs/cache_ut_clip_l14 \
  --out /data/xhw/vgcpod_v1_runs/roundC_20261020/C2 \
  --config configs/round_c/C2.json --seed 3351 --device cuda
```

手动续训在命令末尾加 `--resume`。联合队列自动为中断项添加续训参数，已完成项直接跳过。原队列退出后重新启动，可使用新的 tmux 会话名：

```bash
cd /data/xhw/vgcpod_project/vgcpod_v1_roundC
VG_C_SESSION=vgcpod_C_resume bash scripts/start_round_c_tmux.sh \
  --gpus 1 2 3 --cases C1 C2 --seeds 3351 --b3-seed 3352
tmux attach -t vgcpod_C_resume
```

后续给选定配置补两个 seed，以下以 C2 为例：

```bash
conda activate vgcpod_v1
cd /data/xhw/vgcpod_project/vgcpod_v1_roundC
VG_C_SESSION=vgcpod_C_moreseed bash scripts/start_round_c_tmux.sh \
  --skip-b3 --gpus 1 2 --cases C2 --seeds 3352 3353

```
