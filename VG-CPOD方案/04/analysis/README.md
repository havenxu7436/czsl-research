## 2. 静态幅度解释与B3重复结果

C1 与 B3 的 TEST 条件属性 top-1 一致率为 **99.863%**，2,914 张中仅 4 张不同；无偏组合 top-1 一致率为 **99.828%**，仅 5 张不同。C1−B3 的 TEST CW/OW AUC 为 −0.060/+0.012，说明静态幅度调整几乎复现原 B3 的预测行为。

在相同参数下，恒定模式系数对应静态幅度：

```math
\gamma_{bj}=c\mathbf{1}_{r}
\quad\Longrightarrow\quad
\Delta U_{bji}=(c\rho)\kappa\,g_b^{\top}W_c(u_i\odot v_j).
```

B3 的训练门控均值约 1.241，对应 ρ≈0.1241；C1 取 ρ=0.125。公式与预测一致性共同支持“共同放大是 B3 主效应”的解释。

## 5. 本轮之后的方向

C 轮结束时的下一阶段安排为：GPU1 补 C2/3352，GPU2 补 C2/3353，GPU3 运行 D1/3351。D1 在 C2 上仅把 ρ 从 0.1 改为 0.125，检验中心化调制与静态幅度合用的效果。保留 β=0.1、CP LR=3e-4、η=0.25、τγ=0.1、rank32、10 轮与 batch64。

同步在同一 checkpoint 上比较动态图像门控与训练均值门控：

```math
\bar\gamma_{jk}=\frac{1}{N_{\mathrm{train}}}
\sum_{b=1}^{N_{\mathrm{train}}}\gamma_{bjk},\qquad
\gamma^{\mathrm{static}}_{bjk}=\bar\gamma_{jk}.
```

用全部 TRAIN 图像统计各物体查询、各模式均值，再分别导出动态与均值替换的 VAL/TEST；两者各用自身 VAL 选择 bias。这项评估用于分开量化较固定的模式权重与图像相关调制。上述为 C 轮结束时提出的后续实验，04 保存本轮已训练的 C 公式、代码和结果。
