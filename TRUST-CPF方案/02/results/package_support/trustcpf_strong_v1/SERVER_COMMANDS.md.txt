## 6. 本机 Windows PowerShell：下载、校验、解压

新开本机 PowerShell，执行整个代码块：

```powershell
$cpfServer = "xhw@211.87.232.122"
$cpfLocal = "C:\Users\llenovo\Documents\ChatGPT\USG"
$cpfPython = "C:\Users\llenovo\anaconda3\envs\ai-lab\python.exe"
$cpfProject = Join-Path $cpfLocal "trustcpf_strong_v1"

$cpfRemoteReply = ssh $cpfServer 'cat "$HOME/experiments/trustcpf_strong_v1/latest_archive.txt"'
if ($LASTEXITCODE -ne 0 -or $null -eq $cpfRemoteReply) { throw "请先在服务器执行结果打包" }
$cpfRemoteArchive = ($cpfRemoteReply -join "`n").Trim()
$cpfArchiveName = ($cpfRemoteArchive -split '/')[-1]
$cpfLocalArchive = Join-Path $cpfLocal $cpfArchiveName

scp -o ServerAliveInterval=30 -o ServerAliveCountMax=6 "${cpfServer}:$cpfRemoteArchive" "$cpfLocalArchive"
if ($LASTEXITCODE -ne 0) { throw "下载中断，请重新执行本节" }
scp -o ServerAliveInterval=30 "${cpfServer}:${cpfRemoteArchive}.sha256" "${cpfLocalArchive}.sha256"
if ($LASTEXITCODE -ne 0) { throw "校验文件下载未完成" }

$cpfExpectedHash = ((Get-Content -LiteralPath "${cpfLocalArchive}.sha256" -Raw) -split '\s+')[0]
$cpfActualHash = (Get-FileHash -LiteralPath $cpfLocalArchive -Algorithm SHA256).Hash
if ($cpfActualHash -ine $cpfExpectedHash) { throw "SHA256不一致，请重新下载" }

$cpfExtract = Join-Path $cpfLocal ($cpfArchiveName -replace '\.tar\.gz$', '')
& $cpfPython "$cpfProject\scripts\extract_results.py" "$cpfLocalArchive" "$cpfExtract"
if ($LASTEXITCODE -ne 0) { throw "解压失败" }

Write-Host "完整结果：$cpfExtract\trustcpf_strong_v1\work"
Get-Content -LiteralPath "$cpfExtract\trustcpf_strong_v1\work\status.json"
```

解压使用 Python 的 UTF-8 tar 支持，避开此前 Windows tar 的中文路径问题；下载后首先验证 SHA256。重新执行 scp 会重传该文件，不会续传残缺文件。
