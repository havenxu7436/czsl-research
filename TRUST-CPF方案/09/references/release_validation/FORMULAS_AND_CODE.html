1. 本批要回答的问题

第一批中，联合 Absolute 预测器提升了 Q5 效用决策，但正式冻结识别尚未稳定超过 Uniform；同一模型的重复响应也有明显波动。本批同时比较教师阶段匹配与响应平均，正式识别器固定为第一批三个 Uniform-best。

本批保留 TRUST 的主链：关系 on/off 干预 → 效用监督 → 模型响应条件化预测 → 类型预算下的 Bernoulli 分配。CLIP 特征、CPF 强基底、关系库、正式识别权重与评估器沿用第一批。

其中 R\mathcal R 为原模型的 graph regularizer。优化器 AdamW：初始学习率 3×10−43\times10^{-4}，weight decay 10−410^{-4}，batch size 64，梯度范数上限 1。共 T=10MT=10M 个更新，MM 是每轮 batch 数，零起点更新编号 tt：

ηt=η0min⁡ ⁣(t+1M,1)1+cos⁡ ⁣(πmax⁡(0,t−M)max⁡(1,T−M))2. \eta_t=\eta_0 \min\!\left(\frac{t+1}{M},1\right) \frac{1+\cos\!\left(\pi\frac{\max(0,t-M)}{\max(1,T-M)}\right)}{2}.

STOP 集从原 seen/unseen 风险池尚未使用的图像中选出，每组各 256 张；排除教师训练、效用测量和 Q5 评分图像。随机种子为 9401+j9401+j，三 seed 使用相同图像索引。本地实际源数据检查：最少仍有 779 张未用 unseen 图像，满足采样数量。

3. 在新状态重新测量 U-NLL 效用

所有新响应与新监督均使用 θk⋆s,j\theta_{k^\star}^{s,j}。设测量 Query 图像集合为 Uj\mathcal U_j，候选集合为全部训练组合 Ctrain\mathcal C_{\mathrm{train}}：

ℓθ(yi∣xi,b)=log⁡qθ(yi∣xi,b)−log⁡∑c∈Ctrainqθ(c∣xi,b),LU(θ,b)=−1∣Uj∣∑i∈Ujℓθ(yi∣xi,b). \ell_\theta(y_i\mid x_i,b) =\log q_\theta(y_i\mid x_i,b) -\log\sum_{c\in\mathcal C_{\mathrm{train}}}q_\theta(c\mid x_i,b), \qquad L_U(\theta,b)=-\frac1{|\mathcal U_j|} \sum_{i\in\mathcal U_j}\ell_\theta(y_i\mid x_i,b).

对关系 ee，固定背景的其余关系，分别令 be=0b_e=0、be=1b_e=1：

δe,r=LU(θ,b−e(r),0)−LU(θ,b−e(r),1)=1∣Uj∣∑i∈Uj[ℓθ(yi∣xi,b−e(r),1)−ℓθ(yi∣xi,b−e(r),0)]. \delta_{e,r} =L_U(\theta,b^{(r)}_{-e},0)-L_U(\theta,b^{(r)}_{-e},1) =\frac1{|\mathcal U_j|}\sum_{i\in\mathcal U_j} [\ell_\theta(y_i\mid x_i,b^{(r)}_{-e},1) -\ell_\theta(y_i\mid x_i,b^{(r)}_{-e},0)].
ye=1K∑r=1Kδe,r,SE⁡^2(ye)=1K(K−1)∑r=1K(δe,r−ye)2. y_e=\frac1K\sum_{r=1}^K\delta_{e,r}, \qquad \widehat{\operatorname{SE}}^2(y_e) =\frac1{K(K-1)}\sum_{r=1}^K(\delta_{e,r}-y_e)^2.

正效用表示打开关系会降低 unseen NLL。对 Be∼Bernoulli(πe)B_e\sim\mathrm{Bernoulli}(\pi_e)：

−∂∂πeEB∼πLU(θ,B)=EB−e ⁣[LU(θ,B−e,0)−LU(θ,B−e,1)]. -\frac{\partial}{\partial\pi_e}\mathbb E_{B\sim\pi}L_U(\theta,B) =\mathbb E_{B_{-e}}\!\left[ L_U(\theta,B_{-e},0)-L_U(\theta,B_{-e},1) \right].

所以该标签是 Uniform 分布处的期望风险负梯度估计。它解释局部关系贡献；最终策略效果由实际多图识别测量得到。

Q1–Q4 每折 8 个背景，Q5 16 个。背景随机种子为 9301+1000j+r9301+1000j+r，其中 r=0,…,K−1r=0,\ldots,K-1。保留旧测量图像与背景，便于新旧阶段配对分析；on/off 分数重新计算。每个 block 保存真实类别 log probability、组内 margin、跨组阈值和正确门控值，可重算监督。仅 U-NLL 用于本批拟合。

4. 模型响应：单次与两次平均

每条关系使用 8 维响应。Inner 每个组合随机选至多两张训练图像，组合等权、组合内图像等权；对 4 个 Uniform 背景计算 on/off。分别在“全部支持图像”和“该关系目标原语对应图像”上提取四个统计：

he=[EΔℓ,SD⁡(Δℓ),E mean⁡c(Δzc−Δz‾)2,E(H(p+)−H(p−))]all ⊕ [⋯ ]target∈R8. h_e= [\mathbb E\Delta\ell,\operatorname{SD}(\Delta\ell), \sqrt{\mathbb E\,\operatorname{mean}_c(\Delta z_c-\overline{\Delta z})^2}, \mathbb E(H(p^+)-H(p^-))]_{\mathrm{all}} \ \oplus\ [\cdots]_{\mathrm{target}}\in\mathbb R^8.

其中 zcz_c 是候选组合的 joint log probability，Δz=z+−z−\Delta z=z^+-z^-，Δℓ=log⁡p+(y)−log⁡p−(y)\Delta\ell=\log p^+(y)-\log p^-(y)。标准差使用与支持样本权重一致的总体方差；条件于 target 后重新归一化权重。

第一份响应沿用旧教师的支持图像、权重和随机种子。第二份使用原种子加 100000，重新选择 Inner 支持图像和背景，形成独立随机抽样：

hˉe=he(1)+he(2)2. \bar h_e=\frac{h_e^{(1)}+h_e^{(2)}}2.

本批预测器始终用各教师第一份响应训练。平均响应只改变部署输入，不另拟合一套模型；正式模型的两份响应直接复用第一批记录。

5. 九教师联合 Absolute 拟合

拟合教师集合为三个 seed 的 Q1、Q2、Q3，共 J=9J=9 个。输入标准化统计只由这些教师计算。对特征维 dd：

cd=mean⁡j,ehj,e,d,sd=max⁡(SD⁡j,ehj,e,d,10−6),at=max⁡(SD⁡j,e:t(e)=tyj,e,10−12). c_d=\operatorname{mean}_{j,e}h_{j,e,d}, \quad s_d=\max(\operatorname{SD}_{j,e}h_{j,e,d},10^{-6}), \quad a_t=\max(\operatorname{SD}_{j,e:t(e)=t}y_{j,e},10^{-12}).

三种关系类型为 OI、OE、AE。构建按类型分块的 27 维向量：

代码通过线性方程求解，实际岭系数为 α=9λ\alpha=9\lambda。候选 λ∈{0.1/3,1/3,10/3,100/3}\lambda\in\{0.1/3,1/3,10/3,100/3\}。

6. 类型预算概率与匹配置换

对每种类型标准化预测效用；若类型内效用为常数，则该类型 re=0r_e=0：

re=μ^e−mean⁡f:t(f)=t(e)μ^fSD⁡f:t(f)=t(e)μ^f. r_e=\frac{\widehat\mu_e-\operatorname{mean}_{f:t(f)=t(e)}\widehat\mu_f} {\operatorname{SD}_{f:t(f)=t(e)}\widehat\mu_f}.

固定 κ=1\kappa=1，求解等式预算下的严格凹目标：

max⁡πκ∑ereπe−∑e[πelog⁡(2πe)+(1−πe)log⁡(2(1−πe))],s.t.∑e:t(e)=tπe=nt/2,0<πe<1. \begin{aligned} \max_{\pi}\quad& \kappa\sum_e r_e\pi_e -\sum_e\left[\pi_e\log(2\pi_e) +(1-\pi_e)\log(2(1-\pi_e))\right],\\ \text{s.t.}\quad& \sum_{e:t(e)=t}\pi_e=n_t/2,\qquad 0<\pi_e<1. \end{aligned}

拉格朗日一阶条件给出：

log⁡πe1−πe=κre−γt(e),πe=σ(κre−γt(e)). \log\frac{\pi_e}{1-\pi_e}=\kappa r_e-\gamma_{t(e)}, \qquad \pi_e=\sigma(\kappa r_e-\gamma_{t(e)}).

预算和关于 γt\gamma_t 严格递减；二分求得唯一解。96 条关系的三类数量为 12、36、48，期望预算为 6、18、24。Bernoulli 采样固定的是期望数量，每张图的实际关系数可波动。

五次置换仅在同类型中重排概率，保留预算、概率分布和熵，改变关系与概率的对应。随机种子为 7101～7105。reference 响应控制固定新预测器与正式识别器，只替换输入响应的模型状态。

def add_stopping_set(split,cfg):
    s=copy.deepcopy(split)
    used=set(s['train_ids'])
    for partition in ('measure','evaluate'):
        for values in s[partition].values():used.update(values)
    rng=np.random.RandomState(cfg['stop_seed']+s['fold']);stop={};remaining={}
    for group in ('seen','unseen'):
        pool=sorted(set(s[group+'_pool'])-used);remaining[group]=len(pool)
        if len(pool)<cfg['stop_images_per_group']:
            raise ValueError('Fold %d has only %d unused %s stopping images'%(s['fold'],len(pool),group))
        stop[group]=rng.choice(pool,cfg['stop_images_per_group'],replace=False).tolist()
    assert not set(stop['seen'])&set(stop['unseen'])
    s.update(stop=stop,stop_seed=cfg['stop_seed']+s['fold'],stop_remaining=remaining)
    return s

            factor=min((step+1)/warmup,1.)*.5*(1+math.cos(math.pi*max(0,step-warmup)/max(1,total-warmup)))

def fit_ridge(xs,ys,types,alpha,normalization=None):
    x=np.concatenate(xs).astype(np.float64);y=np.concatenate(ys).astype(np.float64)
    t=np.tile(types,len(xs))
    if normalization is None:
        normalization=dict(center=x.mean(0),spread=np.maximum(x.std(0),1e-6),
            scales=np.asarray([max(y[t==k].std(),1e-12) for k in range(3)]))
    center,spread,scales=[np.asarray(normalization[k],dtype=np.float64) for k in ('center','spread','scales')]
    z=design(x,t,center,spread)
    beta=np.linalg.solve(z.T@z+float(alpha)*np.eye(z.shape[1]),z.T@(y/scales[t]))
    return dict(beta=beta,center=center,spread=spread,scales=scales,alpha=float(alpha),
        dimension=int(z.shape[1]),fit_folds=len(xs),intercepts_penalized=True)

def policy(mu, types, strength):
    """Unique equality-budget KL solution in float64; return CPU probabilities."""
    mu = np.asarray(mu, dtype=np.float64)
    types = np.asarray(types, dtype=np.int64)
    if mu.shape != types.shape or not np.isfinite(mu).all() or strength < 0:
        raise ValueError('Invalid utility vector or strength')
    prob = np.full(mu.shape, .5, dtype=np.float64)
    info = {}
    for t in sorted(np.unique(types)):
        ix = types == t
        mean, std = float(mu[ix].mean()), float(mu[ix].std(ddof=0))
        r = (mu[ix] - mean) / std if std > 1e-12 else np.zeros(ix.sum())
        z = strength * r
        gamma = 0.
        if strength > 0 and std > 1e-12:
            lo, hi = float(z.min() - 40), float(z.max() + 40)
            for _ in range(200):
                gamma = (lo + hi) / 2
                p = 1 / (1 + np.exp(np.clip(gamma - z, -700, 700)))
                residual = p.sum() - ix.sum() / 2
                if abs(residual) <= 1e-12:
                    break
                if residual > 0:
                    lo = gamma
                else:
                    hi = gamma
            prob[ix] = p
        error = abs(prob[ix].sum() - ix.sum() / 2)
        if error > 1e-10:
            raise ArithmeticError('Equality budget did not converge')
        info[str(t)] = dict(mu_mean=mean, mu_std=std, gamma=gamma,
                            budget=float(ix.sum() / 2), budget_error=float(error))
    return torch.from_numpy(prob), info
