# TRUST-CPF Stage v1：第二批 10 epoch 完整结果分析

## 5. 重复响应：预测指标改善与决策收益出现分离

以下指标在本批 Q5 上计算；类型中心化 R² 是先在每种关系类型内去均值，再衡量残差。

| 方法 | 整体 Spearman | 类型中心化 R² | 一阶代理收益 | 实际 Q5 AUC 增益 |
| --- | --- | --- | --- | --- |
| Old-Single | 0.257 | 0.0470 | 0.04919 | +1.336 |
| Matched-Single | 0.184 | 0.0412 | 0.05151 | +1.463 |
| Old-Average | 0.313 | 0.0525 | 0.05303 | +1.077 |
| Matched-Average | 0.245 | 0.0437 | 0.05802 | +1.208 |

新预测器使用平均响应后，整体 Spearman 从 0.184 提高到 0.245，一阶代理收益从 0.05151 提高到 0.05802；但实际 Q5 AUC 从 +1.463 降到 +1.208。旧预测器也出现相同方向：Spearman 从 0.257 提高到 0.313，实际 Q5 AUC 从 +1.336 降到 +1.077。

**“响应平均使预测更准”没有自动转化为“图策略更好”。** 平均后的效用还要经过类型内标准化、预算求解与 Bernoulli 图采样，实际概率混合含有关系交互。当前数据表明代理与实际决策的联系仍不充分；单凭相关性或一阶代理增加不能选出更好的策略。

同一正式识别器的两份独立响应，类型内预测排序一致性仍偏低：

| 响应状态 | 旧预测器：ρ／概率 RMSE | 新预测器：ρ／概率 RMSE |
| --- | --- | --- |
| Q5 | 0.546 / 0.186 | 0.513 / 0.175 |
| Reference | 0.488 / 0.155 | 0.463 / 0.178 |
| 正式 Uniform-best | 0.361 / 0.201 | 0.367 / 0.217 |

正式 Uniform-best 的重复排序相关由 0.361 到 0.367，基本没变；概率 RMSE 从 0.201 到 0.217。阶段匹配没有明显提升正式响应的稳定性。这里的概率 RMSE 是各 seed、各类型 RMSE 的均值。

新预测器的原始重复预测 RMSE 虽然更低，但类型内标准化会重新缩放输出；较小的效用数值波动并不保证最终分配概率更稳定。这个机制与保存的概率统计一致。

## 7. 对 TRUST 路线的判断

| 研究点 | 本轮证据 | 结论 |
| --- | --- | --- |
| 关系效用确实存在 | Q5 测量效用 +2.114，三 seed 都超过自身置换均值 | 继续保留 |
| 效用可由响应学习并用于决策 | Matched-Single Q5 +1.463，相对置换 +1.319 | 继续保留效用监督 |
| 教师阶段匹配是关键突破 | Q5 较旧预测器 +0.127；正式主方法与 Uniform 持平 | 小幅机制收益，不足以作为主要性能贡献 |
| 两次响应平均可稳定改善策略 | 正式收益很小；Q5 两套预测器均下降约 0.26 点 | 作为读出比较保留，不升级为核心创新 |
| 当前状态响应优于错配响应 | 正式 TEST 当前响应未超过 reference 响应 | 本轮未支持 |
| 当前配方已经达到最终论文目标 | 正式增量很小，部分指标、seed、bank 不同向 | 尚未达到 |

本轮对论文目标的整体判断是：**比第一批略有改善，但仍未出现识别性能上的突破。** 正向证据集中在留出教师的效用决策；正式 CZSL 端仍存在迁移缺口。应保留 TRUST 的效用监督主线，同时降低对“继续匹配训练阶段和降低探针噪声就能解决问题”的预期。

### 下一步建议

把后续工作集中为一批“决策情境条件化的效用迁移”实验：保留当前强 CPF 基底、on/off 监督和共享拟合框架，检验关系效用是否需要显式依赖候选组合或竞争组，而非继续为每个模型只输出一组全局关系概率。旧全局映射、条件化映射和匹配置换使用相同正式权重或同一训练预算比较。

这与此前 Competition 只替换效用标量目标不同：新的研究变量是效用函数是否能表示“关系在什么组合竞争情境下有用”。当前结果提供了动机——留出教师上可用的效用没有稳定迁移到正式测试组合——尚未证明这个解释。下一批应直接测量相应条件效用并评价真实决策，不再仅用预测相关性选择方案。

本批结果不支持把主要资源继续投入更长教师训练、更多同类小范围正则搜索或扩大噪声实验。先改变并检验影响组合迁移的核心建模假设；真实识别增量建立后，再做新划分或第二数据集确认。
