本页保留 v1 完整结果形成时的下一轮提案。后续 v2 已归档，并修订了投影冻结与学习率配方；执行规格见 v2 修订方案。

研究判断：结束 TRUST-CPF v1 的效用预测、风险惩罚和随机选图扩展。下一轮只做一个整合实验：在已经验证较强的 CPF＋静态 CP 基底上，让知识仅修正物体条件属性分数。设置 Base、Knowledge、Shuffle 三组，三个 seed，共 9 次训练；GPU 使用 1、2、3。

本文分析归档内已有实验，补做结果汇总、同样本效用比较和日志恢复。没有启动新的训练，也没有改动原训练结果。

此前讨论中的两类“常数”要区分清楚：drop 是对每条关系独立做 Bernoulli 采样，本轮各类型概率均为 0.25，期望保留 OI/OE/AE 各 3/9/12 条，共 24/96 条；capacity 不使用关系附件，学习的是通用低秩变换与完整三元评分。capacity 的优势不能作为 Bernoulli 选图机制的收益。

2.2 低 AUC 的主要问题已经超出了积分口径

21 个模型、两个 world 中，native 与 exact AUC 的最大绝对差只有 0.113 点。积分采样差异解释不了当前模型与历史强基底之间的十几个至二十多个点差距。

日志中的 val_auc 已经使用百分数单位。例如 0.021956 就是约 0.022 个 AUC 点，不能再乘 100 解释成 2.2。教师阶段的 val_auc=None 表示该阶段未执行 VAL 选模；正式适配阶段接近零的数值则是实际结果。

3. 效用、消融与噪声结果是否支持继续 TRUST 机制

3.1 效用预测：有局部信号，但没有形成可靠的选择依据

以下均为独立 Q5 审计，每个 seed 3,072 条标签。方向准确率使用正负两类平均的 balanced accuracy，随机基准为 50%。

seed 完整模型 Spearman 方向准确率 完整模型 RMSE 类型常数 RMSE 边查表 RMSE 90% 区间覆盖率
3351 0.0878 52.62% 0.017361 0.016813 0.018545 77.31%
3352 0.2157 53.60% 0.008833 0.008466 0.009682 86.62%
3353 0.2302 50.50% 0.008191 0.007558 0.007788 90.36%

完整模型的 RMSE 在三个 seed 上都高于类型常数。方向准确率仅为 50.50%–53.60%；90% 区间覆盖率从 77.31% 到 90.36%，不确定性校准随 seed 明显变化。

完整模型并非完全没有排序信号：seed3352、3353 的整体 Spearman 分别为 0.216、0.230；OI 类型内部相关分别为 0.430、0.357。但 OE 类型内部相关分别为 −0.038、−0.029，AE 较弱，跨类型和跨 seed 的表现不一致。将这些预测直接变成全图选边概率，没有得到对应的 TEST 收益。

在测量定义中，标签本身为一条边对某个查询任务的边际损失改善：

u^Q,e,θ=1M∑m=1M[LQ(θ,Gm−e)−LQ(θ,Gm+e)].\widehat{u}_{Q,e,\theta} =\frac{1}{M}\sum_{m=1}^{M} \left[\mathcal{L}_{Q}(\theta,G_m^{-e})- \mathcal{L}_{Q}(\theta,G_m^{+e})\right].

代码符号与此一致，正值表示加边降低查询损失。困难在于这个量同时依赖查询组合 QQ、教师参数 θ\theta 和背景图；输入特征主要由关系语义与训练支持集摘要构成，没有显式输入该次查询组合或教师状态。因此，当前学习目标包含输入未直接描述的变化来源。

这一点在跨 fold 对齐中已经表现出来。把 Q1–Q3 的每条边平均效用与 Q5 的同一条边平均效用比较：

seed 96 条边均值的 Spearman 效用正负号一致率
3351 -0.1922 40.62%
3352 0.0178 51.04%
3353 0.2521 55.21%

三个 seed 中，排序相关为 −0.192、0.018、0.252，符号一致率为 40.63%、51.04%、55.21%。不同 fold 同时改变查询组成和教师参数，当前测量不能把二者分开；结果已经足够说明“边有一个稳定、容易迁移的全局效用次序”在本实现中没有建立起来。

背景图采样噪声也不小。Q1–Q3 中，记录的平均 Monte Carlo 方差占标签总方差约 29%–60%；Q5 增加到 16 个背景后降至约 5%–25%。增加采样可以改善测量精度，却不会自动消除跨教师、跨查询任务的目标变化。继续加大网络、ensemble 或测量数量，投入方向与当前主要问题不匹配。

dev_nll 为负并不是这里的错误。连续高斯密度可以大于 1，其负对数密度可以为负；NLL 的下降也不直接证明效用排序有效。

3.2 两个消融：视觉摘要有小幅作用，未测边结果没有超过简单对照

semantic3351 去掉视觉摘要后，整体 Spearman 从 0.0878 降为 0.0185，RMSE 从 0.017361 升为 0.017689；方向准确率从 52.62% 变为 52.46%。视觉摘要改善了一部分拟合，但幅度尚不足以支撑整条选择机制。

unmeasured3351 按类型留出 18 条边，即 2 条 OI、7 条 OE、9 条 AE，占全部关系的 18.75%。为了与完整模型公平对照，本次把四个预测器都放在这些留出边对应的同一批 591 条 Q5 样本上重新计算；类型常数也仅用非留出边训练。

3.3 知识打乱：原始内容存在信号，整条流程仍弱于无关系模型

seed3351 的原始 robust 为 9.999 CW / 8.282 OW，完整打乱流程为 8.588 CW / 7.545 OW。原始内容高出 1.411 CW 点、0.737 OW 点。

但打乱实验同时重新训练了教师、参考模型和效用预测器，回答的是整个流程对正确附件关系是否敏感。下一轮要用同一个基底、同一个参数化来测量内容差异。另一个很有说明性的现象是：打乱流程的效用 Spearman 为 0.357，高于原始 seed3351 的 0.088，最终识别却更低。效用审计更容易拟合，并不等价于学到了更有利于 CZSL 的关系。

4. 从实现看，下一轮应当改哪里

当前最重要的实现差异在三元项。用 Tθ(x,zo,za)T_\theta(x,z_o,z_a) 表示当前归一化投影后的三元评分，eo,eae_o,e_a 表示原始锚点，zo,zaz_o,z_a 表示图更新原型，则两类模型实际使用：

ΔUgraph=Tθ(x,zo,za)−Tθ(x,eo,ea),ΔUcapacity=Tθ(x,e~o,e~a).\begin{aligned} \Delta U_{\mathrm{graph}} &=T_\theta(x,z_o,z_a)-T_\theta(x,e_o,e_a),\\ \Delta U_{\mathrm{capacity}} &=T_\theta(x,\widetilde e_o,\widetilde e_a). \end{aligned}

图模型只有“三元项的变化量”，capacity 则有完整可训练三元项。零边时图模型的该项严格消失。这是从代码可以直接确认的函数形式差异，参数数量接近不能消除它。r0/capacity 又分别预训练自己的参考模型，图组使用另一套共同参考模型，因此当前比较同时包含参考模型训练差异。

此外，v1 的物体基础分数采用各候选物体查询特征与自身文本的匹配；历史 G0 使用全局视觉特征对物体文本评分。两者的学习率、CP 归一化和辅助损失也不同。直接在 v1 上增加适配 epoch，只会继续优化已经明显偏弱的基底。

下一轮同时落实三个相互配套的改变：恢复完整静态 CP；固定较强的物体概率；用确定性知识残差修正条件属性。 研究内容收敛到正确知识是否有可利用的条件判别信息。当前的五折教师、效用 MLP、风险惩罚、预算求解和多图平均退出这一轮。

5. 下一轮：强 CPF 基底上的条件知识残差

5.1 一个正式实验，三组 × 三 seed

组别 共同部分 条件属性分数 回答的问题
Base 对应 seed 的 G0 静态 CP 权重、冻结的物体评分、相同条件头续训 原始完整静态 CP 强共同基底在同等训练预算下的表现

Knowledge−Base 衡量整个知识分支的收益，其中包含新增参数的作用；Knowledge−Shuffle 衡量相同分支下正确附件内容的作用。这两个差值共同解释实验。三组从同一个 seed 对应的 G0 checkpoint 出发，使用同一图像顺序和训练预算。

数据首先固定为本轮 UT-Zappos natural 划分。使用 96 条现成知识关系：OI 12、OE 36、AE 48。关系全部参与确定性聚合，不再训练选边概率。Shuffle 在 OI/OE/AE 内分别打乱 source 附件，保持关系类型、目标节点、度数和 source 多重集不变；用固定扰动 seed7101 生成一次并保存映射。训练 seed 的差异只来自共同基底和优化随机性。

5.2 共同基底：直接保留 G0 的评分与尺度

固定 CLIP 图像向量 g(x)∈R768g(x)\in\mathbb{R}^{768}、属性文本 eae_a、物体文本 eoe_o 和组合文本 eaoe_{ao}。继承对应 seed 的 G0 权重，物体分数为：

三组均冻结 Bo,CoB_o,C_o，CLIP 及全部文本向量也冻结。条件属性分数保留完整静态 CP：

这里 Au,Av∈R32×768A_u,A_v\in\mathbb{R}^{32\times768}，Wc∈R768×32W_c\in\mathbb{R}^{768\times32}，Bo,Co,Bc,Cc∈R768×8B_o,C_o,B_c,C_c\in\mathbb{R}^{768\times8}。保留 G0 的 κ=20\kappa=20、ρ=0.15\rho=0.15。CP 因子沿用原尺度，不加入 v1 中额外的投影后 L2 归一化。Base 训练 Bc,Cc,Au,Av,WcB_c,C_c,A_u,A_v,W_c，Knowledge 和 Shuffle 也训练同一套共同参数。

5.3 知识只改变条件属性项

将全部属性和物体文本统一记为锚点 eve_v。关系 ee 的 source 文本向量为 he∈R768h_e\in\mathbb{R}^{768}，target 为 v(e)v(e)，类型为 t(e)∈{OI,OE,AE}t(e)\in\{\mathrm{OI},\mathrm{OE},\mathrm{AE}\}。复用现有类型低秩消息形式：

其中 Lt∈R768×16L_t\in\mathbb{R}^{768\times16}，Rt∈R16×768R_t\in\mathbb{R}^{16\times768}，固定 η=0.1\eta=0.1。每种关系类型分别除以对应目标节点度数，与现有图实现一致。实现归一化使用既有的数值 epsilon。

用共同 CP 参数读取更新原型，不再为知识分支额外随机初始化一套三元评分器：

Δcao(x)=ρκ g⊤Wc[(Auza)⊙(Avzo)−(Auea)⊙(Aveo)],caoK(x)=cao0(x)+αΔcao(x).\begin{aligned} \Delta c_{ao}(x) &=\rho\kappa\,g^\top W_c \left[ (A_u z_a)\odot(A_v z_o) -(A_u e_a)\odot(A_v e_o) \right],\\ c^K_{ao}(x)&=c^0_{ao}(x)+\alpha\Delta c_{ao}(x). \end{aligned}

Knowledge 和 Shuffle 的可训练标量 α\alpha 均初始化为 0；LtL_t 用标准差 0.01 的高斯初始化，Rt=0R_t=0。因此训练起点严格为同一个 G0 条件评分，之后通过 CZSL 监督直接学习如何使用原型残差。第一步可先更新 α\alpha，随后梯度进入消息参数。

完整静态项始终保留。设关系聚合为零且锚点已单位归一化，则 za=ea,zo=eoz_a=e_a,z_o=e_o，从而 Δc=0\Delta c=0、cK=c0c^K=c^0。这里消失的是知识引起的增量，原本的完整 CP 能力仍然存在。

三个模型统一输出：

没有额外的知识物体 logit 修正。未知组合通过对应原型和共享 CP 因子评分，推理时不使用真实物体标签。

5.4 训练目标与固定配方

沿用 G0 的任务目标。设训练候选集合为 Ctr\mathcal{C}_{\mathrm{tr}}，样本真值为 (ai,oi)(a_i,o_i)，定义：

ℓpair,i=−Jaioi(xi)+log⁡∑(a,o)∈Ctrexp⁡Jao(xi),ℓcond,i=−log⁡P(ai∣oi,xi),ℓobj,i=−log⁡P0(oi∣xi),L=1.51+β1B∑i=1B[ℓpair,i+β(ℓcond,i+ℓobj,i)],β=0.075.\begin{aligned} \ell_{\mathrm{pair},i} &=-J_{a_i o_i}(x_i) +\log\sum_{(a,o)\in\mathcal{C}_{\mathrm{tr}}}\exp J_{ao}(x_i),\\ \ell_{\mathrm{cond},i}&=-\log P(a_i\mid o_i,x_i),\\ \ell_{\mathrm{obj},i}&=-\log P_0(o_i\mid x_i),\\ \mathcal{L} &=\frac{1.5}{1+\beta}\frac1B\sum_{i=1}^{B} \left[\ell_{\mathrm{pair},i} +\beta(\ell_{\mathrm{cond},i}+\ell_{\mathrm{obj},i})\right], \qquad\beta=0.075. \end{aligned}

物体项因分支冻结而成为常数；保留它便于与原目标对齐。组合归一化仍会对所有训练候选的条件分数产生梯度。三组不增加效用监督或额外置信度损失。

在相同完整属性词表下计算，并单独报告未见组合图像的平均 margin、正 margin 比例。Knowledge 与 Shuffle 的新增参数数目相同；不再用“参数数目相近”代替内容对照。

我对后续主线的选择是：先用这 9 次训练把“知识内容是否有用”直接做清楚，同时结束 v1 的效用估计与选图研究。 Knowledge 同时优于 Base 和 Shuffle，才构成继续研究知识条件判别的依据；只优于 Base、接近 Shuffle，收益主要应归于新增分支的参数化；两项都没有形成清楚增益，则将后续投入转回此前讨论的可训练局部视觉判别，即同一物体条件下先比较属性证据、再汇聚位置。

该局部视觉方向已经在 VG-CPOD roundK 分析中形成了具体方案。它与本轮三组知识实验不同时混入一个新模型：前者改变视觉证据，后者检验外部语义附件，混合修改会再次丢失主要增益来源。

当前数据已经足够结束“再跑更多 v1 噪声或小消融以寻找优势”的工作。下一轮的价值在于恢复强识别能力后，集中回答一个明确的问题；不再延长教师、效用预测、风险与随机选图组成的实验链。
