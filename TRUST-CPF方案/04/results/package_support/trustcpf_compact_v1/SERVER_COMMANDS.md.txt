出现 `UPLOAD_AND_EXTRACTION_COMPLETE` 表示上传解压成功。脚本位置及 ZIP 均在本机 `output` 目录，SHA256 文件采用 Linux 换行。

## 2. 服务器 Bash：初始化与测试

以下命令在登录服务器后执行：

```bash
conda activate vgcpod_v1
cd /data/xhw/experiments/trustcpf_compact_v1

python run.py setup \
  --source /data/xhw/experiments/trustcpf_strong_v1 \
  --response-source /data/xhw/experiments/trustcpf_modelcond_v1 \
  --cache /data/xhw/vgcpod_v1_runs/cache_ut_clip_l14

source scripts/env.sh
"$CPF_PY" -c 'import sys, torch, numpy; print(sys.executable); print("PyTorch:", torch.__version__, "NumPy:", numpy.__version__, "CUDA:", torch.cuda.is_available())'
"$CPF_PY" -m unittest discover -s tests -v
```

`setup` 会扫描已有缓存并校验来源；结束输出 `SETUP_COMPLETE`。测试末尾应为 `OK (skipped=1)`；跳过项是本轮复用特征、不再运行的 CLIP 提取接口。新算法只依赖当前环境已有的 NumPy/PyTorch。初始化自动写入实际 Python 路径，无需填写旧的 `/srv/.../python`。
