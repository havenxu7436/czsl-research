Align 半密度对齐：仓库恢复、服务器训练与本地保存

本页从仓库重建同一执行版本；个人上传、训练和下载原命令 保留当时路径与操作说明。

服务器：从仓库恢复

conda activate vgcpod_v1
cd "$HOME/czsl-research"
export CPF_REPO="$PWD"
git lfs pull --include="TRUST-CPF方案/**"
python tools/reproduce.py materialize --line TRUST-CPF方案 --stage 05 --dest "$HOME/experiments/trust-05-replay"
cd "$HOME/experiments/trust-05-replay/trustcpf_align_v1"
python run.py setup \
  --source "$CPF_REPO/TRUST-CPF方案/04/results/raw_export/trustcpf_compact_v1" \
  --teacher-source "$CPF_REPO/TRUST-CPF方案/02/results/raw_export/trustcpf_strong_v1" \
  --cache /data/xhw/vgcpod_v1_runs/cache_ut_clip_l14 \
  --work "$PWD/work"
source scripts/env.sh
CUDA_VISIBLE_DEVICES="" "$CPF_PY" -m unittest discover -s tests -v
mkdir -p logs
nohup bash scripts/run_all.sh 0 2 3 >> logs/queue.log 2>&1 < /dev/null &
tail -F logs/queue.log

队列参数是三张物理卡与 seed3351/3352/3353 的对应，可按服务器空闲卡修改。缓存需与本阶段 assets 指纹一致。运行包含本批全部识别及 Q5 队列。

服务器：完成检查和打包

source scripts/env.sh
"$CPF_PY" run.py report
"$CPF_PY" scripts/check_complete.py
bash scripts/pack_results.sh

下载新运行结果时，在 Windows 执行恢复包内的 scripts/download_trustcpf_align_v1.ps1；下载脚本根据服务器 latest_archive.json 取得归档名，校验 SHA256 后使用 UTF-8 解压。

在本地仓库根目录执行：
