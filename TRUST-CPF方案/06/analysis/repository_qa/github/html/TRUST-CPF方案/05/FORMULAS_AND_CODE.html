2. 半密度概率求解

令预测效用为 $\mu_e$，类型集合为 $E_t$，$N_t=\vert E_t\vert $。采用总体标准差：

$$c_t=\frac{1}{N_t}\sum_{e\in E_t}\mu_e, \qquad s_t=\sqrt{\frac{1}{N_t}\sum_{e\in E_t}(\mu_e-c_t)^2}, \qquad r_e=\begin{cases}(\mu_e-c_t)/s_t,&s_t\gt 10^{-12},\\0,&s_t\le10^{-12}.\end{cases}$$

对 $\kappa\in\{0,0.5,1,2\}$ 求解：

$$\max_{0\lt \pi_e\lt 1} \left[\kappa\sum_e r_e\pi_e- \sum_eD_{\mathrm{KL}}\bigl(\mathop{\mathrm{Bern}}\nolimits(\pi_e)\Vert\mathop{\mathrm{Bern}}\nolimits(0.5)\bigr)\right], \qquad \sum_{e\in E_t}\pi_e=N_t/2.$$

KL 对概率的一阶导数为 $\log(\pi_e/(1-\pi_e))$。加入每类型等式乘子 $\gamma_t$，一阶条件给出：

$$\kappa r_e-\log\frac{\pi_e}{1-\pi_e}-\gamma_t=0, \qquad \pi_e=\sigma(\kappa r_e-\gamma_t).$$

目标的二阶导数为 $-1/[\pi_e(1-\pi_e)]\lt 0$，故解唯一。类型概率和随乘子单调下降，用 float64 二分求解。实现中收敛误差为 $10^{-12}$，最后检查不超过 $10^{-10}$。全常数类型和 $\kappa=0$ 返回精确的 0.5。

核心实现：trustcpf/align.py::policy。原始效用、类型尺度、乘子及 float64 概率保存到 policies.pt。训练和推理使用 float32 概率，部署表报告实际使用概率；其预算误差仅来自 float32 舍入。

prob, type_scale = policy(mu, types, strength)
indices = permutation(types, 7101)
permuted_prob = prob[indices]

类型内概率置换保留概率多重集合、熵、期望边数和各类型边数分布，改变概率与关系的对应。节点覆盖差异单独记录。

$$P_{\mathcal C}(y\mid x,b)= \frac{\exp s_y(x,b)}{\sum_{c\in\mathcal C}\exp s_c(x,b)}, \qquad \log\overline P_{\mathcal C}(y\mid x)= \mathop{\mathrm{logsumexp}}\nolimits_{m=1}^{16}\log P_{\mathcal C}(y\mid x,b^m)-\log16.$$

4. Q5 的单图与混合效用

每个 Q5 Query 组合用固定 seed 8101 划分图像为两个不重叠集合，各集合每组合最多 8 张。少于两张的组合记录在 sampling.json，其余组合在两侧具有相同支持集。

令保留组合数为 $Q$，某侧组合 $q$ 的图像数为 $n_q$，样本权重为 $w_i=1/(Qn_q)$。测量和评价分别按自身 $n_q$ 计算权重。

测量使用 $K=8$ 个独立背景块，每块 $M=16$ 张独立半密度图。背景块 seed 为 8111–8118。干预第一槽的边 $e$，其余开关固定；所有边共享该块的另外 15 个伴随槽。

定义真实类概率 $p^0_{i,e,k},p^1_{i,e,k}$ 和伴随概率之和 $S_{i,k}$，候选为全部 TRAIN 组合：

$$d^{(1)}_{e,k}=\sum_iw_i\left(\log p^1_{i,e,k}-\log p^0_{i,e,k}\right),$$ $$S_{i,k}=\sum_{m=2}^{M}P_{\mathcal C_{\mathrm{tr}}}(y_i\mid x_i,b_k^m), \qquad d^{(M)}_{e,k}=\sum_iw_i\left[\log(S_{i,k}+p^1_{i,e,k})-\log(S_{i,k}+p^0_{i,e,k})\right].$$

于是：

$$\widehat u^{(1)}_e=\frac1K\sum_kd^{(1)}_{e,k}, \qquad \widehat u^{(M)}_e=\frac{M}{K}\sum_kd^{(M)}_{e,k}.$$

混合 NLL 的分母 $M$ 在 on/off 差中抵消；共享概率控制 $M$ 个独立槽位，因此单槽差需要乘 $M$ 才对应整个混合风险对采边概率的负梯度。单图和混合标签复用同一对前向分数。

对应标准误平方：

$$\widehat{\mathop{\mathrm{SE}}\nolimits}^2(\widehat u^{(1)}_e) =\frac{\mathop{\mathrm{Var}}\nolimits_{k,\mathrm{unbiased}}(d^{(1)}_{e,k})}{K}, \qquad \widehat{\mathop{\mathrm{SE}}\nolimits}^2(\widehat u^{(M)}_e) =\frac{M^2\mathop{\mathrm{Var}}\nolimits_{k,\mathrm{unbiased}}(d^{(M)}_{e,k})}{K}.$$

核心实现：

single = ((log_on - log_off) * weights).sum(-1)
mixture = ((torch.logaddexp(log_companion_sum, log_on)
            - torch.logaddexp(log_companion_sum, log_off)) * weights).sum(-1)
u_single = single_blocks.mean(0)
u_mixture = graphs * mixture_slot_blocks.mean(0)

见 decision_audit.block_effect、measure、summarize_effect。保存各块 96 条边的 on/off 真类 log 概率、15 个伴随槽的 log 概率、图掩码、图像与候选 ID、权重及教师哈希。所有加法在 log 域完成。

5. 独立图像上的真实决策作用

用审计版 Compact 的预测、实测单图效用、实测混合效用各生成 $\kappa=1$ 策略；每个策略增加 seed 7101 的类型内概率置换。对六个方向分别保存完整策略与局部策略：

$$\pi^{\mathrm{local}}=\tfrac12\mathbf1+\eta(\pi-\tfrac12\mathbf1), \qquad \eta=\min\left(1,\frac{0.1}{\|\pi-\tfrac12\mathbf1\|_\infty}\right).$$

零方向取 $\eta=1$。加上 Uniform 共 13 个策略。局部策略保留预算，最大概率位移为 0.1。

评价集合使用全新的 8 个 bank，种子 8201–8208，每个 16 图。策略间共享 uniform 随机数，再按各自概率阈值采样。对于同一组预测同时计算：

$$\widehat R_1=-\sum_iw_i\frac1M\sum_m\log p_i^m, \qquad \widehat R_M=-\sum_iw_i\log\left(\frac1M\sum_mp_i^m\right).$$

single_gain／mixture_gain 定义为 Uniform 风险减当前风险，正值代表改善。真实策略相对概率置换的配对收益保存在 decision/audit.json。每个 bank 的结果独立保存，另汇总均值、标准差与 MCSE；这里的 MCSE 表示固定教师和图像条件下的图采样变化。三个训练 seed 的结果另行比较。

同时保存原单位的一阶代理 $u^\top(\pi-0.5)$，以及预测—单图实测、预测—混合实测、单图—混合实测的类型内 Spearman／Pearson。这样可以检查代理收益是否转化为实际风险改善。
