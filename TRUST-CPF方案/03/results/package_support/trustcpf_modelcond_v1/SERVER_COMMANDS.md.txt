## 1. 本机 PowerShell：上传并解压

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\llenovo\Documents\ChatGPT\USG\output\upload_trustcpf_modelcond_v1.ps1"
~~~

脚本校验本地 ZIP，上传 ZIP 和 SHA-256 文件，在服务器校验并解压到 /data/xhw/experiments/trustcpf_modelcond_v1。按提示输入服务器密码，独立 SSH/SCP 连接可能提示多次。

随后登录：

~~~powershell

~~~

对应的手动上传命令如下；已运行上传脚本时直接进入第 2 步：

~~~powershell

scp -o ServerAliveInterval=30 -o ServerAliveCountMax=6 "$cpfBundle\trustcpf_modelcond_v1.zip" "$cpfBundle\trustcpf_modelcond_v1.zip.sha256" "${cpfServer}:/data/xhw/experiments/"
ssh $cpfServer 'cd /data/xhw/experiments && sha256sum -c trustcpf_modelcond_v1.zip.sha256 && unzip -oq trustcpf_modelcond_v1.zip -d .'
~~~

## 2. 服务器 Bash：一次性准备

~~~bash
conda activate vgcpod_v1
cd /data/xhw/experiments/trustcpf_modelcond_v1
python run.py setup \
  --source /data/xhw/experiments/trustcpf_strong_v1 \
  --cache /data/xhw/vgcpod_v1_runs/cache_ut_clip_l14
source scripts/env.sh
"$CPF_PY" -c 'import sys,torch; print(sys.executable); print("Torch:",torch.__version__,"CUDA:",torch.cuda.is_available(),"GPU count:",torch.cuda.device_count())'
"$CPF_PY" -m unittest discover -s tests -p 'test_*.py' -v
~~~

setup 读取当前已激活环境的 Python，记录到 server_env.sh，并校验旧模型与特征缓存。直接复用 CLIP 特征，无需重新填写 DATA_ROOT、CLIP_CKPT，也无需安装新的 PyTorch。

本机测试环境为 Python 3.11 / PyTorch 2.11；交付源码兼容 Python 3.8 语法，接口沿用现有 PyTorch 1.13。服务器上的测试会验证实际运行环境。
