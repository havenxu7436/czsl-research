# TRUST-CPF / TRUST-G₀ 三数据集完整实验结果与分析

日期：2026-10-30。实验版本：`trustg0_three_v1_10ep`。数据集：UT-Zappos50K、MIT-States、C-GQA。独立完整流水线 seed：5351、5352、5353。

**整体结论：Context 在 UT 和 C-GQA 上相对 Uniform 有小幅正式识别收益，MIT 基本持平。MIT 与 C-GQA 的独立教师审计同时支持效用分配具有局部价值；但这份价值尚未稳定转化为三个数据集的最终识别优势。TRUST 的效用监督与条件迁移研究点可以保留，当前版本还不足以支撑“跨数据集稳定优于等预算基线”的论文主结论。**

本报告将三个完整结果包统一统计，不改动原始结果。UT、MIT 延续同日已完成的全量核验，C-GQA 补齐同口径复算，并新增三套实现、配置和数据划分的交叉检查。本文件包含全部关键表格和结论，无需另外打开图片或前轮报告才能阅读。

## 1. 这批实验回答什么，以及数据是否完整

本轮底座是历史 VG-CPOD V1，记为 G₀；TRUST-CPF 是研究路线名称，结果表使用 TRUST-G₀ 区分本次实现。**它不是 Wu 等人 ICCV 2025 CPF 的纯论文复现。** 本报告评价同一 G₀ 体系内的增量，不将其绝对分数与 CPF 论文分数直接作复现判断。

### 1.1 实验与统计口径

| 方法 | 权重与读出 | 主要回答的问题 |
| --- | --- | --- |
| G₀ | 原始底座，无关系残差 | 起始识别能力 |
| Capacity | 冻结 G₀，单独训练通用残差头，无知识附着 | 额外容量与适配的贡献 |
| Dense | 复用 Uniform 权重，所有关系开启 | 使用全部关系的效果 |
| Uniform | 公共关系权重，所有边选择概率为 0.5 | 等期望关系预算基线 |
| Matched | 复用 Uniform 权重，27 参数全局效用预测 | 全局效用监督的增量 |
| Context | 复用 Uniform 权重，51 参数条件效用预测 | 情境条件效用的增量 |
| Context-Shuffle | 打乱部分拟合教师的情境输入对应，重新拟合 | 正确情境对应是否有用 |
| Matched-Perm × 5 | 同类型关系内置换 Matched 概率 | 全局分配与具体关系的对应是否有用 |
| Context-Perm × 5 | 同类型关系内置换 Context 概率 | 条件分配与具体关系的对应是否有用 |

每个数据集、每个 seed 都独立训练教师、拟合效用模型及训练正式识别器。每套流水线有 15 位教师：3 次初始化 × 5 折；Q1–Q3 的九位教师拟合效用，Q4 提供开发审计，Q5 独立审计。本轮超参数固定，Q4 不调参。

G₀ 训练 10 epoch；关系参考训练 10 epoch，再适配 10 epoch。正式 Uniform 与 Capacity 分别执行上述两个关系阶段。教师取最后一轮；正式 G₀、Uniform、Capacity 从 epoch 0–10 按 VAL CW native AUC 选模。各效用策略共享同一个 Uniform best checkpoint，因此 Context − Uniform 直接比较分配策略；Uniform − G₀ 同时包含额外模块和适配训练，不能当作效用监督本身的收益。

每套流水线有 17 个方法、45 个读出：G₀/Capacity/Dense 各一次，其余 14 个策略各三个图库，图库 seed 为 1701/2701/3701，每个图库 16 张图。关系置换 seed 为 7101–7105。

**统计先在同一 seed 内平均图库及相应置换，再跨三个独立 seed 汇总。所有 ± 为样本标准差，不是置信区间。** Q5 先平均同 seed 的三位教师，再汇总三个 seed；9 位教师的正向次数只作描述。AUC/HM 使用 0–100 标度，增量单位为点。TEST HM 固定使用相应 VAL 的 bias，区别于 TEST 搜索的最佳 HM。NLL 越低越好；原始 ECE 为 0–1 标度。原始概率的 NLL/ECE 与经过 bias 的 HM 分开解释。

### 5.2 效用预测质量：C-GQA 提供了新的正向证据

原始审计中，Matched 对全局效用标签，Context 对条件效用标签，二者原始 RMSE/相关性不能直接当作同目标精度比较。下表将 Matched 广播到两个情境，使用同一条件标签、同一情境权重计算 RMSE；排序相关则在各情境、各关系类型内中心化后计算。先平均同 seed 的三位教师，再跨 seed 汇总，与九位教师等权均值相同。

| 数据集 | Q5 预测器 | 共同条件目标加权 RMSE ↓ | 类型内中心化 Spearman ↑ |
| --- | --- | --- | --- |
| UT-Zappos50K | Matched | 0.0036906 | 0.0051 |
| UT-Zappos50K | Context | 0.0039356 | 0.0098 |
| UT-Zappos50K | Context-Shuffle | 0.0038417 | 0.0153 |
| MIT-States | Matched | 0.0002885 | 0.0665 |
| MIT-States | Context | 0.0002890 | 0.0340 |
| MIT-States | Context-Shuffle | 0.0002896 | 0.0600 |

| C-GQA | Context | 0.0002574 | 0.3224 |
| C-GQA | Context-Shuffle | 0.0002668 | 0.3235 |

UT、MIT 的 Context 没有提高同目标条件预测精度。C-GQA 的 Context RMSE 则从 Matched 的 0.0002619 降到 0.0002574，约降低 **1.73%**；三个 seed 的均值都改善，8/9 位教师改善。Q4 也有 8/9 教师改善。这支持情境输入在 C-GQA 的条件效用数值拟合中提供信息。

不过，C-GQA 的 Context 类型内排序相关 0.3224 仍低于 Matched 的 0.3413。条件数值拟合略好，不等于预算分配需要的关系排序也更好；这与 Context 的正式 OW 不及 Matched 相呼应，但并不能单凭相关性确定其因果来源。

进一步将查询图像按组合拆成两半重算效用标签，Q5 split-half Spearman 均值为 UT **0.410**、MIT **0.498**、C-GQA **0.695**。C-GQA 标签排序的重复性更好，与它更高的类型内预测相关一致。两半共享背景图，只在有至少两张查询图像的组合中各取一张，因此它是样本敏感度诊断，不是完全独立重复实验。

三个数据集的 Context 概率标准差范围分别为 UT 0.177–0.182、MIT 0.174–0.184、C-GQA 0.116–0.128；均明显区别于 Uniform。所有类型内期望预算 Σπ=|E_type|/2 都满足，随后进行 Bernoulli 采图，16 图概率混合。当前结果不是策略未启用或预算不一致造成的。

### 5.3 候选集合变化是有依据的下一步检验方向

| 数据集 | 测量 / Q5 候选数 | 正式 TEST CW | 正式 OW |
| --- | --- | --- | --- |
| UT-Zappos50K | 83 | 101 | 192 |
| MIT-States | 1,262 | 1,662 | 28,175 |
| C-GQA | 5,592 | 6,515 | 278,362 |

当前效用标签、响应特征及 Q5 决策均在自然 TRAIN 组合集合上计算，而正式 CW/OW 采用更大的候选集合。MIT、C-GQA 在 OW 的候选规模分别扩大约 22.3、49.8 倍。

令候选集合为 $`\mathcal{C}`$，关系干预前后分数为 $`s_j^{(0)}`$、$`s_j^{(1)}`$，且 $`\Delta s_j=s_j^{(1)}-s_j^{(0)}`$。单图效用为

```math
\begin{aligned}
u_e^{\mathcal{C}}(x)
&=\log p_{\mathcal{C}}^{(1)}(y\mid x)-\log p_{\mathcal{C}}^{(0)}(y\mid x) \\
&=\Delta s_y-\log\sum_{j\in\mathcal{C}}p_{\mathcal{C}}^{(0)}(j\mid x)\exp(\Delta s_j).
\end{aligned}
```

这是 softmax 分母相除的直接结果。改变候选集合会改变竞争项，因而同一关系的效用不必保持大小和符号。三数据集的风险迁移表与这一机制相容，但本轮没有单独控制候选集合，因此只能把它作为优先检验的解释，不能认定为唯一原因。情境划分、标签质量和教师到正式权重的变化仍可能共同影响迁移。

该式描述单图干预，正式部署为 16 图混合。历史 Mix16 实验已测试另一层单图/混合差异，标签排序高度相似且没有带来独立正式增量，故下一轮不应仅重复 Mix16 修改。

当前数据不支持将 MIT 的 G₀→Uniform 收益都归给 TRUST，也不支持把 C-GQA 的 OW 3/3 微小正向增量直接写成稳定全面优势。适合保留的证据是具体的机制链及其尚未闭合的迁移环节。

## 7. 论文结论与下一步的明确判断

| 研究主张 | 本轮证据 | 当前判断 |
| --- | --- | --- |
| 额外模块与适配能改善 G₀ | MIT、C-GQA 的 Uniform CW/OW 三 seed 全正；Capacity 同样有收益 | 成立于这两套数据，但不等于效用监督贡献 |
| 关系效用能跨教师产生决策收益 | MIT、C-GQA Q5 对 Uniform/关系置换三 seed 平均全正；三数据集未见 NLL 均改善 | 有正向机制证据 |
| 情境条件能改善效用预测 | C-GQA 同目标 RMSE 改善，8/9 教师；UT/MIT 未改善 | 有数据集依赖的支持 |
| 正确情境对应改善最终识别 | UT/C-GQA CW 有小幅收益；MIT 接近零；C-GQA OW 低于 Shuffle | 尚不一致 |
| TRUST 稳定超过等预算 Uniform | UT、C-GQA 平均正向；MIT 接近零；多处 seed/图库方向不同 | 当前版本尚未达到 |
| TRUST 是各任务下最佳方案 | UT OW G₀ 更高；MIT/C-GQA OW Capacity 更高 | 当前结果不支持 |

**研究路线仍值得保留；下一轮应集中改善效用迁移，而不是继续扩展外围消融。** 三数据集已经覆盖，不必再把“多跑一个数据集”当成主要进展。

建议下一批只围绕“候选集合一致的条件效用”推进：保留本轮 G₀、共同 Uniform 权重、预算和读出，复用现有教师；对齐源响应、目标效用及审计所使用的候选规则，并共同检查已见/未见风险。主要比较保留 Uniform、当前 Context、候选对齐 Context 及其关系置换，同时引用已有 Matched/Capacity 结果。改变候选后需要重新计算对应响应与效用，不能直接缩放当前统计量。

拟合仍只使用自然 TRAIN 内的教师数据，开发规则在 Q4/VAL 确定，TEST 保持最终评估用途。若新方案只提升 Q5 而正式 Uniform 对照仍不改善，后续重点应转向效用迁移表示本身；若正式收益与关系对应同时改善，才继续完善论文主结果。

本轮最准确的结论表述是：**响应驱动的关系效用在独立教师任务上具有可学习、可决策的价值；条件分配在部分数据集改善识别，但跨候选空间和跨模型状态的稳定迁移仍是决定最终收益的关键问题。**
